# 確定音演出集の確認
提供動画 NakloAPrNTI、1960.894秒。約120秒間隔の画面サンプルと55/175/535/1015秒から各12秒の音声を抽出し、スペクトログラムを確認。32分すべてを聴き通したレビューではない。BGM・筐体音を含む録音から個々の音源を正確に分離したものではない。
複数の筐体で光・役物・図柄確定が組み合わされる画面と、帯域の広い過渡音・持続倍音・急な周波数上昇が見える区間を参照。
独自合成の確定音を連打・金属的なFM・グライド・低音・和音の余韻へ再構成。音量だけで評価せず、調整画面に試聴と低音強度を設置。聴感の好み・実機再現度は未検証。元動画・音声は配布ビルドへ含めない。
