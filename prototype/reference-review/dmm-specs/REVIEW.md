# DMMぱちタウン：機種スペック・演出設定の読み方

確認日：2026-09-22。ユーザー提供の[機種一覧2ページ目](https://p-town.dmm.com/machines/pachinko?page=2)と、下記3機種の詳細本文を確認。取得したHTMLの本文・表を読んだ記録であり、画像内の振分け図や動画の全内容まで確認したものではない。一覧は更新されるため、参照には個別機種URLを使う。

## 今後の仕様検討で優先すること

「設定」を一つにまとめず、**機種の基礎スペック／状態ごとの遊技の流れ／演出カスタム／ゲーム独自の補正**に分ける。ユーザーの意図は、このように実機の仕様を具体的に理解して設計に反映すること。今回の調査だけで他機種の数値をゲームへ採用したことにはしない。

機種名だけでなくバージョン・型式を記録する。同じ作品でも99ver.と別スペックは別物。「準備中」「非搭載」「－」も区別する。「設定判別」という見出しがあるだけで、その機種に設定差があると推測しない。

## 読み取る項目

| 項目 | 記録する内容・注意点 |
| --- | --- |
| 確率 | 通常時／高確率／右打ち中を分ける。図柄揃い・役物チャレンジ・小当り等との合算を同じ事象として扱わない |
| ラウンド・カウント | 何Rの大当りがあり、各R何個で終了するか。初当りと右打ち時の振分けも別に記録 |
| 賞球 | 入賞口ごとの払い出し。賞球列だけから対応する口を推測せず、説明・盤面図で確認 |
| 出玉 | 払い出し／実質獲得など、ページの注記ごと保存。発射消費後の差玉と同一視しない。複数大当りの合計表示も区別 |
| 突入 | 右打ちへの移行、RUSH直行、チャレンジ突破込みのトータル、LT突入を分ける |
| 継続・終了 | ST回数、残保留、時短、転落など何で終わるかを記録。継続率だけをゲームのラウンド上乗せ率に転用しない |
| 状態遷移 | 当選・非突入・規定回転数消化・転落で次にどの状態へ進むか。打ち方の指示も併記 |
| 演出 | 通常／右打ち、カスタム、発生タイミング、色、発展先を組み合わせて読む |
| 遊タイム等 | 搭載有無と移行先。大当りの直接保証とは区別する |

## 確認した具体例

### 炎炎ノ消防隊2 99ver.

[DMMの詳細](https://p-town.dmm.com/machines/5067) ／ [メーカーのスペック](https://www.sankyo-fever.jp/products/machine_list/pxj/spec/)

- 通常1/99.9、右打ち実質1/23.8、4Rまたは9R・10カウント、払い出し400または900個。
- 初当り後の右打ち移行100%には、短いチャレンジが含まれる。トータルRUSH突入約60%とは別の指標。
- チャレンジ1回＋残保留4個、RUSH30回＋4個、上位64回＋4個。約77%と約95%はそれぞれの継続率であり、同一大当りのR加算確率ではない。
- カスタム表は通常時と右打ち中に分かれる。同名の先青線フラッシュでも、通常時は信頼度、右打ち中は発生率を選ぶ形。表示される「50%」を大当り抽選確率と解釈しない。
- 演出表は信頼度と大当り占有率を別欄にしている。現在のゲームの演出設定にも、この区別が必要。

### eゾン100

[DMMの詳細](https://p-town.dmm.com/machines/5060)

通常約1/199.5で、今回の基準に近い。ただしSTとLTは別の状態・確率を持ち、通常側の滞在モードでも右打ち突入割合が変わる。STは回数で、上位は転落方式で終了するという違いもある。**1/199前後という一点だけで同じ遊技仕様とは判断しない。** 本ゲームにこれらのモードを採用したわけではない。

演出カスタムや色の基本序列があっても、個別演出には例外がある。一律に「青＝低信頼」「赤＝固定の期待度」という共通テーブルを全機種・全演出へ当てはめない。

### デカスタeGODZILLA7 超震撼ver.

[DMMの詳細](https://p-town.dmm.com/machines/5092)

一覧の確率は役物チャレンジ・図柄揃い・ST実質という異なる段階を含む。役物チャレンジ発生約1/58.99、成功約42%、その成功後の図柄抽選1/9.9という流れを読み、1/9.9だけを通常1回転の当選確率として抜き出さない。

2R／10Rというラウンド表と、最大7500個という出玉表示を分けて確認する。「7500÷賞球÷カウント」で単一大当りのR数を逆算しない。取得時点では導入予定・解析準備中の項目があり、未掲載の振分けや詳細は未確認として残す。

## 演出を設計するときの区別

以下はこのゲームへ落とし込むための整理。

- **信頼度**：その演出が出たときに当たる割合。
- **大当り占有率**：大当りのうち、その演出を伴う割合。サイトに対象演出等の限定注記があれば分母も保存する。
- **出現率**：対象の変動のうち演出が出る割合。対象が通常時か右打ち中かも必要。

例えば全1000変動で大当り10回、演出Aが20回出てそのうち8回当たる仮想例なら、信頼度40%、大当り占有率80%、出現率2%。これは説明用の例で実機の公表値ではない。

先読み・先バレ・保留変化・リーチ中のチャンスアップ・復活等を、発生段階に沿って組み立てる。色変更は当落結果に対応した演出選択として設計し、演出カスタムの変更だけで基礎大当り確率を変更しない。基礎確率を変えるスキルは別のゲーム独自効果として表示・管理する。

## 本ゲームのスペック表に用意する欄

| 区分 | 現状と今後の記載方針 |
| --- | --- |
| 基礎 | 通常確率1/199等、4R/6R/10R、振分け、各入賞口の賞球、カウント・開放時間。実機確認済みか仮設定かを付ける |
| 状態 | 現在は通常変動・リーチ・大当り・上乗せ判定。電チュー・ST・時短・V入賞は未実装と明記 |
| 継続 | 現在の同一大当りへのR加算はゲーム独自。実機のRUSH継続率と別欄にする |
| 演出設定 | シーン・結果パターンだけでなく、予告→リーチ→発展→当落／復活の流れ、色・信頼度・占有率の設計値を分ける |
| ゲーム補正 | コース倍率、永続強化、スキル、保証天井、保留5個、自動止め打ち、ステージ進行・チケット |

実機の性能表と、開発用に値を変更できるデバッグ画面も別物。今回の調査では仕様・数値・演出の追加実装は行っていない。収益・交換率の攻略表は本ゲームの換金しない設計には転用しない。
