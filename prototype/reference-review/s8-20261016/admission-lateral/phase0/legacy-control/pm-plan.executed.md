# S8継続：ヘソ直前の左右方向を単独比較

目的：ユーザーが承認した「3枚を維持し、他の必要箇所も改善して入賞を増やす」を継続する。期間は固定せず、この有限組の比較・採否まで。第1組の釘90上0.25は9/250で増加なし、球半径2.0は右RUSH滞留で不採用。旧記録を保全し、今回は元半径1.8・3枚羽根を維持する。

根拠：3枚基準で釘90へ接触した6球が全OUT、多くが接触で右向き速度を失った。ID240は90の後に91左側で反転した。ヘソ近傍後OUT15球の保存済み下降sampleは左9/右6に外れた。これらは接触候補の根拠であり、移動の効果や正確なセンサ横断位置を保証しない。

## 有限4設定

1. `legacy-control`：旧風車・元101点、性能参照だけ。
2. `three-base`：3枚羽根・元101点、現基準。
3. `pin90-right025`：3枚羽根、元位置から釘90だけ右0.25。
4. `pin91-left025`：3枚羽根、元位置から釘91だけ左0.25。

全てガイドなし、球半径既定1.8・既定表示、power.18・間隔.6、gravity690、レールlegacy、口20、風車中心と形状/回転係数、元101本と釘属性・左上の狙い・抽選/賞球を固定。配置は元位置から単独変更し、上移動や球径案と組み合わせない。宣言以外を拒否し、静的成立しない案は未実施として残す。

## 比較・選別・受入

第1組の厳密validatorを維持し、今回専用manifest/planと許可2案を追加する。旧4設定のguardsを緩めず履歴を保持する。関連test/互換/静的preflight後、同一新source/HEAD/plan/manifestで全成立設定をfresh測定する。phase0各実250発、250spawn stepで停止＋45秒排出、最大300秒未達は失敗保存。測定中source/Git変更・撮影・重処理をしない。変更ごとに実試射とヘソ、両対照との差、一般/OUT/返却/残球/滞留/LCDを報告する。

両対照のヘソを厳密に超え、安全と狙いが成立した新案だけ選別する。最多ヘソ、同率は記載順の90案を優先し1案だけ選ぶ。phase.175/.35/.525で旧対照・現3枚・選別1案を各250発（計9件）、750中ヘソ60以上かつ各phaseで両対照非悪化、返却比非悪化、残球/滞留/LCD4区分0と全計数一致を要求。一般/OUT/最長無入賞・基礎賞球も開示し、副作用は採用保留。既知位相の比較で実機率や統計的独立性へ一般化しない。

未達ならこの有限組の結果を残して原因観測へ戻り、次案の根拠と比較範囲を提示する。結果後に合成・次善乗換え・目標緩和をしない。3枚維持と入賞性能達成は分けて判定する。
