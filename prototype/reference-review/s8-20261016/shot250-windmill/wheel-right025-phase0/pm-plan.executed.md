# S8追加承認：風車位置だけの実250発比較（第6組）

2026-10-16、ユーザーの「はい、風車も変えていいです」で、既存の釘だけの比較から風車位置の変更を今回に追加する範囲が承認されました。スプリント8・GitHub Issue23内で継続し、集約先release/0.3.0は維持します。[構造照合](S8_BOARD_RELATION_REVIEW.md)の読取りを根拠に、釘群→風車→道入口の相対関係を検証します。以前の風車固定は今回の位置だけの比較について更新し、他の固定条件は維持します。

## 目的と守る条件

目標は、変更後を3開始条件各実250発、合計750発でヘソ60回以上（平均20/250）とし、各条件でも同一版の変更前より減らさないことです。一般入賞/OUT/最長無ヘソも示し、未解決悪化があれば採用を保留します。逆戻り非悪化、残球・滞留・液晶侵入4区分0、全計数整合を求めます。

原図由来101釘の中心と属性を完全固定します。発射0.18・狙い位置・球半径1.8と既定表示・重力/反発・発射間隔・従来レール/壁・口20・既存皿・抽選/保留/賞球も固定します。通常連釘の隙間と追加皿の重なりという構造上の残件は隠さず、この位置比較と同時に球径や部材を変えません。

風車は原中心(64,476.5)から位置だけ変更し、腕長10、初期角0.28、初期角速度0、4腕、実腕接触半径1.3・反発0.3・トルク係数0.0005・角速度上限±7・減衰exp(−0.7h)を維持。metadata armRadius0.8と実接触半径1.3の既存差も今回修正しません。初期状態を揃えた後の自然な回転差は結果として記録します。内部座標は実測mmではありません。

元の釘群から風車へ入る位置と、風車右下の道1/2へ出る位置を一組として見ます。原配置で風車中心→道1は右8.5/下11.5、全回転包絡と釘軸の隙間は2.800（球径3.6より小さい、包絡はsolid円ではない）。位置変更がどの方向で入賞を増やすかは未特定です。

## 実装と試射の順序

1. 内部の風車位置指定を初期化時に描画と衝突へ共通に渡す。位置だけを後から物理へ書き換えない。旧釘比較の風車固定検査は緩めず、新専用比較が元101本と宣言した風車座標・その他の全固定属性を照合する。
2. 指定なしの既存factoryと時間固定/実発射固定の記録が変わらないことを旧版の短窓oracleで確認。不正位置/干渉拒否、位置以外の固定、観測非作用、実250停止と正確な終端、描画と接触の初期中心が共通であることを必要テストで確認する。これらを入賞性能の試射と混同しない。
3. 変更前をfresh開始条件0で実250発測り、PMが新しい版と分母/安全を確認する。その後、4案を上表順に各実250発。変更前に内容を示し、1実行ごとに実試射数/ヘソ数/基準との差/一般・安全をチャットへ報告する。複数案を無言でまとめて実行しない。
4. 実spawn250に達したstepで発射停止、45秒排出する。最大300秒で250未達なら実途中数と失敗を残す。要求250を実分母へ置換しない。1/120の実停止/終端と30Hz保存frameを区別し、全250球のshot/outcome/残球を照合する。
5. 安全/狙いを保ち変更前のヘソ数を上回る新1案だけを、最多→小移動距離→manifest順で選ぶ。別開始条件0.175/0.35/0.525でfresh変更前と選別案を各250発確認し、合計60以上・各条件変更前非悪化・安全/副作用でPMが採否判定する。これらのphaseは以前の別案で観測済みであり、統計的独立性や実機確率を保証しない。
6. 未達・不採用は本編の元位置を維持し、全4案と失敗を記録する。別案へ確認を乗り換えたり、目標を下げたりせず、この有限比較と入賞改善の達成を区別する。達成案だけを本編へ反映し現画面/通常・右打ち・停止復帰/必要回帰/最新CIと説明動画・PRレビューへ進む。

## 役割・証拠・終了

リードが位置指定/計測と関連テスト、デザイナーが風車上下と道入口の同倍率の表示/接触の対応、スクラムマスターが全計数/固定条件/採否を独立照合、PMが原図の関係からの判定と毎回の報告を行います。

試射前にsource/計画/manifest/HEADを凍結し、実行版・圧縮rawと両SHA・全実終点をshot250-windmill/へ保存します。旧5組のraw/ハッシュや失敗を変更せず、この新sourceの比較として記録します。測定中はコード・計画・HEADを変更せず、撮影/重いテストを並行しません。期間は固定せず、この4案と該当する確認・受入で区切ります。

動画は新結果の台本を人間が承認してからVOICEVOX（ずんだもんノーマル）/Remotionで作成し、実プレイ比較と全結果/未達も示します。新たな台本承認や公開許可を今回の風車変更承認に含めません。本番公開・mainマージは行いません。
