# 風車の上へ入る経路を、釘1本ずつで比べる

目的：風車に当たらず左へ落ちる玉を減らし、ヘソ入賞を増やす。開始済みスプリントの承認範囲。動画は改善が確認できるまで保留。

前回の風車左1.75は現在9→10/250、旧対照13未満で不採用。今回は風車を元の中心(64,476.5)に固定する。保存済み実軌跡では、風車手前y460を左へ通り風車に反発しない145球の直前反発釘に46（53球）、48（25球）が多かった。ただし途中の壁や他球の影響があり、釘1本だけを原因とは断定しない。

候補は元配置から独立に、46右0.5、48上0.5、48下0.5の3案。1単位を球11mm仮定から換算すると各約1.53mm相当で、実機の採寸値ではない。46は左寄りの低速反発位置、48は高速反射の高さと時刻の変化を調べる。方向の効果は未確定。前回の48左右0.5や風車移動とは組み合わせない。既定strict配置検査を維持し、上限解除を追加しない。

固定：元101本のうち対象以外100本・全属性、風車の3枚形状/中心/回転係数、球R1.8と表示、左上の狙い/power.18/間隔.6/gravity690、反発・抽選・賞球、外枠・レール・壁・口20、追加ガイドなし。元の旧風車対照も保存し、両対照を同じ源で再計測する。

試射順は旧対照、現在3枚、46右0.5、48上0.5、48下0.5。phase0各実250発、最大5件。250発のspawn-stepで停止し45秒排出、発射最大300秒。全ID・30Hz・実終点・固定入力・source/HEAD・gzip両SHAを保存。各変更の試射数、ヘソ、一般、OUT、安全、風車成功反発/道接触を報告する。試射中は重いテストや動画制作を並行しない。

選別：両対照よりヘソ数が厳密に多く、返却率非悪化、残球/滞留/液晶4区分0、全計数一致の案だけを候補にする。複数ならヘソ最多、同数なら移動総量最小、それも同じなら上記の宣言順で1案だけを選ぶ。その1案のみ未使用phase .175/.35/.525で両対照と各250発、最大9件確認。60/750以上、各条件で両対照のヘソ/返却率非悪化、安全全0を満たすまで採用しない。一般/OUT/最長無ヘソの副作用も判定する。初回250は確認750へ混ぜない。

選別不成立なら3案とも不採用として証拠を残し、結果後に閾値や方向を変えて追加試射しない。本編適用・公開は今回の試射と別の判定にする。

静的検査で不成立の案は理由を保存して試射せず、代替案は追加しない。対照側に安全異常や計数不一致があれば比較不成立として止める。一般入賞や最長無ヘソなどの副作用が未解決なら、数の選別を通っても採用は保留する。
