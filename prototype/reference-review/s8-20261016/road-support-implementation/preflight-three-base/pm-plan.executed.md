# S8：道釘の支持と通過を分ける限定試作

ユーザーのヘソ入賞増の継続・必要箇所の改善・改善後に動画化する方針に従う。3枚羽根を維持し、新しい人工ガイドは足さない。期間は下記1候補の選別・必要な確認・採否まで。

## 調べる問題

旧推定格子ツールに由来する中心距離4以上を内部位置比較へ継承し、動かした釘を含む全pairへ適用していた。球D3.6/軸r.2では軸間に球が通る幅を一律要求し、道釘が球を支えるための隙間まで試せなかった。釘同士の重複とは別の条件であり、原図の道と機能から採寸した根拠ではない。旧試射とguardを当時の記録として保持し、結果を見て過去の不成立を成功へ書き換えない。

ID2右.5の場合、2/3中心距離hypot(3.25,2)=3.816084、軸間3.416084は球D3.6より.183916狭い。一方、軸直径.4・可視Sprite枠幅14×.52/3=2.426667は重ならない。原図の連釘で球を支えて道へ渡す仮説として妥当とLead/Designerが読取確認した。上を通る保証ではなく谷への滞留/交互補正のリスクがあるため、動的排出と受渡しを必須にする。内部値で実測mmではない。

## 有限3設定

1. `legacy-control`：元101点、旧風車の性能参照。
2. `three-base`：元101点、3枚羽根・現在の基準。
3. `three-road2-support050`：3枚羽根、元位置から道釘2だけ右.5、pair2/3だけ球通過幅条件の例外。

候補の例外は明示的な専用内部resolver/設定で、上記1候補・pair2/3・実2釘role=michiに限定する。全域4の引下げ、旧比較からの例外流入、他pair/右入口/ヘソの狭小化、追加case/合成はしない。釘の軸非重複・可視頭非重複と固定物/開口/風車/他pairの全guardは維持する。既存resolverの無指定既定と旧比較の許可条件は維持する。

球半径1.8/既定表示、3羽根の形・中心/既定係数、左上狙い、元101本と全属性、発射.18/間隔.6、gravity690、legacyレール/壁・口20、ガイドなし、抽選/賞球を固定。表示/接触を意図的にずらしたり、力で支持したりしない。

## 実装・試射と判定

小さい関連testで旧guard不変・例外漏れ拒否・指定pairの軸/頭検証・元101指定差と全fixed/frame/計数を確認。旧基準の初期と短い全JSON/events/replayの互換を確認する。3静的preflight後に新plan/manifest/全input/HEADを凍結し、3設定をphase0 fresh各実250発、250spawn step停止＋45排出・最大300秒で測る。毎回の実試射/ヘソ/両対照との差/一般/OUT/返却/残球/滞留/LCD・道1〜3接触/その後経路を報告する。残球を消して成功にしない。測定中source/Git/plan/cases変更・撮影・重testなし。

候補が両対照ヘソを厳密に超え、安全/狙い成立の場合だけ、phase.175/.35/.525で旧/現3枚/候補をfresh各250（計9件）確認。750中ヘソ60以上・各phase両対照ヘソ非悪化/返却比非悪化・全残球/滞留/LCD4区分0・全計数一致を維持する。一般/OUT/最大無ヘソ・基礎賞球も開示し、未解決副作用は採用保留。既知phaseで実機率/独立性を保証しない。

未達ならこの1案を確定し、支持/滞留/反射の実証から次案の根拠と有限範囲を示す。結果後に釘3の移動や風車移動を合成しない。検査の意味の訂正、物理の成立、入賞目標の達成を別判定とする。
