# S8継続：3枚風車から道釘への受け渡し

目的：3枚羽根を保ち、必要箇所を改善して入賞を増やす最新承認内で続行する。ヘソ直前の単釘3案は上9・右9・入口左8/各250（3枚基準9）で改善なし、球R2.0は右RUSH滞留で不採用。失敗は別記録に保全した。期間はこの有限組の比較と採否まで、固定週数なし。

根拠：新3枚基準では風車の成功接触70球、旧形状124球。新3枚で接触した70球はヘソ6/一般3/OUT61、未接触180球はヘソ3/一般1/OUT176。道入口の2本目は14球が接触した（旧3球）。後段だけでなく供給と受け渡しを比較する。過去の風車4方向は旧4枚・ガイドありなので今回の3枚・ガイドなしを測った成績へ流用しない。接触増加が入賞増を保証するとは扱わない。

## 選別・受入・次

両対照をヘソで厳密に上回り安全と狙いが成立した新案だけ選別する。最多ヘソ、同率は表の記載順で1案に固定。選別1案をphase.175/.35/.525で旧風車対照・現3枚基準と各250発比較（計9件）。750発中ヘソ60以上・各phaseで両対照ヘソ非悪化・返却比非悪化、残球/滞留/LCD4区分0、全計数一致を要求する。一般/OUT/最長無入賞・基礎賞球も開示し副作用があれば採用保留。既知位相であり実機率や独立統計試験へ一般化しない。

有望なし/確認未達ならこの組を確定して原因観測へ戻り、根拠と次の有限範囲を提示する。結果後の合成/次善乗換え/目標緩和なし。3枚維持と性能目標は分けて判定する。
