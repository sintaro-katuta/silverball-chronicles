# 水面を維持して雲を追加
- 動画: lcd.mp4（24秒、通常液晶実録画、音声なし）
- 雲素材: ../../public/assets/lcd/cloud-sky-v1.png
- プロンプト: ../../public/assets/lcd/cloud-sky-v1.prompt.txt
- 実装: ../../src/pixi/cloud-idle.js
- 雲の速度: 1.5秒に1ドット、右方向。端は鏡像接続。
- 人物・剣・月・城を固定。水面は採用済み6秒周期・1ドット振幅。
- 7時点の合成で空マスク外の変化0、水面への雲の影響0。停止画像一致、ページエラーなし、build成功。
- 録画から連続6フレームを抽出して目視確認。雲素材は隠れた部分を補完したため、元絵と雲の配置・細部に差がある。前景周囲の細部は固定。採用は未確定。

## 長時間ループの追加確認
雲は鏡像接続した420画素を1.5秒/画素で進むため、1周期630秒（10分30秒）。鏡像との継ぎ目315秒、周回630秒、2周1260秒の前後を実描画で比較。各境界で通常の1画素右移動との不一致0（比較21768画素）、0秒と1260秒の画像差0。
loop-boundary.mp4は実装の背景描画関数を使用し、時計を624秒から始めて12秒録画した境界確認用動画。10分間を実時間で連続プレイした録画ではない。固定レイヤーのマスク端は比較対象から除外し、同じ空領域内の連続性を確認。
