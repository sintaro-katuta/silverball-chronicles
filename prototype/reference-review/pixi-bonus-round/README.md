# 右打ちとラウンドの連動

lcd-bonus.html の実入賞による確認録画。通常強度0.23→2回目に固定当たり→777→右打ち案内→確認用自動操作で右強度0.6→アタッカー開放。

1Rは10入賞または開き切ってから15秒で終了。1玉15玉払い出し、1R10入賞150玉。扉が0.5秒で閉じ、完全閉鎖後0.65秒待機して2Rを開く。ラウンド間には入賞判定を閉じ、10個目で即座に受入停止する。

動画は1Rの完全閉鎖と2Rで2玉入ったところまで。最後に一時停止し、その時点の玉・表示・扉が凍結することを確認。verification.jsonに閉鎖時と最終状態・ラウンド履歴を保存。未回収の玉が残る一時停止であり、全玉排出動画ではない。

払出表示は賞球合計、差玉ではない。既存Gameの入賞計算とラウンド処理を使用し、旧ステージ進行・チケット・保存をこの確認アダプターでは無効化。電チュー閉鎖。音・戦闘・RUSH自動連動・本編保存の接続は未実装。
