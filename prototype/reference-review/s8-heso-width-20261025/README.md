計測時基準 a95cccb、18/16を許可する入口幅検証だけを追加して凍結。正式 runs は11件2750発。幅20 132/750（17.60%）、18 125/750（16.67%）、16 116/750（15.47%）。幅16を選別、別位相52→41/250で確認後、本編profileを16に変更。

[計画・結果・限度](../../../docs/agile/S8_HESO_WIDTH.md)。runs/plan.jsonは事前条件、manifest.jsonは比較中の12ソースとrunnerのSHA、progress.jsonは最終結果。導入後に本編profileを変更したので、比較の前後一致を導入後のソース固定とは呼ばない。

preflight-stage-key-invalid は記録キー重複で中断した試走。正式比較と採否から全件除外し、正しい記録形式で全条件を最初から測り直した。
