# 右通過ゲート・実働確認

動画は全体約4秒→右側拡大。両方閉鎖／電チュー開放／アタッカー開放／両方閉鎖を各10秒、その後発射を止めて排出する。開閉は確認用の操作でゲート抽選ではない。

ゲートは液晶右側の金色の左右センサー。上下に抜ける通路を既存ガイドへ取り付け、通過時に青い灯りが0.18秒点灯する。ゲートの計数は入賞計数とは別で、通過した玉は下流へ進む。下向きの通過を玉ごとに一度だけ数える。

14テスト合格。0.6秒と0.05秒間隔の右打ち3条件でゲート有無の玉状態・入賞数が同一。停止後残留0、発射と回収の計数一致。見逃し・重複・上向き・予測計算を単体確認。高速通常打ち0.025秒の既知残留問題は本変更の対象外。

verification.jsonは録画時の実測。gate.countは通過数で、countsへ加算して保存則を計算しない。
