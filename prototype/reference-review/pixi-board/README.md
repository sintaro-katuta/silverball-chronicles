# 確定部品の盤面統合

board-pixi.htmlで共通銀玉、釘、風車2基、中央始動口、通常入賞口3か所、電チュー、アタッカー、ネジ付き樹脂ガイド、OUT口を同時表示。各素材を盤面座標に置き、単独試作と同じ玉に対する比率で表示する。発射計算は従来通り、機構は描画せず固定開口で隠す。

個別試作はそのまま保存。AttackerView / RightStartViewを再利用し、通常の玉とガイドは統合側の共通レイヤーから描く。取込みは各部品の確定済み表示を維持。OUT口の手前の縁は玉より前に描画する。

## 統合で調整した箇所

電チューとアタッカーは同じright-inner-lowerガイドに異なる座標を指定していた。統合専用board-flow.jsは上端(336,468)→下端(330,558)へ統一。電チューの入口(359.5,493)、アタッカーのpocket.x357.25/y581と下辺固定の扉は維持。ガイドは電チュー側の上端幅とアタッカー側の下端中央配置をつなぐ案。右外側のネジは通路外へ配置。
