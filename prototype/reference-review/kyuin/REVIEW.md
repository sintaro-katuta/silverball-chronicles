# キュイン合成の参照

提供動画：Synth レシピ ㉙ パチンコ・パチスロの効果音 キュインサウンド《Massive 使い方》（Sleepfreaks DTMスクール） [Fai-uNteibs].mp4
長さ：430.954秒。
確認範囲：20秒間隔の22画面、240・300・360秒付近の拡大画面、終盤の音声スペクトログラム。音声を全文書き起こししたものではなく、聴感一致も未検証。

画面で確認した構成：Squ-Swl波形、Lowpass 4、C Tube、Dim Exp。240秒付近に「1EnvをOSC1のPitchに適用する」。300秒付近にOSC1 PitchへのEnv1/Env2の割当（49.00、23.00）と上昇時間の調整。360秒付近にAMP（4 Env）の微調整。

反映：Web Audioの独自合成で、速い音程上昇＋遅い上昇と減衰を重ね、ローパス・共鳴・ソフト歪み・短い遅延を適用。Massiveプリセットを完全再現するものではない。大当り確定時の冒頭に鳴らし、通常の赤リーチとは区別。既存の祝福和音を後ろへずらして告知音を目立たせる。

試遊サポートに「キュイン音を試す」を追加。元動画／抽出音声はアプリに同梱せず、すべてローカル生成。

検証：全20効果音をChrome OfflineAudioContextで合成。キュインpeak 0.244、大当りpeak 0.349（フルスケール1.0）で単独再生のクリッピングなし。実機スピーカーの聴感確認は未実施。
