# 下部操作部の曲面モデル制作

2026-09-26。「今できる最大のモデリング」依頼の下部操作部担当。実機の測量モデルではなく、R1および商品正面写真を基準にした専用形状の制作。実寸・製造金型形状の一致は未検証。

## 観察した資料

- `2026-09-25/cabinet.webp`：白い非対称下部、左スピーカー、中央の突出した黒いPUSH台座、右の横軸グリップ、横長の黒い前縁。
- R3 `CABINET_BRIEF.md`：R3初期資料は液晶・盤面中心で下皿／ハンドルの細部と背面が不足する。寸法を確定した扱いにはしない。
- R3 `fair-after-oblique.png`：現行FAIR前面と下部の位置関係。FAIRを変更せず、別の下部操作部として置く。
- 既存`YozoraBuilder.BuildHousing`と`ReferenceCabinetBuilder.LowerApron`：旧下皿は平板、PUSHはほぼ正面向きの円盤、ハンドルは一定半径の円筒と確認。

## 実装

新規 `Editor/PremiumControlsBuilder.cs` の `Build(Transform cabinet, YozoraMachine machine)` で生成する。rootが全体生成の最後へ接続する。既存ソースにはこの担当から変更していない。

|部品|制作した形状|
|---|---|
|深皿|128点の角丸断面を外底→外壁→丸縁→内壁→底へ連続ロフト。皿の開口と凹んだ内側が存在する。内底の細い成形リブ、巻き込む黒い前縁、細いニッケルの縁|
|白いエプロン|左上が高く右へ下がる非対称輪郭。72×20の曲面パッチと側面の厚み。上端の細い金属継ぎ目と下端の丸いシーム|
|PUSH台座|7段×96点の輪郭を繋いだ、中央が膨らみ上へ絞られる黒い曲面。上面を閉じ、下のグラファイト継ぎ目を独立|
|PUSH操作面|斜め上へ向けた金属冠、丸い肩、紫の細い透過帯、内側のサテン面、厚みのある透明ドーム。冠側面の48個の細いローレット。印字も面の傾きへ合わせる|
|ハンドル|横軸。半径が変わる128分割のゴムグリップ、曲率に沿う20本の縦フルート、両端の磨いた押さえ輪、膨らんだ白いキャップ、中央メダリオンと軸、内側支持部|
|スピーカー|黒い後退した空間と白い穴周囲。細い長孔に内壁を作り、黒点を白板に貼るだけの構成を避ける|

メッシュは共有頂点で法線を再計算し、皿・pod・回転断面の表裏を確認。スピーカー孔の内壁と背面暗部の面方向を修正した。PUSH印字は白い円盤に浮かぶ旧文字を無効にし、新しい傾斜面の上に配置する。

## 置換・保全

- 旧名：Lower pearl apron / Tray cavity / Tray rim / Control island / PUSH surround / PUSH frosted button / PUSH purple rim / Horizontal ribbed handle / Apron grille。
- 名前が一致してもColliderを持つオブジェクトは削除せず、警告して保持する。
- main筐体担当は`ReferenceCabinetBuilder.LowerApron()`呼出を停止。旧下部の削除は維持し、複合バッチへ旧下部が二重に残らないよう連携済み。
- 新モデルにはCollider、センサー、Rigidbody、Light、ReflectionProbeを追加しない。Rules、玉材質、全体照明、FAIR、玉通路を変更しない。
- 新しい金属／ゴム／白／レンズの材質はこの下部専用。既存材質を上書きしない。
- PUSH上端は概ねy0.245以下、ハンドルはy0.20以下。液晶面を覆わないよう設計しているが、最終画像での確認が必要。

## 統合画像で確認する点

- 正面：白い左上が高いシルエット、黒いpodと皿の分離、PUSHの文字と透明レンズ、操作部がFAIR／液晶を塞がないこと。
- 斜め：凹んだ皿の内壁と底、白い外装の厚み、podの膨らみ、ハンドルの手で握る曲面、スピーカー孔の奥行き。
- 既存レンズと新レンズの透明描画順、暗い環境で黒い曲面が潰れないこと、穴面の裏返り、PUSH印字の重なり。

現時点はコードと静的検査まで。rootの実描画画像を受け取り、造形／材質を再調整してから視認結果を追記する。過去の画像を今回モデルの検証済み画像として扱わない。

## 初回実描画後の修正

root生成の `maximum-model-2026-09-26/after-controls.png` と `after-oblique.png`（21:32時点）を視認。グリップの曲面・溝、黒いpod、皿の奥行きは初回モデルで識別できた。一方、白いエプロンとPUSH面が白飛びし、別メッシュのスピーカー穴周囲が表面から突き出た金属片のように見えた。

- 白い専用材質の反射率を下げ、金属度・滑らかさも抑制。レンズの色・透明度を調整。全体ライトと玉材質は変更しない。
- 旧スピーカー独立面を撤去。エプロンの曲面セル自体に長孔を作り、3.5mmの孔内壁と4mm奥の暗部を追加。白板の前に孔の列を浮かせない構成へ改めた。
- エプロン縦分割を20→30へ増加し、孔も曲面に従わせる。

初回画像の問題を修正した後の静的コンパイルはexit0。最終反映画像で白飛び低減と孔の凹みを再確認する必要がある。

### 21:38画像の再確認と最終ソース境界

更新された`after-controls.png`を視認。エプロンの白飛びが抑えられ、PUSHにレンズの反射と面の階調が見える。グリップの曲面とリブ、黒い皿／podの形も保持された。
