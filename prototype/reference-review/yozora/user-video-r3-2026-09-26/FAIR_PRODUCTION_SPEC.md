## 固定する機構と制作の境界

- 主回転体中心は現行(.012,.288,-.112)、Y軸、回転速度32deg/sを維持。
- 6ポケット中心半径.03、2当り、SphereCollider半径.0075・localY=.005を維持。
- 選別部(-.18,.366,-.052)、BoxCollider(.09,.014,.035)、5玉振分、ガイド終点/経路/速度、レイヤー11を変更しない。
- 玉Prefab/材質、全体のライト/Cubemap、発射値、抽選、Rules、表示の先行Sprint A/B/Cを変更しない。
- 装飾メッシュはColliderを持たない。既存機構に対して外装が狭く見える等の干渉が見つかった場合は報告し、無断で玉経路を移動しない。
- 全て上記の既存Unity寸法系に合わせる推定値。実機の実測寸法ではない。

## 比較・検証計画

1. 変更前をrootが保存。FAIRのケース幅と回転軸の見え方をR3へ近づけた同じカメラを以降固定する。
2. 変更後を同じカメラ/照明/解像度/表示サイズで保存。ケース中心・開口・左接合・支持板・ねじ・内部が識別できるか比較する。
3. 参照の透視とUnityの一致が未確定な間は、画素差率や『99%』等を合格値にしない。位置の差をカメラ/輪郭/材質に分けて記録する。
4. 消灯寄りの材質と通常発光を確認。ただし全体ライトは変更しない。発光別meshの材質で比較できるようにする。
5. Unity再生成・ビルドはrootと調整後。現時点は変更前の仕様段階で、今回の造形の見た目・Web挙動を確認済みとはしない。
