# 筐体の造形と発光・役物の制作方針

2026-09-26 ユーザー要望：「ギラギラした、楽しませる演出を感じられるパチンコのモデルを作りたい」。SAO夜空の形状照合は継続し、架空台への変更指示とは解釈しない。以下はその要望を具体化する制作案。実装済みとは扱わない。

## 到達したい外観

筐体自身が期待感を作る現代パチンコ。メッキの反射、多面レンズ内部の光、重なる透明成形部品、厚みのあるロゴ、物理的に前後へ動く役物が液晶と連動する。現在の玉の質感を維持する。

## 部品の構造

- 銀/金のメッキ：輪郭を変える面取り・曲面を持つ専用形状。広い単色板のまま色だけ変えない。
- 発光レンズ：前面カット、透明な厚み、内部拡散面、奥の発光源、非発光の区切りを分離。全表面を同じ明るさで塗らない。
- 透明ケース：広い面は内部が見え、縁と曲面に細い反射。玉と通路が見える空間を確保。
- 装飾文字/ロゴ：正面・金属縁・側面・奥の影を分離し、斜めで厚みが読める。
- 可動役物：待機位置・可動範囲・見せ場・復帰位置を定義。SAO参照で未確認の動作を実機仕様として追加しない。

## 同じ筐体の三状態を先に見せる

|状態|筐体側の提案|見るべきこと|
|---|---|---|
|通常|メッキの反射と局所的なレンズ点灯。液晶・図柄・玉が読める|消灯部分にも形と材質があるか|
|期待が高まる場面|左右や下部から主役へ点灯を移し、対象役物を準備位置へ|どこに注目するか分かるか|
|決着・当り|短い溜めから役物の到達、液晶の決着、枠の発光と効果音を同じイベントで合わせる|一瞬の最大演出と、その後に結果を読ませる保持があるか|

色・動作・音の正確な順序は参照動画の連続解析で確定。上の表は制作方針であり実機観測値ではない。抽選・入賞率・総払出は変更しない。

## 制作と検収

1. FAIRのルーレット案を入口として、残る通路接合と樹脂の見え方を解決する。
2. 同じ視点で通常/期待/当りの3状態を作り、造形と光の組合せを確認する。初期の検討画像をUnityの実装結果と混同しない。
3. 筐体外枠・上部装飾・剣/ロゴ役物へ展開。基本形状を先に比較し、部品の微細な追加だけで完成としない。
4. 静止画で輪郭/材質、連続再生で点灯順/役物/音の同期を検証。Webと接写を両方確認する。

次の提示物は同一筐体の三状態比較と短い動作試演。参考にする外部資料は実在筐体の精密モデル/制作事例。単純な玉落としゲームを外観のお手本にはしない。ローカルのみで制作する。
