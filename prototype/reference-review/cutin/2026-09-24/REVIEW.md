## 観察と修正

| 変更前の観察 | 修正 |
| --- | --- |
| 月光覚醒の大文字が目元を覆う | 文字をLCD下側57%へ移し、顔→文字の順に提示 |
| 広い光沢と覚醒エフェクトが肖像の上に重なる | 広域光を肖像より奥へ。光沢は枠の縁だけに限定 |
| 帯・暗幕・紋章が異なる状態のまま次のカットへ切り替わる | 登場・保持・退出の共通進行で透過。暗幕も退出に合わせて収束 |
| 登場中の役物が顔を横断する | 覚醒・復活カット中は役物を下部の到達位置へ配置 |
| 台詞と役物が競合する | 台詞を顔の下、演出文字の上へ。背景帯を薄くする |
| 動きを減らす設定でも帯・紋章が高速移動する | カットイン内の移動・回転・走査を固定しフェードで提示 |

2.5秒の独自タイムライン：0–0.15秒は背景減光、0.15–0.45秒で帯を導入、0.45–0.70秒で文字と台詞を提示、2.10秒まで保持、2.10–2.50秒で帯・文字・暗幕を退出。音キューは既存の覚醒開始のまま。画像は既存のオリジナル背景込み肖像を再利用する。

適用範囲：覚醒・月光収束・復活の共通カットイン。敗北／復活前にはカットインを出さない。演出尺・抽選・出玉は変更しない。一般画面の配置規則としては扱わない。
