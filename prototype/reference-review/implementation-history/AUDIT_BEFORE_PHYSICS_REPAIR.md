## 採用基準

ユーザー確定：1/199前後・4R/6R/10Rを軸とする架空機種。実在する一機種の完全移植ではなく、盤面と遊技の仕組みを可能な限り実機に寄せる。架空作品の世界観は維持する。

通常確率と始動入賞率は別の値。4R/6R/10Rは大当りの種類であり、少ない賞球を「小当り」「中当り」と呼ばない。通常時・右打ち中の抽選方式、保留、賞球、ラウンド、継続方式を機種単位で整合させる。参考機種の継続率だけを切り取って別方式に適用しない。

現在の暫定値は通常確率1/199・1/229・1/259、4R/6R/10Rの振り分け45/35/20%、10カウント、基礎賞球は始動口2・一般入賞口4・アタッカー15。これは試作用の組み合わせであり、特定実機のスペックを再現した値ではない。強化前・倍率前の規定カウント分の払い出しは600/900/1500玉。発射消費を引いた純増ではない。

## ゲーム独自として整理する領域

| 分類 | 維持する決定事項 |
| --- | --- |
| 進行 | 通常10ステージ、目標の累計獲得出玉、超過進捗と持ち玉の持ち越し、大当り状態の引き継ぎ、コース解放・難易度 |
| 強化 | ラン内スキル、プレイヤーに付与する永続強化、追加発射・玉の分裂・特殊玉・追加抽選・確率補正・賞球増加。実機の標準動作とは別の効果として記録する |
| 報酬 | チケットと強化への使用、敗北時にも出玉に応じて獲得、リタイア時0枚。機種の賞球表とゲーム報酬を混同しない |
| 天井救済 | 消化回転数に応じた大当り保証。可変・非常に深い救済として維持。現在1990/2290/2590回は暫定。実機の遊タイムと同一仕様ではない |
| 操作・停止 | オート発射・調整、手動操作、一時停止とスキル選択中の停止。操作支援と台の物理仕様を分ける |
| 敗北 | 持ち玉0が3秒継続。盤面に玉や保留が残る可能性を含め、実機ではなくゲームの終了条件 |
| 無限モード | 好きな機種でステージ無限、チケットなし・永続強化なし。天井やラン内スキル等もあるため、実機そのままのモードとは呼ばない |
| 計測 | 持ち玉・大当り後回転数・累計回転数・差玉グラフ。現グラフは開始時からの持ち玉増減なので、スキル補給も含むゲーム収支である |

## 既決要望と実機再現の差

これらは勝手に削除せず、既決のゲーム側の例外として扱う。

- **保留5個＋変動中1回**：ユーザー指定の容量。参考実機の容量を再現したものではない。複数の始動口・特図を導入する際はそれぞれの保留と消化順を設計する必要がある。
- **大当り途中のR上乗せ**：現在は最終ラウンドの途中で抽選し、同じ大当りの総Rを繰り返し増やすゲーム独自方式。実機で複数の大当りをまとめて出玉上乗せに見せる方式とは内部処理が違う。「＋R」の見せ方を残しつつ内部を複数大当りに分ける案は今後の改修候補で、採用済みではない。
- **液晶・枠に衝突判定なし、液晶手前に釘**：玉が枠上に止まる不具合を避けるための既決要望。センター役物の外周を回る実機風の盤面に変える場合、この要望との整合を確認する。衝突しない表示面と、玉を誘導する物理部材を区別して設計する。

## 改修の順序と確認条件

1. 盤面：入賞口・アウト口・通路・釘を機種ごとに設計し、玉が止まらない、壁を抜けない、見えない場所で入賞しないことを確認する。
2. 右打ち：固定経路による誘導を維持し、表示する通路と動きを一致させ、開放中・閉鎖中・ラウンド間の流れと入賞を確認する。実機らしい入賞しやすさと、無条件の全玉入賞保証を区別する。
3. 遊技状態：抽選情報・保留・変動・大当りを分離し、基礎スペックとゲーム補正を個別に追えるようにする。
4. 継続方式：R上乗せの既決体験を維持するゲーム方式と、実機に寄せた内部方式の差を解消する設計を具体化する。ST等を無断で新規採用しない。

効果音はユーザー指定により今回の整理・改修対象から外す。
