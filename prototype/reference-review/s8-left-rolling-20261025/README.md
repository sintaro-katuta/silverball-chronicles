# 左打ちの入口と道釘の修正（2026-10-25）

採用候補は `final-250-*` と `final-heldout-100`。道釘26本の接触を、同じ釘頭の主面半径1.04へ校正し、左の前面釘に受動的な回転摩擦0.5を適用。玉半径3・釘101中心・道釘反発0.12・発射を維持。

`before-100` は同じソース上で旧軸半径0.2・回転摩擦なし・入口の補作壁3区間を復元した変更前比較。歴史的な別runを今回の同時対照へ流用したものではない。

`head-confirm-400` は本編へ組み込む前の明示設定による4開始条件各100玉。`trials/` と `experimental/` は不採用の候補と、比較で使用したコード。最終コードには速度依存反発・接線反発・粗面角度分岐・停止時分岐を持ち込んでいない。

参照した粗い球の接触モデルの一次資料：https://arxiv.org/abs/2106.01276 。この資料の実験係数や実機再現を主張するものではなく、並進/回転のエネルギーと接触モデルの比較の参照。採用した処理はクーロン上限付きの並進/回転結合のみで、接触時に両者の合計エネルギーを増やさないことをテストした。

詳しい範囲・採用理由・残件は `docs/agile/S8_LEFT_ZONE_DISCUSSION.md`。描画確認と静止画はこのフォルダへ保存。
