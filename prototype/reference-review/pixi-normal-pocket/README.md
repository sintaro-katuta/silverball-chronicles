# 通常入賞口のPixiJS試作

中央始動口v3を基準に内蔵画像生成で作成。星飾りを外し、正面を金の紋章にして識別。太い金縁、青い器、共通28px銀玉、描画解像度1を維持。

左下の既存通常入賞口 (67,617)、幅19、id0を表示。左打ちパワー0.5で30秒発射、5秒排出。通常入賞のうち、この入口に入った玉だけを0.26秒で奥へ縮小・消失。前縁で取込み玉を隠す。3か所すべての入賞数とこの口の取込み数は分けて記録。

抽選・賞球・保存を接続しない機構確認用の独立試作。物理・入口位置や幅の変更なし。
