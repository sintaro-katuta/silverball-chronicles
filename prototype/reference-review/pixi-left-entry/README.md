# 左打ち・入口視認性と経路集計

物理配置は維持。最初3本を風車側へ寄せる案は比較結果が悪化したため不採用（comparison.json）。動画は強度0.23→0.24→0.25を拡大し、発射停止後に排出。強度別は発射時のpowerで所属を固定しており、切替後に入賞しても元の強度に入る。

近傍到達：ヘソ中心左右25、上40から入口より玉半径下までの領域へ一度でも到達。
命釘接触・非入賞：命釘接触記録があり、近傍到達し、最終的にヘソ入賞ではない。命釘が外れた原因と断定する指標ではない。
接触なし・非入賞：近傍到達したが命釘接触記録がなくヘソに入らなかった。nearMissOutcomesに以降の入賞/OUTを分類。
到達 = nearAdmitted + deflectedAtHeso + nearMiss + nearPending。
道釘途中落ち：道釘経路接触があり、近傍に届かず回収済み。

入賞数と経路分類は別の観測軸で、全項目を足して発射数と比較しない。強度別trackedは経路に触れていない玉も含む。未回収玉は結果未確定。
