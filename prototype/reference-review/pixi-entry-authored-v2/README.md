# 専用ドット絵によるRUSH突入告知 v2

6案とも専用の6カットを新規生成。前版の通常背景切り抜き・紅い月への着色・線描画による代用を撤去した。紅い月は2番の月案だけ。

1. 通常復帰からの復活：リザルト→左打ち→通常画面→再暗転→銀髪騎士の覚醒
2. 蒼い月が紅く染まる：接近→亀裂→圧縮→紅い光の解放
3. 水面の奔流：微光→水紋→収束→静止→青白い水柱
4. 城が目覚める：窓→塔→門の光が増し、閉じた門の前で溜めて開放
5. 蒼白の抜刀：構え→剣の集光→溜め→一閃
6. 月蝕機関の解放：機関の起動→ロック→圧縮→開放。盤面の月蝕役物と連動

専用カットは各8秒。復活のみ偽の通常復帰を含め14.05秒。その後は確定済みのRUSHタイトルと右打ち案内に接続する。全フレーム作画のアニメーションではなく、新規作画6カットの切り替えと控えめなカメラ移動による構成。

検証：Chrome上で各案を録画。告知中の残り100回転・抽選0回・通常払出900玉・ブラウザ例外なしを自動確認。関連6テスト、production build成功。SEなし。
