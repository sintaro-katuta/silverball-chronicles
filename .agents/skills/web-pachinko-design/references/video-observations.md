# 動画の観察記録

確認日：2026-09-24。以下はフレーム観察。音声を聴いた評価や全編の実時間視聴とは区別する。画像・動画はゲーム配布素材として追加していない。

## V1：マトリックスの流線・ロゴ制作例

[動画](https://www.youtube.com/watch?v=gcLYACZkOLM)／[解説本文](https://zenn.dev/matrixsoftware/articles/e0e87abd1d8ef3)

今回9秒のvideo-only映像を取得。4fpsで0.25秒ごとの計36フレームを抽出し、全フレームをコンタクトシートで確認。音声なし。記事ではAI生成キャラクターを使用したと説明。

観察：青い流線・破片の中にキャラクター、その手前に赤を含む立体的なCHANCE文字。文字の白い縁で輪郭が分かれ、拡縮・傾き・前景の斜線・像の乱れが変化する。短い構成が繰り返される。

解釈と翻案：前後の層と主役の輪郭が重要。月影機関では技名・人物・流線の役割を分ける。青い背景や赤い英字をそのまま採用する意味ではない。0.25秒より短い動き、正確なイージング、音との同期はこの観察では判定できない。

一時取得物は `/private/tmp/silverball-design-research/` に置いて検討した。再調査はURLから行う。スキルは一時ファイルに依存しない。

## V2：GODZILLA7 超震撼ver. 実戦

[動画](https://www.youtube.com/watch?v=wNSCu4J0ydk)

既存資料：プロジェクトルートの `prototype/reference-review/godzilla7/REVIEW.md` と `battle-sheet-0.jpg`。今回確認はシートの約9:00〜9:55、5秒間隔12画面。全編視聴ではない。

観察：図柄から赤い警告へ変化し、物理役物の映像を挟み、VS表示・敵紹介・対決へ移る。対決中は図柄が上部に小さく残り、怪獣の全景や顔、攻撃が主役になる。

翻案：発展に合わせて情報の優先度を切り替える。液晶だけでなく装飾役物との連動も検討する。ただし、この機種の物理V抽選は現行ゲームに移植しない。編集者の字幕・カメラの寄りを液晶自体の演出に数えない。

## V3：炎炎ノ消防隊2 99ver. 実戦

[動画](https://www.youtube.com/watch?v=HgLC_yDGGp4)

既存資料：`prototype/reference-review/fireforce99/REVIEW.md` と `sheet-1.jpg`。今回確認は約1020〜1860秒、120秒間隔8画面。

観察：大きな777、異なる色・背景のRUSH画面、残回数、獲得数、図柄の大小の違いが見える。配信者の立ち絵・字幕・右側情報は映像に重なっている。

翻案：通常・RUSH・BONUSの差を、ラベルだけでなく画面の主役と構成で示す。撮影・編集と機械表示を分ける。この間隔では変動速度、音のタイミング、平均演出尺は測れない。

## V4：AEカットイン制作

[動画](https://www.youtube.com/watch?v=yVKYavHOfmY)

既存資料：`prototype/reference-review/cutin/REVIEW.md` と `frame-1-30s.jpg`。今回の画像確認は30秒付近のみ。別時刻の観察は既存レビューに記載された過去の作業であり、今回実施したと扱わない。
