# 試聴から残す判断

この文書は2026-10-16、セッションのユーザー発言と残った記録から再構成した。過去の録音ファイル自体の復元や、新たな聴感合格を意味しない。

## 制作の目的と好評だった方向

目的はゲーム内で使えるオリジナル効果音。既存演出の再現は工程と音の特徴を理解する実験だった。機能や手法の数を増やすことを品質向上と呼ばない。

ユニコーン再現ではCの共通パルス／鋸波音色がBのFM方式より好まれた。Bも選択肢として残す。共通シンセを全体に使い、音程・一定音程の保持・音色の一体感を重視する。これを全用途への単一プリセット強制にしない。

オリジナル「月光開放」の2声ハーモニーは好評で、低いハーモニー版が確定した。同じ音型を3回反復する案や40〜68 msの過度に細かい動きは好まれず、変化のある展開へ戻した。追加バリエーションの差が小さく、前の低いハーモニー版が選ばれた。

## 追加版の不採用

- 録音ドラム版：VCSLの録音を重ねたが、ユーザーは「ドラムが邪魔」「違う」と評価した。この組合せの不採用で、ドラムや実音全般の禁止ではない。
- シンセベース版：2声へ低音5音を加えたが、「音楽としては良いが、ゲーム効果音ではベースが邪魔」と評価された。ゲーム内の役割と音楽的な厚さを分けて判断する。基準の2声へ戻す。
- 最後のフォール：ユーザーは緩やかに・落ち先を高めにと指示した。基準の最後は指定音程が一定で音量が減衰する設定だったため、音程と音量のどちらかを確認し、暫定で音量の余韻を0.4秒延ばした6.4秒版を作った。この試作は未採用。音程の下降を修正した成功例にしない。聴こえの表現を設定だけで否定せず、対象区間と意味を揃える。

## 東京喰種の3ファイル

提供MP3の再現初稿では合成ノイズが不評。ノイズを減らし、倍音と音量の時間変化を調整した。音量の差は3例で縮小したが、03の帯域スペクトル差は悪化した。全体の再現改善とは扱わない。音程線が近くても、複雑な響き・倍音・発音・減衰が違えば一致とはいえない。

## 比較と報告

比較ページは参照音と最新候補の2音だけ。古い候補は内部に保持し、ファイル名と版を明示する。音量・尺・切出し・時間位置を揃える。単にRMS図を追わせたり、pYINのvalidやprobabilityを増やすことを改善目標にしない。

未推定F0は欠測。ノイズ・複数音・探索範囲の影響を調べる。共同有効区間だけの音程誤差と比較可能率を示し、全体の類似度へ読み替えない。スペクトログラムを共通尺度で並べ、音量の時間変化も比較する。Hz・倍音の明るさ・音量を区別する。

解析・ブラウザの終了イベント・耳での確認・ユーザー試聴・ゲーム内受入を別の状態で記録する。ブラウザ保存の自動確認が長時間止まる環境では、同じ操作を繰り返して制作を止めず、直接ファイルのデコードとHTTP配信を確認し、保存操作は未確認と報告する。
