# JSON設定と音の層

`assets/approved-presets.json`は2026-10-11に「良さそう」と評価された月震・鋼閃・金月の合成設計を、イベント列へ展開した出発点。全案を必ず使う規則ではない。各案でseedを初期化するため、以前の一括スクリプトと乱数の消費順が違う案のノイズ波形まで同一とは保証しない。

## 最小例

```json
{
  "version": 1,
  "target_lufs": -18,
  "true_peak_ceiling_dbfs": -2,
  "preview_gap_s": 0.7,
  "cues": [{
    "id": "new-verdict",
    "title": "新しい決着音",
    "role": "図柄確定",
    "duration_s": 1.5,
    "seed": 1201,
    "events": [
      {"kind": "impact", "at_s": 0, "duration_s": 0.4, "gain": 0.5},
      {"kind": "body", "at_s": 0, "duration_s": 1.1, "gain": 0.4,
       "pitch_hz": [[0, 440], [0.05, 220], [0.3, 330], [1.1, 330]],
       "fm_index": 1.8, "fm_ratio": 2.37, "flutter": 0.3,
       "attack_s": 0.002, "release_s": 0.16, "decay_s": 0.8},
      {"kind": "ring", "at_s": 0.3, "duration_s": 1.1, "gain": 0.25, "hz": 660}
    ]
  }]
}
```

## 共通の単位と制約

未知のキーはエラーにする。Hzは基準周波数、秒は絶対時刻または層内時刻、centsは1200で1octave、gainは線形振幅の倍率。gain 0.5は−6.0206dB。`20 log10(f2/f1)`はピッチ差ではなく振幅の式なので使わない。ピッチ差は`12 log2(f2/f1)`半音、`1200 log2(f2/f1)`cents。

| フィールド | 意味・既定値 |
|---|---|
| `version` | 現行は整数1 |
| `target_lufs` | 積分音量の目安。既定−18、スクリプト範囲−50〜−5 |
| `true_peak_ceiling_dbfs` | true peak上限。既定−2、範囲−20〜−0.1 |
| `preview_gap_s` | 連続比較時の無音。既定0.7、範囲0〜10 |
| `cue.id` | 重複しない小文字・数字・ハイフン。64文字以内。ファイル名にも使う |
| `cue.title`／`role` | 名前と伝えるイベント |
| `cue.duration_s` | 余韻を含む全長。このレンダラーは0.03〜30秒の演出SEを対象とする |
| `cue.seed` | 0以上2^64未満の整数。案ごとに初期化 |
| `event.at_s` | キュー内での層の開始秒 |
| `event.duration_s` | 層の長さ。最低0.005秒。開始＋長さがキューを超えない |
| `event.gain` | 層の線形音量。既定1、範囲0〜4 |
| `event.pan` | 左−1、中央0、右1。既定0。簡易バランスで、等電力パンではない |

出力の余韻はキューの全長へ収束する。末尾に空きがないと反射音の抜けも短くなるため、単に層を伸ばすだけでなく全長へ余韻の空間を確保する。

## 音の層

### `body`：電子音の本体

有限本の倍音＋非整数比FM、軽い歪み、左右のデチューンを使う。

| 制御 | 意味・既定値 |
|---|---|
| `pitch_hz` | 必須。`[[層内秒, Hz], ...]`。0〜duration_sを厳密に増える時刻で覆い、周波数は20〜8000Hz |
| `fm_index` | FMの深さ。0〜8、既定1.6 |
| `fm_ratio` | 変調周波数／基準周波数。0.1〜8、既定2.37 |
| `flutter` | 振幅の震動量。0〜1、既定0 |
| `detune_cents` | 左右±のデチューン。0〜50、既定4.1 |
| `attack_s` | 入口の立上り。既定0.002、1/96000秒以上、層の長さ以下 |
| `release_s` | 末尾のフェード。既定0.16。層より長い値では層全体へ減衰がかかる |
| `decay_s` | 指数減衰の時定数。既定null（なし）。正数を使うと1時定数で約−8.686dB |

pitchはHzの線形補間。段差に近づけるなら、変化直前と直後に別の点を置く。指数的なグライドが必要なら、対数周波数を等間隔に分けた点列を作る。相の積分を保ち、制御点ごとにオシレーターをリセットしてクリックを作らない。

### `impact`：低い衝撃＋短い金属・ノイズ

`weight`は層全体の倍率（既定1、0〜4）。通常は共通`gain`で配分し、プリセット移行時以外は倍率を二重に調整する必要はない。

### `rumble`：震動する低い芯

`hz`は基準周波数（必須、20〜500Hz）。正弦波、倍音、低域ノイズと振幅変調を合わせる。スマホで低音が落ちるときは、単に基準Hzのgainを増やすより、本体の中域・入口との関係を聴き比べる。

### `ring`：金属の余韻

`hz`は共鳴の基準（必須、20〜2000Hz）。非整数比の部分音が別々に減衰する。`strength`は内部倍率（既定0.35、0〜4）。長さは`duration_s`、音量は通常`gain`で変える。

## 固定の音色定数

低い衝撃の下降定数、ringの部分音比、flutterの細かな揺れ、反射タップなどは`engine.py`に保持する。この初期レンダラーは全シンセ方式を網羅するものではない。必要な音が作れなければエンジンを拡張し、変更した数値とコードのSHA256を記録する。設定だけを変えた場合と、合成方式を変えた場合を区別する。

## 復旧した追加のイベント

`noise` は `band_hz:[low,high]`（20〜20000 Hz内、low<high）と `attack_s` / `release_s` / `decay_s` を指定する。`tone` は全区間を覆う `pitch_hz`、`waveform`（sine/saw/square）、整数 `harmonics`（1〜64）、同じ包絡設定、必要な場合だけ `am_rate_hz` と `am_depth`（0〜1）を使う。`am_rate_hz` は0.1〜500 Hzの全区間を覆うカーブ。

全イベントに `amplitude_curve:[[層内秒, 線形振幅], ...]`（0〜4）を指定できる。時刻は厳密に増え、0からduration_sまで覆う。これは合成の振幅設計で、比較用の固定ゲインとは別。追加できること自体を品質改善と扱わない。

2声のパルス音色例は別形式の `assets/pulse-harmony-approved.json` と `render_pulse.py` を使う。
