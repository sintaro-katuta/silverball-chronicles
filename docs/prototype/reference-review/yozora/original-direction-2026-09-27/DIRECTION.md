# 夜空を切り開け — オリジナル演出

ユーザー指示：実機の断片的な再構成を止め、繋がりと重さを優先して自由に作り替える。
対象：独立 Unity SAO 版。実機映像の再現とは呼ばない。

主役：閉ざされた道に挑む剣士。問い：最後の一撃で封印を破れるか。
通常40秒 / RUSH18秒。抽選・賞球・保留・FAIR・物理は維持。変更する秒数は演出待機のみ。

| 通常秒 | 画面 / 原因と結果 | 音・運動・出口 |
|---|---|---|
| 0–4.5 | 図柄テンパイ | 停止 → 世界へ |
| 4.5–10 | 街の進路を塞ぐ同じ結晶封印を提示 | 低い響き、接近。「封印を斬り裂け」 |
| 10–14 | 一撃が弾かれ、剣士が受け止める | 金属接触 → 短い硬直 → 減衰する反動 |
| 14–21 | 同じ封印に小さな亀裂。剣士が再び構える | 微細な割れ、同じ亀裂が残る |
| 21–27 | 亀裂へ向けて剣に光を集める | 収束音、粒子は剣へ向かう |
| 27–31 | 「この一撃で、道を開く」PUSH | 入力は押込みのみ。未入力でも同じ進行 |
| 31–32 | 溜め、同じ対象を静止して保持 | BGMと効果を落とす |
| 32–36.5 | 大きく振り抜き、斬撃が封印へ到達。接触点を保持 | 移動 → 接触の短い硬直 → 決着前の間 |
| 36.5–40 | 当り：結晶が割れて光の道。外れ：封印が耐えて光が消える | 既に確定した結果だけを開示、図柄へ受け渡す |

RUSHは同じ対象・因果を18秒に圧縮。BONUSは勝利後の同じ街と剣士を背景に実払出を表示し、別の敵・別の戦いを突然始めない。払い出し後は次の道の開放を示す。行先はルールのResult段階まで見せない。

設計根拠：web-pachinko-design / motion-and-sound.md の「攻撃→反応→決着」「静止には理由」「音と光の共通イベント」。これは新規創作案であり、実機に存在するという主張ではない。既存生成原画を再利用し、原作映像・音源は用いない。
