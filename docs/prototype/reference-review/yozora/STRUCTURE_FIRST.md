# 釘・機構を先に照合する

2026-09-26 ユーザー指摘に基づく方針転換。

## 判明したこと
- 青薔薇：R1/動画冒頭の機種画像の右下装飾を参考に推定造形。アタッカーの開口・可動扉を照合したモデルではない。
- 既存アタッカー：YozoraBuilder.BuildMechanismsの矩形チャンバー、ヒンジ扉、受入センサーによる暫定機構。実機の部品寸法・位置・動作との一致は未達。
- 釘：BuildPlayfieldの少数の規則配置で、動画上の各釘を座標採取したものではない。
- 右打ち側の釘群：現行BuildPlayfieldのPin呼出は左側・PLUS周辺のみ。右側の実機釘群の転記が未実装。
- 右側：RIGHT入賞口、短い受入ガイド、アタッカーの暫定構成。装飾を積んでも構造は一致しない。

## 今回の変更
装飾のRendererと装飾Canvasだけを切替える構造確認モード。初期状態は非表示。Collider/Rigidbody/センサー/ルールは保持。薔薇の上の誤解を招くATTACKER表示を削除。

## 次の照合順
1. 動画の右側接写と入賞前後を切り出し、上から下までの通路・釘・受入口・扉を番号付けする。
2. 見える形状と映像で確認できない部分を分け、現在の暫定構造との対応図を作る。
3. 釘と固定ガイドの位置を正面基準へ転記し、まず無装飾モデルで比較する。
4. 可動部の閉→開→入賞→閉を動画と照合する。仕様未確認部分を推定で完成扱いしない。
5. 構造が確認できてから、上部ロゴ、神器の字間・中央十字星、透明カバー、印刷、発光を戻す。

まだ機構を一致させた修正ではない。構造の不足を隠さず確認するための変更。
