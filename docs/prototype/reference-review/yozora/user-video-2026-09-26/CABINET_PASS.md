# 筐体の再造形（並列作業・2026-09-26）

参照は提供動画 R1 の既存抽出 07:15 フレームと DMM 機種前面写真。前面写真は今回画像として開いて観察した。新たな全編連続視聴・音声評価はしていない。

`ReferenceCabinetBuilder.Build(cabinet, machine)` は旧外観の一部を置換し、コライダーと液晶座標を維持する。シーン生成後の実行時ビルドは親担当で行う。

- 四角い反復ブロックだった外枠を、連続した細いクロームの返し・紫の拡散レンズへ変更。
- 上部丸型スピーカーを黒い面と細密な金属メッシュへ変更。白く粗い水玉に見える点を縮小。
- 液晶の非対称な輪郭に沿って、透明の成形レンズ・外周の反射筋・内部のリブを追加。左右に不規則な多角形のプリズムと浅い凹凸を配置。
- 右側神器表示の黒い凹面とクロームの台座、横向きの剣の下の結晶成形部を追加。
- 青薔薇を角丸ボックスの集合から、薄い多角形の花弁の重なりへ変更。
- 下部の白いエプロンを非対称形状に変更。左の孔列・斜めの境界線、前に突出するPUSHの黒い台座と同心円状のボタンを作成。
- 2本の剣は同じ親Transformに残し、先細りの剣先・盛り上がった中央稜線・折れた鍔・巻かれたグリップへ変更。
- マテリアル別に静的メッシュを結合。反射にはプログラム生成した白色の面光源パターンを使用。実際の店舗環境の再現ではない。
- FAIR担当の形状と重複しないよう旧FAIRの透明ランプ／紫の5個パネルを除去する。

この造形は前面画像から推定した近似寸法。実機の金型CAD、実測寸法、透明樹脂の屈折、全印刷絵柄、筐体全体の完全一致は未達。映像や前面写真を3D筐体の代わりに貼り付けてはいない。実行・表示確認の結果は統合担当の検証記録に従う。
