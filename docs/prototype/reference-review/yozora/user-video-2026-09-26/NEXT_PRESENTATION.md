# 液晶・図柄・BONUS担当の対応と残件

2026-09-26追加作業。対象は独立SAO Unity。実機一致の検収完了ではない。

## 今回実装

- [x] 5ラインをすべて表示可能にする。上／中／下／斜め2本のいずれかに確定チケットの図柄を割り当てる。表示線は完了変動数による順送りで、実機の選択頻度を復元したものではない。抽選を追加しない。
- [x] 当りは選択された線だけが一致し、外れは5本とも不一致となる充填処理。0〜8、5線、当外、Amayori有無の180ケースを検証対象とする。
- [x] 結果線を、段差のある各列の数字位置を結ぶ折れ線として表示。中段の水平線1本だけだった表示を置換。
- [x] 前の0図柄デモが新RUSHへ残る問題を防ぐRulesインスタンス別の履歴管理を維持。
- [x] R2 00:55で確認した「左Aliceの1／右Kiritoの1」だけをテンパイ時の人物差分として反映。番号と人物を常に1対1に固定しない。他の人物配列は未確定。
- [x] BONUS専用表示層。上部ROUND、現在単位の払出／当該単位の告知額、実払出累計、告知済累計、カウントと進捗バー。
- [x] 最大1500玉単位の進行と、次単位開始時の完了単位表示。将来の未告知単位まで含むAward.Payout／Award.roundsは表示側で参照しない。
- [x] RUSH移行ロゴ・残回数の入口を追加。演出表示がルールを再抽選しない。

## 原画・映像

- [ ] 実機原画とコマ単位のキャラクター芝居。現行は生成した代替静止画と構図移動・図形効果であり、実機動画素材ではない。
- [ ] LAST FLOORのクィネラ／キリトの攻防、倒れたアリス、金PUSH。R2 03:25〜04:10を観察したが該当原画なし。無関係なファナティオの絵をこの対決に流用しない。

- [ ] WoU AWAKENING以降の別人物図柄・背景・曲。R2 16:50でαとは別キャストを確認。現在のαアトラスを全段階の実機図柄と扱わない。

## 予告・リーチ

- [ ] 連続予告、各保留、各発展先、ダブルライン、神聖術式の分岐・復活を網羅。現在は代表ルートのみ。
- [ ] 5ラインの実機選択頻度・ダブルテンパイの全組合せ。今回の順送りは表示検証可能にするための仮配分。
- [ ] 無編集の実機尺。150秒／23秒は編集動画上の参考間隔から作った代表尺である。

## BONUS・RUSH

- [ ] 払出終了後の物語→PUSH→RUSH移行を待つ専用ルール遷移。現在は最後の入賞でRulesが次モードへ即移行するため、長い物語だけを前面に置くと裏でSTが進んでしまう。表示だけで無理に延長しない。
- [ ] R2 12:55の「War of Underworld 3000 V狙え」の時点に合わせた先告知。初見の低解像度読取りは訂正済み。11:45は150/1500、11:50は285/1500であり、1500+1500という根拠にはしない。
- [ ] R2 15:50〜16:35のSWORD DRIVEポイント増加、地面から出る金数字、Total3000の専用映像。ポイントの内部算出条件は未確認なので実払出を根拠なくptへ換算しない。
- [ ] 連続回数、WoU進行段階と次キャストのルール・演出接続。

告知済額と実払出額、まだ告知していない内部予定額を区別する。「実機は予定額を常に隠す」という断定はしない。新しいRules.BonusProgress.RevealedPayoutを表示根拠とし、映像の確定した先告知点を組み込む場合はAnnounceBonusUnitsで開示する。
