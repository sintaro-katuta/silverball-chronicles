## 実装ファイルと監査

- `ReferenceCabinetBuilder.cs`：装飾のみ。旧の裸PLUS表示を除去し、銘板/PLUS文字を別Canvasとして作成。ゲームのコライダーを追加しない。
- `FairMechanismBuilder.cs`：FAIRケースのメッシュ置換。ポケット・選別センサー・搬送終点・回転速度は変更しない。
- `FairGuidedBall.cs`：既存経路を `Route(start, entry)` と `TravelSpeed` / `RotorWaitLimit` へ公開。再開始時の内部状態を初期化。経路・速度・待機時間は維持。
- `CabinetPhysicsAudit.Run()`：シーン生成後に実行する構造監査。水平回転軸、6ポケット/2当り、終点とセンサー軌道の交差、ガイドの有限値/降下方向/球寿命、レイヤー隔離、装飾にコライダーがないことを検証する。

この監査は構造の破綻を検出するもので、実機入賞率・動画との外観一致・Web上の挙動を証明するものではない。Unity CLI・ブラウザは親担当が統合後に実行するため、本担当から今回の再生確認成功は報告しない。
