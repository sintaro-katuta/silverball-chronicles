# FAIR振分・水平回転体の改修

基準: 提供MP4の04:30静止画。中央の透明な縦長ケース、水平面の六区画、橙色の当り区画、左から下る透明通路を観察。動画全編や内部寸法・回転速度の実測ではない。

- `FairMechanismBuilder.Build` が中央のY軸水平ローター、橙2・白4のポケット、縦リブ透明ケース、左からの透明斜路を生成。
- 左下センサーに下向きで進入した実玉を1玉ずつカウント。重複進入を除外し、5玉目だけ選択。上向きの発射玉および右打ち中は対象外。
- 選択した**同じ球**を `FairGuidedBall` が樹脂内ガイドに沿って搬送。他4玉は元のPhysXのまま下方へ流れ、PLUS/OUTへ向かう。
- ポケットは実際に回転する独立トリガー。搬送終了した球と接触したポケットの `winningSlot` によって入賞する。入賞後に1/3を乱数抽選していない。波の位相と発射間隔の相関があり、短期の当り穴比率を1/3に強制していない。
- FAIR内の球を専用layer11に移し、盤面ガラスやOUTとの誤接触を防ぐ。通常の球・右打ち経路はlayer8のまま。
- ポーズはUnity fixed time停止に追従し、リセットは既存の全球破棄とカウンターリセットに追従。

**再現の限界:** 斜路内は拘束搬送。内部の細かな樹脂形状・摩擦・自由落下・穴への落下をすべて剛体接触で再現したものではない。選別と移動を可視化する縮約モデルであり、完全な実機物理と呼ばない。入口の位置や回転速度32度/秒・搬送速度は暫定。実測の全玉入賞率・PLUS入賞率を保証しない。

構造検証は100進入→20選択、水平回転軸、六個中二個の当りトリガー、所有者接続をチェックする。Webでの発射→振分→搬送→ポケット入賞は別途実行して記録する必要がある。
