# 筐体モデリング改修 2026-09-26

ユーザー指示「一旦今できる最大のモデリング」に対し、既存SAO夜空Unity筐体を更新。実機資料R1/R3とDMM盤面接写を形状判断に使用。動画フレームを製品テクスチャには取り込まない。寸法は推定で、完全再現ではない。

## 実装
- 外枠の曲面、複層透明レンズ、成形筋、左右非対称装飾、銀/紫の盤面印刷、鏡面プリズム。
- スピーカーの旋削形状とメッシュ、面取りを持つ上部クレスト。
- 厚みのある剣、5層の湾曲花弁による青薔薇。
- Blenderで生成したSAO/神器の立体文字（面取り・側面・落ち影用の黒い輪郭）。
- FAIRの連続ケース、左偏心開口、U字断面通路、透明支持スカート、支持耳と窓、曲面の葉。
- 深い下皿、非対称の白い曲面エプロン、外装を貫くスピーカー穴、斜め上向きPUSH、曲率を持つゴムグリップ。
- Webに正面・斜め・FAIR・操作部の視点選択。一時停止中も切替可能。

## 再生成
Unity Editor `CabinetMaximumReview.BuildAndCapture` で生成・既存ルール検証・画像出力。`BuildWeb` は加えてローカルWebを書き出す。比較画像beforeは旧シーン、afterは更新シーンで同一のカメラを使用。実機と同一カメラを意味しない。

Blender文字の編集元は `unity-yozora/ModelSources/EmbossedCabinetType.blend`。他部品はUnity Editorの生成コードで編集する。

## 残る差
- 実測寸法・CADがないため輪郭、部品配置、レンズ刻みは推定。
- 透明樹脂の多重屈折、ホログラム印刷、実機固有の光拡散を完全には再現していない。
- キャラクターパネルと液晶映像は既存試作素材。実機固有の原画・映像・音声ではない。
- 静止した材質だけでギラギラ感の全体は完成しない。発光部品と液晶を連動させた動的な演出の追加調整が残る。
- 玉の材質、ルーレットの振分け、物理センサー、抽選と出玉を変更していない。
- クラウド更新なし。

## 確認結果
- 4視点のUnity描画を確認し、白飛び、隠れた盤面印刷、上部パネルの交差、スピーカー孔の読みづらさを修正。
- Unityルール検証15件＋FAIR、20,000変動の長期検証、BONUS進行、装飾と物理の分離監査成功。実機との確率・物理較正を意味しない。
- Unity WebGLビルド成功。ブラウザで起動と停止中のFAIR視点切替を確認し、縦長画面の画角を追加修正。
- Vite build成功。既存のPlayCanvas worker externalize/chunk-size警告あり。
- 音声の実聴、実機と同一条件の測光比較、携帯実機性能は今回未検証。
