## モデル

`ReferenceRightMechanism.Build(cabinet,machine)`。旧右側ケース、釘なしガイド、旧跳ね上げ式扉、旧右センサーを置換。

- 右上8本・下流3本の釘。座標は映像からの比率推定で、実物寸法やゲージ調整値を主張しない。
- 内外の連続した樹脂レール、成形後板、段差溝、横リブ、固定ボスとネジを作成。後板を釘より奥へ置き、釘の視認を優先。
- 上流球中心の推奨接続点 `(0.193, 0.836, -0.052)` m。
- 上側横長窓の中心 `(0.207, 0.449, -0.061)`。
- 下側赤矩形の中心 `(0.206, 0.369, -0.060)`。
- スライド板は `(0.201, 0.371, -0.052)` から奥へ50mm退避。実機機能の同定を待つ位置仮定。実球に接触する板と表示板は同一オブジェクト。
- 下流右始動センサーは `(0.225, 0.334, -0.052)`。閉状態で外側バイパスを下る玉を受付。
- `machine.door` の既存角度入力を `RightMechanismDrive` が受け取りスライドへ変換。独自抽選なし。撮影は `ApplyOpening(0/1)` で直接ポーズ設定可能。

## 物理検証1回目からの修正

上流注入2条件が下流の釘と内壁間で停止。中心間13mmから壁半径1.7mm・釘半径1.3mmを引くと隙間10mmで、11mm球が通れなかった。釘を保持し、内壁y=.414〜.360のxを.174→.168へ戻して実隙間16mmに拡張。閉扉も左端が新内壁へつながるよう中心x=.201/幅.064へ変更。表示と接触の形状は共通。再試験は統合担当。

## 物理検証3〜4回目の修正と結果

- Round 3 は閉時2条件が下釘と扉上面の間で停止、中間外側通路1条件も閉開両方で停止。
- 下釘 `(0.188, 0.394)` は維持。扉中心 y を `.383 → .371` へ12mm下げ、受入センサー y も `.369 → .353` へ下げた。扉の坂は13度を維持。閉時のセンサー先取りを避けつつ、釘と坂の間に玉1個が挟まる状態を解消。
- 中間成形境界の折線 x を `[.230,.236,.235,.226] → [.216,.222,.221,.214]` に変更。外壁との通過幅を球径以上に確保。表示とColliderは同じ座標。
- 統合担当が再生成した Round 4 `RightFlowValidation` は **閉4条件すべてRightへ、開4条件すべてAttackerへ到達、逸走0・停止0** と報告。上流4点から実PhysX接触で流下を確認したもので、実機の釘調整・入賞率・開口機能の同定を証明するものではない。
- この時点で Unity source freeze。実機との位置比較・独立査読は統合担当のレポートを優先。
