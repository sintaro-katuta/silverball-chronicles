# RUSH払出玉数告知・比較試作

comparison.mp4：約28秒、1000→1500→3000玉の順。SEなし。専用確認ページで当選済み払出を指定し、共通の演出・開閉・実入賞処理を動かした録画。

1000玉は銀青、1500玉は金、3000玉は大きな虹色数字。777→告知→現在払出/最大玉数へ切替。告知時は実払出0で、後続の入賞により各70/105/75玉まで増えたことを確認した。払出全額を収録した動画ではない。抽選の振分けや通常当たりの払出は変更なし。

3ケースともブラウザエラー0、最大玉数が指定額と一致、実入賞前に加算されないことを確認。3000-motion.jpgでは数字内の虹色光と払出表示への切替を確認。関連テスト10件・ビルド成功。外観はユーザー確認待ち。
