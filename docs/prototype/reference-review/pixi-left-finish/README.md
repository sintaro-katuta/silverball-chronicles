- 発射強度0.22〜0.26を各120秒流し、30秒排出。before.jsonとafter.jsonは同じ条件。0.23〜0.25を動画で拡大比較。
- 近くへの到達: ヘソ中心の左右25、上40〜下は玉半径の範囲に一度でも入った玉。
- 直前で外れ: 上記範囲へ到達して命釘に接触し、最終的にヘソ以外へ出た玉。接触が失敗の唯一の原因だと断定する分類ではない。
- 近くで外れ: 到達したが命釘接触記録がなく、ヘソ以外へ出た玉。
- 途中落ち: 左道釘へ接触したが上記範囲に届かず、ヘソ以外へ出た玉。
- 到達・道釘接触は経過指標なので、その他の結果数と単純合計しない。未排出の玉は結果を確定しない。
