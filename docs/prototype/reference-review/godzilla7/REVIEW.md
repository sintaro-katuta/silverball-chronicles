## プロトタイプとの差

1. **液晶の役割**：試作は1枚の画像上で数字を変えるだけ。動画は警告、対決タイトル、戦闘、決着で画面構成を変える。
2. **期待を育てる時間**：試作は変動して結果が出る。動画は、次の発展を期待する段階が複数ある。
3. **物理的に見るもの**：試作は釘と入賞口がほぼすべて。動画は大型役物や透明通路が注目先として存在する。
4. **表示面積**：動画はキャラクター・攻撃・文字が盤面の大部分を占める。試作の小さい液晶領域では同じ迫力を出しにくい。
5. **盤面全体の連動**：動画では画面の色と筐体の発光が同時に変わって見える。試作は大当り時の照明差が小さい。

これらは、スキルや永続強化を増やす話とは別に、1回の抽選を見ていて楽しいものにする改善点。

## 月影機関への翻案案（未確定）

架空作品のひとつのリーチを、短い物語として作る。

- 通常：機械都市の風景、巡回中の主人公、控えめな図柄。
- 予兆：月の光が乱れ、通信や照明に異変が起きる。
- 発展：警報と敵の出現。対決タイトルで「何と戦うのか」を示す。
- 戦闘：敵の攻撃、主人公の防御、反撃準備。構図の異なるカットで攻防を描く。
- 勝負所：主人公の台詞・表情のアップと武器の起動。筐体の光や装飾役物も連動。
- 決着：勝利／敗北それぞれの映像。勝利時は大当り開始へつながる。

既存作品の場面・台詞をコピーするのではなく、オリジナルの登場人物・対立・台詞を作る。キャラクターや背景を揺らすだけでは戦闘にならないため、攻撃・防御・決着が分かる絵と動きが必要。

### 役物候補と役割の区別

- **風車**：玉に押されて回転し、進路を変える。釘以外の物理的な変化。
- **透明な分岐通路・シーソー**：玉がどちらへ進むか追える。入口・出口と動きを見せる。
- **回転体・Vゾーン**：玉の行き先を見守る主役のギミック。ただし抽選ルール自体を追加するため、採用は別途判断する。
- **可動する紋章・武器の装飾役物**：戦闘の勝負所に画面へせり出す。演出用で、玉の当たり判定や当選率とは分けて扱う。
- **アタッカーと照明**：既存の大当りルールを使い、開放・払い出し・ラウンド切り替えが目でも分かるようにする。
