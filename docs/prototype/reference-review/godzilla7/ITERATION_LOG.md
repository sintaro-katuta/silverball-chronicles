## 今回の限界と次の比較軸

これは完成品質の宣言ではない。関節を持つ原型3Dモデルは仮素材で、生成アニメ画と同一キャラクターの厳密な造形・作画連続性はまだない。専用リグと戦闘モーション、複数の敵・物語分岐、声・BGM・重い効果音、実機級の筐体造形が次の制作課題。今回の試作では画面と物理ギミックの構成・タイミングを試せる状態にした。

## 4周目：ユーザー指摘による絵柄の統一

生成イラストから簡素な3Dキャラクターへ切り替わることで品質が急落するとの指摘。キャラクターの3D描画を撤去し、生成済みの2枚をそのままCanvasに描画。敵への寄り、主人公への寄り、全景、覚醒のポートレートを切り替え、斬撃、短い衝撃、火花、月光、決着の光を重ねる。画像を変形させず、質感・描き込みを保つ。すべてゲーム時間から描画するため停止中は効果も止まる。今後の3Dモデル制作は必要性を見て判断する。
