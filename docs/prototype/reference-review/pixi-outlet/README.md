# 下部樹脂ガイド・OUT口の試作

既存Physicsのout-left / out-rightとoutletを表示する独立ページoutlet-pixi.html。共通28px銀玉、カメラ倍率3、整数ドット描画。ガイドは透明な本体・明るい縁・暗い側面で厚みを表現。OUT口は金属枠と暗い内部を持ち、手前の縁の後ろへ玉が落ちる。

物理・ガイド座標・半径・反発・入賞・回収条件は変更なし。既存game.loseの発生時だけ0.18秒の落下表示を追加。回収線は既存のy675で、OUT口の見た目が新しいセンサーを追加するものではない。発射・入賞・OUTの数は盤面全体の累計。

実発射30秒と5秒の排出を録画。capture.mjsで中央への回収、カウントと回収表示の一対一対応、ID重複なし、既存ガイドとoutlet不変、ポーズ停止、ブラウザエラーなしを確認。

- outlet-demo.mp4: 実働動画
- entry.png / flow.png: 実画面
- alignment.png: ガイド中心線と回収高さ
- verification.json: 検証結果
