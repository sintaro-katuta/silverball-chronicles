# 中央始動口 素材プレビュー

提供パーツシート08の左側の青い器を基準に、中央始動口の外観確認用ドット素材を制作。

- 内蔵画像生成を使用。入力は新版24パーツシート、対象は08のみ。
- 金の天球儀風装飾、青い器、中央の雫形宝石、黒金の台座を維持。
- 上部は玉が落ちる暗い開口とし、蓋・羽根は設けない。
- 生成プロンプトは `../../../../prototype/reference-review/pixi-central-start/prompt-v1.txt`。指定した80×80は表現の目安であり、生成PNGの実画素寸法を保証するものではない。
- 今回は外観プレビュー。入賞判定・レイヤー分割・玉の取込みアニメーション・PixiJS組込みは未実装。
- 完成承認済みのアタッカー・電チューは変更なし。

## 実働確認
`/central-start-pixi.html` を追加。30秒間通常打ちで実発射し、さらに5秒間残った玉を排出。入口の物理位置(210,535)・幅20と既存釘配置は維持。実入賞時のみ手前の縁に隠れながら0.26秒で縮小・消失。入賞カウント・一時停止・発射切替・判定線表示を用意。抽選・賞球・保存なし。
録画は `../../../../prototype/reference-review/pixi-central-start/central-start-demo.mp4`。検証値は `../../../../prototype/reference-review/pixi-central-start/verification.json`、入賞画面は `../../../../prototype/reference-review/pixi-central-start/entry.png`、判定位置は `../../../../prototype/reference-review/pixi-central-start/alignment.png`。

## 玉を基準としたドット表現 v2
ユーザー指定により、既存の28px銀玉を共通基準として保持。silver-ball.jsに絵を共通化。内蔵画像生成で器を粗い輪郭と大きな色面へ再作画し、central-start-v2.pngへ保存。プロンプトはprompt-v2.txt。64×64・16色は生成時の表現指示であり、出力PNGの実寸・厳密な使用色数の保証ではない。
釘を14pxの段階的な輪郭に変更し、描画解像度を論理画素と揃えた。物理・入賞条件・銀玉の元絵は維持。他の完成部品と本編の絵は未変更。

## 装飾密度の整理 v3
v2のドット感を維持しつつ、玉との比較で細かい意匠を削減。金の格子、小さい星、台座の細工を取り除き、太い縁・2本の支柱・中央の大きな宝石・1個の星へ整理。内蔵画像生成で制作し、central-start-v3.pngへ保存。指示はprompt-v3.txt。玉・釘の寸法、物理判定は変更なし。新しい絵の前縁に合わせ、手前レイヤーの切り分け位置のみ調整。
