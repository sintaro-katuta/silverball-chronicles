# 樹脂ガイド単体

OUT口を非表示にし、前回のout-left / out-rightのガイドを同じ倍率3で上下に配置。上段は左側、下段は右側。全長・傾斜・色・厚みは前回のまま。初期表示は玉なし。

- guides-only.png: ガイドだけの実画面
- guides-transparent.png: 透明背景のコード描画素材
- resin-demo.mp4: 同じガイドへ実発射の玉を表示
- resin-pixi.html: 玉表示切替と一時停止が可能
- verification.json: 既存ガイド座標不変、玉なし・OUT口なしの初期表示、実発射、ポーズ、ブラウザエラーの検証

盤面全体の物理は変更しない。動画は各ガイドの近傍を上下へ移して表示した確認用で、盤面上の配置変更ではない。

## ネジ追加版
両端寄りに取付け部と銀色の十字ネジを追加。下側・盤面側の固定部なので玉の走る縁や物理判定は変更しない。最新のguides-only.pngとresin-demo.mp4はネジ追加後の画面。ガイド描画はresin-guide-art.jsで下部球路プレビューと共通化。
