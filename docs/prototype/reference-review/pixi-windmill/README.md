# 風車のPixiJS試作

左風車 (75,384)、半径18、4本の接触軸、回転角・角速度を既存Physicsから読み取って描画。左打ちパワー0.5で実発射し、30秒後に発射停止、5秒間残球を流す。位置や衝突計算は変更していない。

銀玉は共通28px素材。風車は金の輪郭・青い羽根・銀の軸をコードから整数ピクセルで描く。参照素材07の配色を踏襲し、細部は中央始動口v3と同様に簡略化。参照07の多枚羽根そのものではなく、現行物理の4本に合わせた試案。見た目の採用は未承認。

確認用動画: windmill-demo.mp4。contact.png / running.png / alignment.png は実ブラウザ撮影。capture.mjsで接触後の回転、固定位置・半径、ポーズ停止、ブラウザエラーなしを検証。

抽選・賞球・保存への接続はしない独立試作。
