# RUSHリーチ文字の復元

RUSH専用化で非表示にしていた「リーチ」を表示。既存の0.45秒の中央待ち時間に登場・保持・フェードし、その後777の決着へ進む。通常時の2秒表示、確率と払出は変更なし。

`../../../../prototype/reference-review/pixi-rush-reach/reach.mp4` は新しいコードを実行した30fps・約7秒・音声なしの録画。確認用の当落指定を使用。`../../../../prototype/reference-review/pixi-rush-reach/motion.jpg` で左右7→中央の「リーチ」→777→斬撃を確認。ブラウザエラー0、関連テスト2件・ビルド成功。
