# 釘列のドット絵・実働確認

共通銀玉28pxに対して、既存の金色釘14px（3段階の陰影）をpin-texture.jsへ抽出。中央始動口・通常入賞口・風車も同じ生成関数を使う。画像編集や物理変更なし。

pins-pixi.htmlで通常打ちパワー0.5の実発射を36秒、4秒残球を排出。振り分け釘・寄り釘・道釘の範囲を12秒ずつ同じ倍率3で見る。種類の切替はカメラのみ。実演以外はボタンで任意に切替可能。

capture.mjsは各種類への接触、全釘配置がmakePins()と同一、表示された釘の中心と物理座標の一致、半径維持、ポーズ停止、ブラウザエラーを確認。画像・動画は今回の実ブラウザ記録。

- pins-demo.mp4: 実働動画
- spread.png / yori.png / michi.png: 各釘列
- alignment.png: 判定円を表示
- pin.png: 使用した共通の14px釘
- verification.json: 検証記録

独立した部品確認用で、抽選・賞球・保存への接続は行わない。
