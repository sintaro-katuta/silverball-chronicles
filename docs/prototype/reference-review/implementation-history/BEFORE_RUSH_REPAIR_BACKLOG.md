# 26項目の修正・検証記録

2026-09-22。ユーザー承認の一括改修。改修前の問題文は [履歴](BACKLOG_BEFORE_PHYSICS_REPAIR.md) に保存。現行仕様は [実装対応表](../../REAL_MACHINE_AUDIT.md)、ゲーム全体の確定事項は [仕様書](../../../pachinko.md) を参照する。

「実装」はコード上の対応を示す。測定結果と未確認事項は下部に分け、実機との完全一致とは説明しない。

| ID | 項目 | 今回の対応 |
| --- | --- | --- |
| 01 | 強度を初速へ反映 | `Physics.spawn` で強度から発射速度を計算。重力積分を発射直後から共通使用 |
| 02 | 右下発射から左右へ | 右上のキッカーと上部反射材を物理部材として設計。弱い軌道は反射材の下を通り、強い軌道は接触して右へ向かう |
| 03 | ストッパー等の衝突 | 線分と厚みを持つカプセル衝突。法線と反発係数で速度を更新 |

| 05 | 描画と衝突の一致 | `physics.colliders` と動的 `gate` の同じ座標・太さでレール、樹脂壁、反射材、入賞口の縁、扉を描画。玉は同一平面 |
| 06 | 玉と釘の寸法 | 玉半径4.6、釘軸半径2.1。描画の軸は物理半径と一致し、手前の釘頭を別形状にする。実機実寸の主張はしない |
| 07 | 機能別の釘 | 命釘、ジャンプ、道、寄り、分散、一般入賞口の釘に役割データ。個々のランダムずらしを使わない |
| 08 | 接続とこぼし | 道釘の意図した隙間と複数の釘群を設定。左右通過、入賞、排出、残留を診断可能にする |

| 11 | 右側の垂直落下 | 無釘の細い樹脂ガイドとの接触と重力。固定Xへの吸着、縦釘、床帯、矢印はなし |
| 12 | アタッカー | 閉鎖時の斜め扉と開放時の側方フラップを共通の動的線分で処理・描画 |
| 13 | 閉鎖時排出 | 閉じた扉で流れを外へ逃がし、閉鎖中は賞球しない。通常・ラウンド間・上乗せ待機で同じ開放条件 |
| 14 | 入賞口 | 玉の半径を引いた有効幅と下向きの入口通過で判定。口の側縁も衝突対象として表示 |
| 15 | アウト | 排出口・下部の集球面を表示。経過秒数による玉消去を廃止し、残留は診断値として露出。発射側へ戻った消費玉は返却口から戻し、無料の追加玉では持ち玉を増やさない |
| 16 | 玉同士 | 玉同士の押し戻しと速度交換。追加発射は無料玉の待機数を保持し、同一発射口から0.15秒以上離して出す。オート時は追加玉にも止め打ちを適用 |

| 19 | 止め打ち | 現在の位置・速度から共通ソルバーで到達を予測し、残りカウントと上乗せ前の停止を判断 |
| 20 | 打ち方案内 | 実際に通過した流れの診断をUIへ提供。状態と観測に応じた案内にし、新しい音・罰は追加しない |
| 21 | 保留と抽選 | 入賞時に乱数・確率・強化条件・ラウンド種別を持つ抽選情報を固定。保留配列と変動中抽選を分離。途中の赤演出で再抽選なし |
| 22 | 賞球とゲーム加算 | 基礎賞球、ゲーム加算、払出、発射消費、補給、返却、デバッグ変更を別記録 |

## 追加された図柄停止の要望

左→中央→右の順に停止する。左・中央の一致後にリーチを示し、右だけを変動させて演出へ入る。順番と停止間隔を機種モデルとテストで扱う。最終結果は停止演出の前に決まり、演出によって再抽選しない。

台上部のグラフ・主要数値・ステージ進捗は一つのダッシュボードにまとめ、盤面に重ねず表示する。

## 維持する仕様と範囲

ステージ、持ち玉と進捗の持ち越し、チケット、永続強化、ラン内スキル、無限モード、可変の深い天井、保留5個、R上乗せ、一時停止、持ち玉0が3秒続く敗北、LCD非衝突、上部グラフ、回転数、架空アニメ演出、縦持ち・オフライン・iOS/Androidは維持する。効果音は改修対象外。

電チュー・V入賞・ST・時短・LTは未採用のまま。写真に写っているという理由だけで機能のない装飾部品を追加しない。奥行きの運動・釘のしなり・実機の傾斜までの再現は今回の2D盤面物理に含めない。
