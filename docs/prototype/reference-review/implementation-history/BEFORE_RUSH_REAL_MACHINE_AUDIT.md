## 採用基準

1/199前後・4R/6R/10Rを軸とする架空機種。実在機種の完全移植ではない。盤面の機能と玉の動きは物理的に整合させ、ローグライク進行は別のゲームルールとして扱う。右下の発射部から直接上向きに打つ構成はユーザーの希望に合わせた架空設計であり、全実機共通の配置という意味ではない。

## 発射と盤面

- 一つの右下発射部から初速を与える。位置の補間、固定経路への吸着、強さによる送り先の切替を使わず、重力・接触によって移動する。
- 右側の発射レール、上部キッカー、上部の反射材、無釘の右落下ガイドを、衝突形状から描画する。右の落下部は薄い透明樹脂壁とし、釘の縦列・床の帯・矢印は表示しない。
- 閉じたアタッカーの扉と開いた受け口を物理に反映する。閉鎖時には排出へ流し、開放フラグだけを理由に空間上の玉へ賞球を付けない。
- 命釘・ジャンプ釘・道釘・寄り釘・分散・一般入賞口周辺の役割を、コースごとの整った配置で表現する。玉の通過量・こぼしを計測する。
- 入賞口は玉の半径と口幅に対応した下向きの進入を受け付ける。アウト口を見える位置に置き、寿命による玉削除を詰まり対策にしない。
- 玉同士の接触を計算し、同じ平面で表示する。高速衝突は小刻みの時間積分で検証する。追加発射は無料玉の待機数として保存し、同じ発射口から0.15秒以上の間隔で出す。オートでは追加玉にもラウンド間の待機を適用する。
- 弱すぎて発射側の返却口へ戻った消費玉は持ち玉に返却する。無料の追加玉では返却による持ち玉増加を付けない。
- LCD表示面・演出紋章は既決の非衝突例外。機械的なレール・扉・釘とは区別する。

実寸の3Dシミュレーターではなく、2D盤面の重力・反射を3D表示する試作。釘のしなり・奥行き運動・実機の盤面傾斜を再現したとの主張はしない。上部反射部は機能が分かる見た目を優先し、右通路の樹脂壁は控えめに描画する。

## 機種仕様と抽選

正本は `src/machine-spec.js`。各コースの通常確率は1/199・1/229・1/259。初期4R/6R/10Rの振分け45/35/20%、10カウント、開放15秒、ラウンド間0.65秒、基礎賞球は始動口2・一般入賞口4・アタッカー15。いずれも架空機種の調整値。倍率前の規定カウント分払出600/900/1500玉は発射消費を引く前の値であり、時間切れ時の保証値ではない。

始動入賞を受け付けた際に、乱数、確率、強化条件、ラウンド種別を持つ抽選情報を保存する。保留の消化で回転数を進め、天井救済を判定して演出へ渡す。図柄は左→中央→右の順で停止し、左・中央が一致したリーチでは右を未停止のまま演出へ進む。赤い予告を表示した時点で当落を再抽選しない。抽選待ちの保留5個と変動中1回を別管理する。

基礎賞球 `basePrize`、ゲーム加算 `gamePrize`、払出 `payout`、発射消費 `spent`、返却 `returned`、補給 `supply`、デバッグ変更 `debugAdjustment` を分離する。グラフは開始時からの持ち玉増減なので、補給・返却を含む。金額換算はしない。

通常・大当り・上乗せ判定・ラウンド間を明示する。`rightDraw: null` は右側での新規抽選がコードにまだ実装されていないことを表し、ST・時短・V入賞・LT・電チュー抽選は未実装。提供写真の部品を形だけ追加して搭載済みとは説明しない。

## 承認済みのゲーム独自仕様

- 10ステージ、出玉目標、目標超過分・持ち玉・大当り状態の持ち越し、コース解放。
- ラン内スキル、プレイヤー単位の永続強化、追加玉・分裂・特殊玉・賞球補正・追加抽選。
- 敗北時にも獲得出玉に応じたチケット、リタイア0枚、無限モードではチケット・永続強化なし。
- 保留5個、非常に深い可変の大当り保証天井、持ち玉0が3秒続く敗北。
- 同一大当り中のR上乗せ。`game-round-extension` として初期R・追加R・各上乗せ履歴を区別する。別の大当りを引いたことにはせず、大当り回数を追加加算しない。
- オート発射と止め打ち支援、手動発射、一時停止・スキル選択中の時間停止。
- 架空アニメ画像を使う演出、リーチ告知、色による期待度差、復活演出、上部グラフと回転数。
