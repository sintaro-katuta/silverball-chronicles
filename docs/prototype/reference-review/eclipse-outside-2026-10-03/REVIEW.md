# 外側から入る月蝕役物

対象：リーチ中の大型月蝕役物。既存の金属造形を再利用。液晶開口に可動部全体が切り抜かれていたため、映像内から現れるように見えていた。可動部のマスクを撤去し、液晶外の装飾より手前に描画。暗転は開口内へ限定。左右レールを外へ伸ばし、作動中の収納口を表示。上部冠の開始点を液晶上端の外へ変更。

outside-entry.png、closed.png、eclipse-sheet.jpgで液晶左右外側からの進入、冠の上部進入、合体、外への収納を目視確認。文字は映像の境界で切れず、枠と銘板に重なる。造形と合体位置・時刻、図柄停止前の収納は維持。役物は演出用前景で玉の当たり判定は追加しない。

Chrome収録のpageerror 0、関連10テスト成功、build成功（既存容量・node外部化警告）。eclipse-outside.mp4は12秒地点から6秒の等速無音抜粋。最初の10秒は自然発射、その後当選rng固定と最初の有料実球1個をヘソへ配置。他の玉は自然発射。確率検証ではない。クラウド未更新。
