# 釘調整の記事から確認した設計上の論点

確認日：2026-09-22。ユーザー提供の[Wikipedia「釘調整」](https://ja.wikipedia.org/wiki/%E9%87%98%E8%AA%BF%E6%95%B4)を閲覧。記事の説明と、本ゲームの実装判断を区別する。今回はメモの更新のみで、盤面は変更していない。

## 記事の要点

- 天釘、連釘、バラ釘、命釘、添え釘は、配置と役割が異なる。
- バラ釘も無作為な配置という意味ではなく、整った列や六角形状の配列が説明されている。
- 連釘は誘導や保護、命釘は入口の通過、添え釘はその直前の挙動に関わる。
- 玉の進む先は釘の間隔だけでなく、入射速度・接触位置・角度・風車などとの組み合わせで変わるという説明。盤面全体で各方向へ流れる割合を考える。

記事には出典不足の表示があり、時代・機種の違う説明も含む。寸法・本数・微小調整の効果をそのまま現行実機共通の定数にはしない。機能別の配置を読む資料として使い、必要な数値は対象機種の資料と照合する。

## 本ゲームへの適用判断

以下は記事の引用ではなく、現在のコードとユーザー要望を踏まえた改修基準。

1. **模様より先に経路を設計する。** 発射から入口まで、各釘群へ入る位置・速度と、そこから先の行き先を定める。山形を繰り返すだけでは十分でない。
2. **整列と分散を両立する。** 釘群の形と間隔は規則的にし、釘群の接続・分岐・こぼしで複数の経路を作る。ランダムな位置ずらしを戻さない。
3. **釘の太さも確認する。** 現在の衝突半径は釘3.2／球4.6。実機の釘軸・釘頭・球の寸法比との照合は未完了。見た目の釘頭をそのまま球が触れる軸の太さとみなさない。
4. **平面シミュレーションの限界を明示する。** 現在は主にXY平面の円同士の衝突。釘のしなり、奥行き方向の接触、盤面の傾きは再現していない。今回の記事を読んだだけで再現済みとはしない。
5. **名前を付けるだけで完成にしない。** 現在の `role` は機能を追跡するための分類。命釘単体の隙間による入賞変化は確認済みだが、各寄り・道釘群の到達率・通過率・こぼれ率の追跡は未実装。通常発射の総入賞数だけで各釘群の役割が再現できたとは判定しない。

## 発射経路の未解決事項

ユーザーが指摘した「右下から上がって左へ曲がるなら、強い玉ほど左へ進む」という矛盾は未解消。

現コードは右打ち強度の判定で上部経路を早期終了させて右の落下経路へ切り替え、弱い玉だけを左へ案内する。これは移動先を条件分岐で選んでおり、同じ発射方向で強さだけを変えた結果として自然に左右が分かれる物理ではない。

右下の発射位置、右側アタッカー、無釘の垂直落下というユーザー要望を保つ場合でも、上部の導入構造を先に具体化する必要がある。「テストが通る」「右打ちの玉が入る」だけでこの構造の矛盾を解決済みにしない。この釘調整の記事自体を発射経路の正当化には使わない。
