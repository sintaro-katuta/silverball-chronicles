# 釘の役割に基づく配置

2026-09-22更新。[実装座標の色分け図](../../../../prototype/reference-review/pin-layout/layout.svg)。色は説明図用で、ゲーム内は金属色。

## 基準と資料

ユーザー指定の「規則的で美しい配置」「複数ルート」「釘の役割」を基準にしたゲーム用の設計。特定実機の盤面の完全な複製ではない。

- [SANKYO：釘](https://www.sankyo-fever.jp/beginner/qa/pachinko/134/)：釘が玉の動きを左右する部品であることを確認。
- [SANKYO：道・道釘](https://www.sankyo-fever.jp/beginner/qa/pachinko/131/)：風車からヘソへ続く釘という説明を確認。
- ヘソ直上の2本、寄り・こぼしの役割はユーザーが提示した説明を設計条件として採用。以下の座標と配列は本ゲームの試作用であり、実機の実寸・調整値ではない。

## 実装した役割

| 役割 | 配置・動作 |
| --- | --- |
| ヘソ釘（命釘） | 中央ヘソ(x210,y535)の直上、y522に2本。左右対称。コース別の中心間隔は22/21/20で、球直径9.2。釘自体の衝突で入賞を左右する |
| ジャンプ釘 | ヘソ左右の手前、(182,510)・(238,510)。道釘から最後のヘソ接近に作用 |
| 道釘 | 風車の下から中央へ向かう一定傾斜の列。中央へ集めていた斜めの金属レールは撤去 |
| こぼし | 道釘の途中、左は(154,467)と(190,493)の間、右も対称に間隔を設けた。玉はヘソへ必ず到達せず下へ抜け得る |
| 寄り釘 | 左風車の上に2つの傾斜した釘列を置き、風車側と外側の流れに分かれる配置 |
| 上部の振り分け | 規則的な短い山形と斜め列。寄りへ向かう外側の経路と内側の経路を作る |
| 一般入賞口周辺 | 各入賞口の上に局所的な釘群を配置 |

中央ヘソ直前を塞いでいたシーソーは上方・右内側へ移した。右打ち側は引き続き無釘の垂直落下。役割は `physics.js` の各釘データの `role` に保存し、後の変更で意味を追えるようにした。

## 動作確認

- 命釘だけの比較試験：同じ41個の落下初期条件で、中心間隔14では始動入賞0、22では20、30では26。14は球が通れない比較用の狭さで、本番配置ではない。この試験は隙間の物理作用の確認で、実機の回転率を示す値ではない。
- 通常発射500個の確認：コース順に始動入賞43/42/37。寿命による除去0、最終残留0。値は試作計測で難易度の最終決定ではない。
- 既存の右打ち、ラウンド、自動止め打ちを含む44テスト成功。ブラウザで命釘の位置、レール撤去、右打ち入賞を確認。

実在の釘調整や店舗の有利不利を判定するための説明ではなく、架空の盤面設計の記録。
