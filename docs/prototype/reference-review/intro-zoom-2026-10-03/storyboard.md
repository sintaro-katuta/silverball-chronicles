# 同じ台を見せる開始導入

ユーザーの「全体→今の表示領域→液晶」の順で拡大する案を、本編開始時に実装する。詳細で一覧用48×64の絵を拡大する表示は撤去し、仕様と開始ボタンを残す。一覧は小さな選択用サムネイルを維持する。

既存 `public/machines/moonlit-pachinko-frame.png` の外枠と、本編の人物・盤面・液晶を同じsceneで組み合わせる。新素材や参考機種のキャラクターは追加しない。枠の内側で本編盤面が切れないよう独立レビューする。

1. 筐体全体：上部、側面、玉皿、ハンドル、下部と本編盤面を見せる。
2. 盤面：今の396×436の通常遊技範囲へ寄る。
3. 液晶：同じ人物・背景・図柄を大きく見せる。
4. 盤面へ戻り、発射と遊技時計を開始する。

時間は本作向けの短い仮演出値であり、実機仕様ではない。SEなし。導入中は遊技時計・発射・抽選を進めず、演出だけを進める。一時停止/非表示で導入も停止し、スキップや動きを減らす設定では通常盤面から遊べる。ローカルのみ。
