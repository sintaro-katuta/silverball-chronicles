# 右始動口 PixiJS部品試作

**現行はv6。固定外観は下記の生成画像へ置き換え済み。初版〜v4の図形による虎顔は使用していない。**

参考：提供パーツシート09。銀の獣面、金枠、青い入賞口を整数画素の図形で直接再作画。原画のモザイク処理ではない。輪郭と装飾は低解像度向けの簡略化。アタッカー完成版は変更していない。

## 配置と開閉

独立ページ `/right-start-pixi.html`、256×320の原画、物理1単位=2px、原点(270,390)、最近傍拡大。既存のPhysicsとcreatePartFlowによる盤面全体からの発射を使用。

誘導羽根は既存の支点(347.486,468)と閉端(346.313,426)／開端(377,440)。入口蓋も既存の閉端(313,480)→(347,470)、開端(313,477)→(313,497)を維持。0.55秒smoothstepで接触端点を補間し、同じ端点から各フレームのドット絵を生成。途中反転・一時停止に対応。

全開でrush口への入賞を許可、閉鎖指示で受付停止。通常の抽選・賞球・保留やラウンド制御はない。物理ソースは変更せず試作インスタンスの開閉を拡張。端点の線形補間は3D剛体ヒンジの再現ではない。完成素材の承認用サンプルであり、本編への組込みは未実施。

## 検証

`tests/right-start-pixi.test.js`：閉→開→閉、閉鎖中0入賞、開放中増加、再閉鎖後停止、途中反転の連続性、ポーズを検証。
`../../../../prototype/reference-review/pixi-right-start/capture.mjs`：Chromeの実画面・動画を取得。途中の状態を含め、描画端点と物理端点の一致、ポーズ、ブラウザ例外0を検証。結果はverification.json。

5秒閉鎖、10秒開放、5秒閉鎖。連続発射を20秒で止める。動画は生成映像ではなく実行画面録画。ローカルのみ。

## v2 銀の虎への修正
ユーザーの訂正により狼・ロボット風の尖った耳と顔面板を撤去。丸い耳、幅のある頬、左右に分かれた鼻先、虎の額と頬の縞、ひげ点をピクセルで再作画。開閉・物理・取込み位置は変更なし。v1/open.pngに旧版を保存。画像と動画は修正後に再取得。

## v3 銀の虎の表情修正
丸く白い鼻先の面積を減らし、低い眉・細い青い目・彫りの深い頬・牙が見える口へ再作画。銀の明暗と細い反射で金属レリーフとしての厚みを追加。v2/open.pngに修正前を保存。機構・物理は変更なし。画像と動画を更新。

## v4 虎を装飾枠へ統合
ユーザー指定で、目を細い青い光として深い眼窩へ配置し、低い眉・長い牙・暗い銀の面で威圧感を強めた。額の星型紋章、左右の金の唐草、頬から入口へ繋がる銀の飾り、下縁の反復意匠を追加。虎単体ではなく一体の装飾金具として構成。v3/open.pngに旧版保存。動作は維持して再録画。

## v5 拡大参照に沿った素材の作り直し（現行）
ユーザー提供のreference-detail.jpgを参照し、内蔵image_genで固定ケース全体を再制作。プロンプトはasset-prompt-v5.txt。細長い虎の顔、上へ伸びる刃状の毛並み、金の額飾り、青い目、下の発光した開口部を一体で描いた。旧版はv4/へ保存。
素材：`public/assets/right-start/silver-tiger-housing-v5.png`。Pixi Assetsで読み込み、(71,50)に96×172論理単位で配置。縮小モザイクを作るフィルターは使わず、生成されたピクセル調の原画をnearestで表示。描画解像度は2へ変更。動的な羽根・蓋・球・衝突は別レイヤーのまま。固定素材を単純図形の虎へ戻すフォールバックは設けていない。
高密度のピクセル調素材であり、厳密に単一ドット格子へ揃えたスプライトシートではない。参照の完全なトレースではなく再制作。機構は既存の接触に沿った試作であり、右側の立体開閉図の完全再現は未実施。開閉・入賞・途中の端点一致・ポーズを今回再検証。

## 上方展開試作（2026-09-29）
- v6素材を共有テクスチャのフレームに分割。閉鎖時132px、開放時180px、下端固定。
- 顔上部は48px、下顎は24px上昇。顔の比率を維持し、口内の24pxの隙間を見せる。
- 下部の青いケースは収納時に重なる。口の装飾と羽根・蓋は同じ0.55秒の進行値に同期。
- 入賞判定は従来の青い入口のまま。口を新しい物理入口にする変更は含まない。
- capture.mjsは高さ・上方移動・口の開閉・閉鎖復帰・停止・描画と接触線の一致も検証。

## 旧入口蓋の撤去
左下へ退く蓋はユーザー指示で描画・衝突とも撤去。閉鎖時も蓋は表示せず、入賞センサーの受付停止と既存羽根によって通過状態を維持。最新動画と各状態画像を再取得。

## 下辺固定の受け皿
右始動口に下辺固定の板を追加。開くと手前へ倒れ、前縁に接触した玉だけ取り込む。既存の水平横断センサーから接触式へ変更。口元の上方展開と同時に0.55秒で開く。取り込み後は0.22秒の奥行き移動で表示を消す。閉鎖・途中逆転・停止・入賞と前縁の一致を検証。

## 最新：虎を固定装飾へ復帰
虎の口の開閉と上方展開はユーザー指示で撤回。v6素材を分割せず元寸法で常時表示。受け皿は透明樹脂と銀の縁で描画し、閉鎖中も青い内部と装飾を透かして見せる。受け皿の物理・接触式入賞は前版から維持。最新録画では全状態の装飾位置・寸法の不変も検証する。

## 最新：装飾全体が手前へ倒れる構造
別付けの透明受け皿は撤去。96×172pxの元装飾を一枚のメッシュで下辺固定・手前へ投影し、上辺が玉を受ける前縁になる。背面には暗い開口を配置。全開時のみ上辺接触を受け付ける。口の分割アニメーションは使わない。最新の閉鎖・開放・復帰画像と録画を再取得。

## 最新：装飾を下方へ配置
装飾・背面開口・固定軸・受け口の上辺を物理30単位下へ移動。閉じた虎の頭を既存入口付近へ合わせる。描画と接触線は同じ姿勢から算出。最新録画と各状態画像を更新。

## 最新：取込み先を隙間の奥へ訂正
上辺接触後の玉を装飾の下辺へ動かす表現を撤回。開放で露出した上辺の奥へ移動し、縮小して消す。取込み玉は装飾メッシュより背面に描画。物理接触と入賞条件は維持。

## 電チューの役割を実演（RUSH）
`right-start-pixi.html` の専用ボタンから、実発射玉のスルー通過で普図抽選を行い、その当選で開閉するモードを開始。入賞は実際のGameクラスの右抽選・保留・賞球へ接続。セーブ処理なし。既存の機構だけを動かす20秒実演とは別。証拠はelectric-demo.mp4、electric.png、electric-verification.json。
メーカー根拠：[SANKYO パチンコ機のパーツ名称](https://www.sankyo-fever.jp/beginner/useful-information/7/)。開放抽選の数値は本作の試作値。本編と通常時制御は未適用。

## 最新：左右羽根のチューリップ型
新版素材09を採用。内蔵画像生成で固定本体と1枚の羽根の透明アトラスを制作し、羽根を左右に配置。`public/assets/denchu/tulip-atlas-v1.png`、プロンプト` tulip-prompt.txt`。描画時にTextureの領域を指定し、元PNGは加工せず保持。入口中心は物理(363.5,493)。羽根は(357,490)/(370,490)の軸で回転。開いた先端はx350/x377で右通路の内側。開閉0.4秒。以前の虎方式はtiger-finalへコードを保存。
普図の開放要求1.8秒のうち開動作0.4秒を除いた時間が全開受付になる。スルー→普図→開放→始動の実演を新しい機構へ接続。
最終配置調整：入口中心(359.5,493)、左右の軸(353,490)/(366,490)、開放先端x346/x373。左下ガイドをx336→338にして脇の通過幅を確保。40秒発射→30秒排出の閉鎖継続検証で残留0。上記の初期配置(363.5,493)をこの配置で置換。
