99ver.：通常1/99.9、右打ち実質1/23.8、4R/9R、400/900個。通常RUSHはST30＋4で約77％、上位はST64＋4で約95％（94.6％）。総R数の上乗せ率95％という意味ではない。
今回のユーザー指定の総R上乗せを優先し、別方式のSTや95％を無断導入しない。動画からの画像・音声を配布アプリへ流用しない。
