# PM provisional calibration acceptance

今回の目的は本作の自然左打ちでヘソに入りやすくする校正。実機入賞頻度を新たに同定したとは扱わない。標準.6秒発射で複数powerを同じ300秒＋45秒drain測定し、調整前後でnearHeso（ヘソ幅±25/口上40の観測領域）・実口入賞・発射数・全計数を分ける。初期球配置/球ワープ/ランダム強制入賞/不可視集球bar禁止。

pegSeedはinstallLcdBoundaryがpinsを採寸から再生成し旧seed差を消す。seed0/1/101の配置同一を独立検査し、同じ物理配置を独立試行数へ加算しない。発射位相・powerを実際の別条件として扱う。

暫定受入提案（統括・LEと最終値調整）:

- 本編default .24の同一長期条件で実ヘソ入賞/100発がbaselineを明確に上回ること。暫定目安4〜8/100発は本作の操作感のための提案で、実機値ではない。改善倍数だけを採らず、過剰集球/普通口消失も見る。
- .22/.23/.24/.25/.26が連続した操作可能範囲を持ち、特定一点のpowerだけに成功を依存させない。全powerを同じ率に強制しない。
- デフォルト実口横断の証拠を本編SessionGame自然動画でも取得する。抽選外れ固定は物理入賞数と別で明記。
- rails/pins/rims侵入/中心横断、drain残球、会計を再検証。既存資料101釘の中心変更があれば実機資料版と本作校正版を分け、全採寸一致を主張しない。
- 特図抽選確率・保留容量・RUSH/払出specは維持。右自然3000回帰、3view同session継続、最新source一致が必要。

統計推定区間や実機frequency一致はこの決定論的校正試験の受入には使用しない。すべての発射結果が独立確率標本だとは見なさない。
