# 月影：内部時計とマニュアル追加の撤回

2026-10-05。ユーザー訂正「ゲームの内部的ところ」を受け、開始前説明・任意ヘルプ・入賞口図・月予告表を撤去。前の録画は撤去前の履歴であり、現行のマニュアル機能の証拠ではない。

内部改善の中心は[GF07/GF08の実装記録](game-flow-implementation.md)：四分岐と演出事前確率を共通モデルから導出し、消費済みイベントを直近2048件へ制限。単調増加球IDと生存球の範囲に基づいて捕球IDを退役し、遅延入賞の二重払出を拒否する。

追加の時計整理では、`SessionGame.advanceClock` にゲーム時間・収支記録・W機械の期限更新をまとめた。通常tickと演出待ちの両方から同じ時計を使う。大当り告知・開閉待ち・通常リーチ・復帰で図柄やラウンドの進行を待っていても、電チュー開放とV待機の期限は進む。一時停止では両方が停止する。

従来は演出側が `game.time += dt` を直接使っていたため、W機械の期限更新を飛ばしていた。電チュー開放中に特図2を制御APIで確定し、最初のV成立から告知へ進めた制御テストで、開放時間が告知中も進むことを検証した。本編SessionGameの通常スケジューラは電チュー閉鎖後に特図2を処理するため、この重複条件を自然遊技で確認したという主張ではない。独立する機械時計と演出時計の契約を整理する修正。

`w-mechanical-clock.test.js` で、電チュー期限、一時停止・復帰、V時間切れの一回だけの通知、入賞なしで払出を増やさないことを検証。初回の新規2件は試験準備で電チュー開放中のSessionGame.tickに特図2消化を要求したため失敗し、制御APIによる準備へ修正。修正後の新規2件と確率/保持/session計12件が成功。他23件は成功済みで、自然発射から普図→電チュー2→V2→3000払出と収支一致も含む。

開閉秒数・容量・直撃分岐・内部Vの未確認仕様は推測で変えていない。GF01〜GF06は引き続き未達。最終ビルド・差分空白チェック成功。クラウド更新なし。
