# 月輪パルス：もう一度聞きたくなる当たり音の制作（2026-10-06）

最新ユーザー指定は[シンセ音色への統一](SYNTH_ONLY_SOUND.md)。硬い金属の返しを撤回し、明るい音階を戻した。識別リズムと当たりだけへの割当は維持。以下は制作履歴。


ユーザーの制作基準：「その音が聞きたくてたまらないような特徴的かつ中毒性のある音にする」。これは音の識別性・期待と報酬の演出についての目標であり、心理的な中毒性を検証した結果とは扱わない。

参照：[ユーフルカ氏の遊技機サウンド制作の5つの基本](https://wingless-seraph.net/wp/2019/09/09/これがパチンコ・パチスロサウンドの作り方５つ/)。信頼度/頻度、映像と音の間、大胆な波形編集、鋭い主音を低域で補強するという考え方を採用。掲載音声は試作へのサンプルとして使わず、元波形から独自に制作する。著者の説明を全機種共通の信頼度や、本作に対する聴感の証拠にしない。

## 今回の変更

前回の素材感と自然な余韻だけでは「月影機関だと分かる短い音型」が足りなかった。通常/RUSH当たり専用に「月輪パルス」を制作する。

| 当たり公開から | 音の役割 |
|---|---|
| 0〜約70ms | 素早く噛み付いて戻る短い立ち上がり。輪郭を覚える入口 |
| 74/124/168/204/233ms | 自作金属波形を加工した加速する5連打。リング変調、部分的な逆再生、再生速度変更と飽和で特徴を作る |
| 312ms | 鋭い上昇→沈み込みの主音、タイトな低域と中域の衝撃、刃の6つの響きを重ねて解放 |
| 480/670/930ms以降 | 不均等な3つの明るい返しと、左右に減衰する反射で余韻。RUSHは返しを前へ詰める |

核となるリズムは覚えられるよう保ち、4音型は波形の向き・粒の分布・変調の周波数・反射・返しの響きで作り分ける。完全に同じ録音を連続で再生せず、0→2→1→3の順序は維持する。通常/RUSHの核を共有することと、同一音源の反復回避を両立する。

強い音を常時鳴らす変更はしない。月輪パルスの完全な音型は `win` / `rushWin` だけへ割り当て、通常予告・入賞・斬撃・敗北には使わない。既存の標準51.7秒/復活55.7秒/即告知9.7秒と短尺専用の当たり公開から開始する。外れと復活前の音は維持し、前段で当確を漏らさない。映像・保留・抽選・出玉は変更しない。以前の勝利の汎用和音だけの分岐を撤去し、専用の加工波形へ置き換える。

## 検証と試聴

- 新3テスト：識別リズム、4音型の相違、入口/連打/解放/返しの音量存在、当たりだけへの割当、専用PCMとの一致。
- 既存18音声テスト：全280音型、ピークとフェード、当落、静けさ、音の保護・消音・復帰と支えの寿命。
- 本編8経路、AudioContext/実録音、消音/復帰/ポーズ。本番/確認ページビルド。
- 確認用当たりの実入賞から54秒リーチと決着を、実キャンバスと音声を同時録画してユーザーへ渡す。

音の「中毒性」やユーザーがもう一度聞きたいと感じるかは未検証。音の好みは新しい動画と、通常当たり4音型→RUSH当たり4音型の比較WAVで確認できる。スマホ実機・スピーカー/イヤホンの実聴取は未確認。

最終検証：21テスト、本編8経路、本番/確認ページビルド、diff check通過。約70.72秒の動画の録音ピーク-5.4dB、-50dB/0.4秒条件で無音は既存の間0.82秒と一撃直前0.55秒。`prototype/reference-review/original-se-2026-10-06/signature/` に実録音、通常/RUSH各4音型、同ピーク条件の前後比較（前の素材音→新専用音）、画面と検証JSONを保存。音の好みや中毒性を測定したという意味ではない。

## 続く質感修正：優しい木琴/マリンバ感を減らす

ユーザーの「木琴とかマリンバっぽい音が少し優しい」を受け、当たりの返しを修正。3つの返しのタイミングを維持し、音程を通常の音階から1397/2243/3559Hzの不規則な関係へ、倍音を1.641/2.317倍の金属的な関係へ変更する。丸い8msの立ち上がりを0.65msへ、短い約0.3秒の減衰を約0.5〜0.64秒へ変え、擦れと飽和した輪郭を加える。衝撃後の響きも高い成分を強める。ピーク目標・音型の位置・4音型・当たり公開時刻と外れ音は維持する。音色を硬くするための変更で、音量の引き上げによる置換ではない。

この音色修正の再検証は21テスト、本編8経路と実録音、本番ビルド、diff check通過。`prototype/reference-review/original-se-2026-10-06/hard-metal/` に変更前→変更後の比較WAV、実出力音声、画面、検証JSONを保存。動画は表示時計49.5秒からの決着部分を等速で収録した確認用で、54秒全尺の新録画とは扱わない。通常/RUSHのピーク目標0.54/0.51は維持。
