# 盤面外周の造形修正 — 2026-10-06

ユーザーの「全体と盤面で見えている盤面の形が美しくない」という指摘に対応するローカル修正。対象は盤面の外形・背面・外周縁。液晶・図柄・人物・入賞口は既存の位置を保つ。

## 観察と変更

現行コードを390×844で撮影すると、上半分の弧から右側の長い垂直線へ移り、右下は鋭い角、下端は折れ線になっていた。全体表示では筐体の楕円形の窓に対して盤面だけが角張り、盤面表示では四角い背面領域が残っていた。

`board-silhouette.js` に外装用の共通輪郭を作成。上半分は既存の発射レールの弧を利用し、下半分を連続するベジェ曲線で結ぶ。背面と表示マスク、銀鋼・細い金縁を同じ輪郭で描く。盤面外の四角い塗りと直線装飾を取り除き、筐体の窓につながる丸い外形へ整理した。下縁の太さも含めて本編canvasに収める。

これは外装の輪郭であり、新しい衝突壁ではない。下部の排出境界・発射・釘・口・抽選・出玉は変更しない。排出末端の盤面外部分は下枠の背後へ隠れる。発射レールの接触coreは従来の幅1.4を維持し、厚い外装支持は玉の背面に置く。

参照は既存の採用済み筐体と本作の現行画面。外部機種の新しい方式や寸法は導入していない。スキルの `visual-patterns.md` の構図・奥行き、`review.md` の枠・画面サイズの確認を適用。外観の最終採用はユーザー未確認。

## 確認

- 本編をローカルChromeで390×844、320×740、1280×960、DPR 2で実行。全体・盤面・液晶切替と操作部展開を撮影。
- スマホサイズで自然発射8秒、右打ち・アタッカーの機構確認各4秒、通常復帰2秒を連続実行して録画。これらは機構の確認モードでありRUSH本編の品質検証ではない。
- ブラウザエラー0、計数整合を確認。出口・通常入賞口・ヘソ・右側の機構を撮影で確認。
- 既存のcompact-board、heso-calibration、intro-camera、right-resin-routeの13テスト成功。自然ヘソ入賞、全球排出、右球路、カメラ復帰を含む。
- 本番ビルド成功。既存の500kB超チャンク警告あり。

撮影・ログは [検証フォルダ](../../prototype/reference-review/board-shape-2026-10-06/)。`before-*` は変更前、`after-*` は最初の修正案。最終の下縁余白調整後の証拠は `mobile-*`、`narrow-*`、`desktop-*` と `verification.json`。過去のレビュー画像は今回の検証に流用していない。

スマホ実機/Capacitor、音の実聴取、長時間性能は今回未検証。クラウド未更新。
