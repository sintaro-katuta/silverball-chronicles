# ドット絵と入賞口のリリース版統合（2026-11-06）

目的：ユーザーが同じ改修として進めていた液晶・筐体のドット絵と、マージ済みの円形ヘソ・U字一般入賞口を同じリリース候補に揃える。基準はPR #79を含む `release/0.4.0` の `9db1220`。ヘソ・釘・球径・当落・演出時間・賞球は変更しない。

人物予告5種、戦闘の背景と基本／中間姿勢、復活、筐体上部、決意の一閃の顔アップの格子画像をローカル候補から移植し、nearest表示とリリースでの可逆変換を適用した。通常画面は元の絵を基準に背景・雲・人物・毛先を重ねる。独立人物には剣の周りなど元背景の色が残る箇所があるため、任意位置に使える完全透過素材とは扱わない。上部の参照画像・原寸PNG・編集用JSONと制作手順を保存した。画像生成・標本化と手動修正の範囲は素材の `.prompt.txt` と [制作手順](PIXEL_ART_WORKFLOW.md)に記録。

見比べ用 `prototype/dev/s10-all-grid-review.html` はローカルファイルとして開ける。入賞口と筐体上部を含むPC本編、5種の人物予告、復活、戦闘の前後を一覧できる。背景・人物の分離と各画面の経緯は [調査記録](../agile/S10_74_COMPOSITING_AUDIT_2026-11-01.md) を参照。動画や参照先の一部は従来のローカル作業場所にあり、すべてがこのPRに含まれるという意味ではない。

関連35テスト、本編起動・素材28点・停止再開のPC／390×844ブラウザ検証、5種類の予告素材の全カット・連続再生、実ゲームでの予告5種およびRUSH3条件、戦闘3経路、戦闘／大当たり／RUSH体験とPUSH・払い出しを確認した。リリースビルドも成功。実機端末での性能・音声、全演出の全フレームと筐体光の同時視聴は未検証。

関連Issueは人物予告 #62、通常画面の分離 #73、共通条件 #74、戦闘や復活の個別Issue。受入条件には前後動画・全演出の境界確認などの残作業があるため、この統合だけで完了・自動クローズとしない。PR #79は入賞口の変更としてすでにマージ済みであり、本統合PRと同じ `release/0.4.0` で合わせる。

0.4.0で追加されていた戦闘の顔アップも、元の構図を保った256×256の格子に標本化し、二値alpha、nearest表示、可逆変換にした。全65536セルの編集用JSONを保存。元画像の自動標本化であり手描きの修正ではない。

顔アップは実ゲームのpressure経路40秒を390×844幅で確認。pressure・initiative・exchangeは確認用の保存結果を指定し、各経路の再生・復帰・会計整合を確認した。実端末の確認ではない。
