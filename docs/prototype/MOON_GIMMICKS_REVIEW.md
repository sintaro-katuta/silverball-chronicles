# 月影ギミック実装・受入記録（2026-09-27）

対象は本体のPlayCanvas版。ユーザーが依頼したオリジナルのギミック案を実装。実機再現の主張ではない。設計根拠はweb-pachinko-designのmotion-and-sound / player-preferencesと、直前に提案した「入賞→保留→戦闘→決着」の因果。新規外部資料の引用なし。

## 実装
- 各保留に入賞元・球の印・入賞時のビルドを固定。光跡と小さな印で引き継ぐ。
- 追加玉／入賞強化／粘りの取得傾向に応じ、援護射撃／防壁／受け流しの戦闘分岐。試遊サポートで選択可能。
- 同じ交戦構図と敵の防壁の亀裂を保持し、最後の一撃へ集約。
- 左右の月蝕役物が斬撃に合体し、当落後に開放または収納。
- BONUS下部の機関パネルは告知済みdisplayRoundsだけで開放する。
