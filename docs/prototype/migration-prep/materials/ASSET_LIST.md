# 月影機関 — 全面ドット絵移行の素材検討一覧

2026-09-29。素材の制作・採用判断はユーザー持ち帰り。今回は既存素材の収集と一覧化のみ。新しい画像生成、描き直し、色・レイアウト・書体の変更はしていません。

対象は月影機関と共通ゲームUI。独立したSAO／Unity試作は対象外です。以下の「必要な状態」は現在の機能を移すための整理であり、画像枚数・絵柄・解像度・アニメ速度の決定ではありません。

- **使用中53 PNG**：戦闘50、通常人物1、戦闘フォールバック1、フロア／詳細共用の筐体1。

- 戦闘のうち2画像はRUSH／BONUS背景でも共用。別素材として重複カウントしていません。
- [全55画像の閲覧ページ](../../../../prototype/migration-prep/materials/index.html)／[ファイル名・用途・現寸法の一覧](IMAGE_FILES.md)。ZIP版は展開後の `../../../../prototype/migration-prep/materials/index.html` を開いてください。
- 元画像のまま約164.5 MiB。容量は現行素材の実測で、新仕様の容量目標ではありません。
- ファイル寸法と表示寸法は別です。現在の筐体画像も一覧では96×120へ縮小されています。現在の画像がそのまま採用可能な完成ドット絵である、という判定はしていません。

## 画像以外の現物

- `public/models/course-{0,1,2}.glb`：盤面・釘・機構の旧3D資産3本。フロア5個体の専用画像ではありません。移行後のPixiJSへ直接読み込む素材にはしません。
- `public/models/title-glyphs.glb`：演出用3D字形1本。対応表は `src/playcanvas/title-metrics.json`。
- 上記4 GLB合計約54 MiB。持ち帰り画像ZIPには含めず、リポジトリの元ファイルを保持しています。
- 効果音は `src/sound.js` のWeb Audio合成。月影機関の音声ファイルは現状なし。PixiJS移行のために音を作り直す必要はありません。

## 検討時に残せるメモ

各IDについて「残す意匠」「変更したい点」「背景と人物の分離」「必要な差分」「参考画像」を書けば次工程へ引き継げます。新しい解像度・パレット・書体・アニメ枚数は、この一覧では確定していません。

筐体・球路の装飾は変更できますが、物理の釘・入賞口・扉の接触位置は移行だけを理由に変更しません。540×880の盤面と317×408の液晶は現行の論理座標で、新素材の納品ピクセル数の指定ではありません。
