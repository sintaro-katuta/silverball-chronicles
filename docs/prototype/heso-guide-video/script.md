# 台本

今回は、ヘソの周りにある、左右のガイドを取り除きました。

変更前は、ヘソの左右に受け皿があり、液晶の下から取付板が伸びていました。

変更後は、この受け皿と取付板を外し、ヘソの周囲をすっきりさせています。

見た目と一緒に、ガイドに玉が当たる判定も取り除きました。見えないガイドは残していません。

バージョン、ゼロ点サン点ゼロで採用済みの発射強度や、ヘソの口幅、釘の配置はそのままです。抽選や賞球も変えていません。

自然に飛ばした玉がヘソへ入り、抽選や玉数の計算が正しく進むことを確認しました。関連する十七件のテストと、ビルドも通っています。

パソコンとスマートフォン幅の画面で、ガイドが消えていることと、発射の停止、再開、一時停止からの復帰を確認しました。

ガイドがなくなることで、玉の流れは変わります。長時間の入賞率とスマートフォン実機での確認は、まだ行っていません。

この変更は、ゼロ点サン点ゼロ向けのプルリクエストにまとめています。公開版への反映は、まだ行っていません。
