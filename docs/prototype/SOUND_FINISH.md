# 効果音の仕上げ（2026-10-06）

ユーザーの「効果が安っぽく聞こえる理由」に対し、旧音源の共通FM骨格・短い乾いた減衰・露出した三角波の溜め・一律のミックスを要因として説明。「効果音を仕上げてください」の指示により、音の質感と役割を再制作する。単なる種類の追加を完成基準にしない。

## 音源

自作合成のみを使い、参考機種の音声やサンプルは製品へ流用しない。70音名×4音型の反復回避と現在の割当は維持する。

- 一撃：低域の衝撃＋端末でも残る倍音、6つの異なる周波数と減衰の刃の共鳴、空気を裂く摩擦、左右で異なる減衰した反射。`decisiveHit` は1.55秒、通常接触より強い胴の層を持つ。
- 当たり：最初の衝撃から、ずらして鳴る金属/ベルの和音、0.45秒以降の明るい余韻へ。`win` 2.65秒、`rushWin` 2.05秒でテンポと音階を別にする。
- 各演出：ラッチ、月の結晶、紋章の打撃、風、敵の圧力、刃、機構、再点火を材料モデルで区別。決着音・当たり・敵・上部剣・扉などは固有の周波数、胴/共鳴/空気の配分、長さ、余韻を設定する。4音型は材質のばらつき、接触の時差、粒の分布、結晶の順序と間隔を変える。
- 外れ：下降するゲームの警告音を撤去し、小さい胴の響きと空気が引く音へ。復活前は同じ敗北を使う。
- 空間：27〜563msの左右で異なる反射と減衰した尾をPCMへ合成。全音を同じ広さや長さにせず、操作音は小さく近く、決着は広く響かせる。

## 溜めとミックス

単独の三角波の連続音を撤去。刃の6つの共鳴と粒状の摩擦を持つループを使用する。24秒から表示時計に合わせて密度・帯域を開き、再生速度の変化は0.72〜1.2倍に抑える。音程だけが大きく上がるサイレンに頼らない。49.65〜50.2秒の直前の静けさ、16.2〜17秒の間、普通の敗北と復活前の同音を維持する。

重要SEが鳴る間は背景の音を下げ、一撃は約0.23秒、当たりは約0.45秒、背景を22%へ。重要音の最中に弱い予告が鳴っても、この抑制を弱めない。6つのSE枠が埋まっても入賞/払出の小音で確定音を切らない。操作音・予告・決着の優先度を分ける。支えは2音だけ、キャッシュはSE9MiB＋2つの3秒ループで12MiB未満。代表の一撃と通常/RUSH当たりの最初の音型を事前生成して保持する。

抽選、入賞済み結果、保留、PUSHの可否、演出尺、機構、出玉を変更しない。一時停止/消音/非表示/リセット/破棄で余韻も止める。音の検証中も予告や背景から結果を先に知らせない。

## 検証

- 音源・同期・支え・ミックスの18テスト：全280音型の有限値/無音/重複/ピーク/端のフェード、勝敗と復活の同音、余韻の左右差、当確音の保護、背景抑制と復帰、音の寿命。
- 本編8経路でAudioContextと録音、消音/復帰/ポーズを確認。
- 確認用の当たりを実入賞から再生。リーチ54秒を飛ばさず、実キャンバスとWeb Audioを1つのMediaRecorderで同時録画。更新版MP4をユーザーへ渡す。
- 本番/確認ページビルドとdiff check。

計測と波形/発火の検証を、人間の実聴取に置き換えない。スマホ実機/Capacitor・スピーカー/イヤホンの聴感は未確認。ユーザーが感じる質感の最終評価は動画/試聴で確認する。
