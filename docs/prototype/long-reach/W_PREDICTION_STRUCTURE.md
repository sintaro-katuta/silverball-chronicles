# 東京喰種Wの予告・リーチ構造の照合

確認日：2026-10-05。ユーザー指定の[P-WORLD・e東京喰種W](https://www.p-world.co.jp/machine/database/10249)の演出/解析情報と[メーカー公式](https://pachi-e-tokyoghoul.jp/)の4大注目演出を本文で確認した。動画の連続視聴・実機での再生検証はしていない。掲示板やAI投稿まとめは根拠に使わない。

これまで本編はWの抽選/RUSH/獲得と、月影の戦闘・月/剣予告を中心に実装した。Wの具体的な予告群を体系立てて本編へ照合する作業は未完了だった。「Wの遊技フローに合わせた」を「Wの予告構造も全て実装済み」と扱わない。本書は今回の調査であり、新予告・PUSH・色保留などの採用決定ではない。

## 確認した分類と設計上の役割

### P-WORLDの掲載分類（ユーザー画像と照合）

- 注目演出：注目演出
- 予告演出：先読み予告／リーチ前予告
- リーチ演出：キャラ／ロング／バトルSP／エピソード／喰種クライマックス／特殊／全回転リーチ
- 大当り中の演出：通常時の大当り演出／右打ち中の大当り演出
- HYPER喰種RUSH中の演出：モード概要／予告演出／リーチ演出

以下の表はこの掲載分類をそのまま転記したものではなく、役割による再整理。前回回答で両者を混ぜて説明したため、掲載見出しとの対応が不明瞭だった。「発展の示唆」「リーチ中」「役物」「結果の告知」は独自の分析軸であり、サイトの同階層の分類ではない。「注目演出」も時間順の最初の段階ではなく、複数の段階で出る代表的な強い演出をまとめた紹介枠。

東京喰種ZONEは掲載位置が「リーチ前予告」、本文の説明が「先読みゾーン」。機能が先読みであることと、サイトの掲載位置を区別する。タイトル・テロップ・カットインの色は各リーチ内のチャンスアップであり、独立した掲載分類ではない。

以下の役割は掲載説明をもとにした設計上の整理。記事にない分岐率・秒数・出現率・厳密な信頼度を推定しない。

| 段階/分類 | 掲載された例 | 役割の整理 |
|---|---|---|
| 先読み | 保留変化、東京喰種ZONE | 消化前から対象変動を気にさせる。保留色などが期待の手掛かりになる |
| リーチ前 | 連続予告、回想、ステップアップ、背景変化 | 段階的な期待とテンパイへの導入。全変動がリーチへ進む意味ではない |
| 発展誘導 | 覚悟の証明、ジェイソンルーレット | 強いリーチへ進む示唆や発展先の提示。「発展濃厚」と「当たり濃厚」を区別する |
| リーチ後/途中 | 決意のマスク、タイトル/テロップ/カットインの色 | 同じ本編の途中でも期待の違いを読む手掛かりになる |
| 複数の時点に重なる役物 | 喰MAXハンド | 視覚と筐体の強い合図。掲載説明では様々なタイミングで発生し、常に当たり確定という意味ではない |
| 結果/プレミア | 全回転、勝敗告知 | 当たりを強く知らせる。ページは全回転を大当たり濃厚と説明 |
| 大当たり後 | 突入チャレンジ | 図柄当たりを見せる段階と、RUSH突入を見せる段階を分ける |

キャラ/ロング系はその場の決着に加え、継続や上位リーチへの入口になる。バトルSP・エピソード・クライマックス・特殊・全回転は別経路で、全件が同一の階段を上るわけではない。通常/RUSHの予告名・分岐は別。例えばRUSHの百足先読みはテンパイすると捕食へ、赫眼煽りはテンパイ後の成立/不成立で発展先を分けると掲載されている。

メーカー公式の「決意のマスク」は特定のセリフ付きの大当たり濃厚パターンにも言及する。P-WORLDの一般的な期待度上昇説明から、全パターンを一律確定にしてはいけない。手役物のカスタムも信頼度40/90/大当たり濃厚の設定で意味が異なると公式が示している。現在の月影へこれらの値を移植する採用はしていない。

## 月影との照合と未達

月影では短いリーチの当たり/外れ、戦闘3本、上部の月/剣、復活、二重月輪/刀身紋章、直当たり/RUSH即告知を本編へ接続済み。演出で保存当落を再抽選しない。

保留変化・先読み、通常変動中の段階予告、弱いリーチから上位へ途中発展する多段構成、戦闘中の独立したチャンスアップ群の体系的な設計と同時配分は未達。現在の主な経路は入賞済み当落から短尺/戦闘/直接告知を選ぶ構成で、3本の戦闘に到達するまでの経路を実機相当の種類数にした意味ではない。

採用済み台帳は追加の色保留・先読み連続予告・PUSH操作・新しい予告音を現段階の採用表へ含めていない。今回の調査だけで無断追加しない。今後扱う際は予告の役割、発展先、当落別出現質量、他予告との条件付き信頼度、尺と画面の占有を定義する必要がある。
