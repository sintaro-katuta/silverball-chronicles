# 演出台帳と上部・突入案内の訂正（2026-10-05）

基準は[演出パターン台帳](../PRESENTATION_PATTERNS.md)。強い外れと当たりの共通本編を整理し、未制作の復活／即告知を区別した。54秒本編を全演出パターンの完成とは扱わない。

入賞時の乱数記録から結果を表示し、演出中には再抽選しない。旧合算199.9・図柄49.5%／チャージ50.5%では図柄約1/403.8になるため、公表各399.9から合算199.95・各50%を導出するモデルへ訂正した。図柄突入50%とチャージ突入1%を別に管理する。公表丸め値の再構成であり、内部ROMの厳密な表ではない。月予告の期待度計算も同じ図柄確率を参照する。

上部案内は17–21秒の弾む矢印のみ。液晶の待機、案内文字、暗転、自動画面切替を撤去し、19.6秒の受け止めと22.3秒の小反撃を追加した。19–24秒の上部動作と54秒の決着は維持。演出軽減時は矢印を静止表示する。

Wの大当り終了イベント後に突入資格を表示側へ伝えていなかったため、RUSH状態だけ成立して突入演出が再生されない問題を修正した。確定した突入決定イベントでのみフラグを更新し、既存の突入演出・タイトルの後に、大当りと共通の右打ちカットインを一度表示する。RUSH待機の操作情報は「RUSH」とする。
