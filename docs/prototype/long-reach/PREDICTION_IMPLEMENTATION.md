# 予告・発展構造の実装対応

2026-10-05。ユーザーの「それで、実装かえて？」を受けた月影機関への翻案。参照の掲載順・分類は [W予告構造の照合](W_PREDICTION_STRUCTURE.md)を用いる。参考は [P-WORLD](https://www.p-world.co.jp/machine/database/10249)とユーザー添付PDF。サイトの紹介分類と、演出が発生する時間順を同じものとして扱わない。

これは東京喰種の人物・映像・名称を製品へ複製する実装ではない。下表は参考演出の役割と月影の現在の対応・限界を示す。対応欄があることを、参考機種の全演出が独立素材で完成した意味にしない。

## 最新の専用映像接続（2026-10-05）

人物の決意・約束の回想・門の防衛・屋根の追跡・橋の救出の5専用素材を制作し、本編入口へ接続した。通常5秒5カット、RUSH2秒3カット、短い通常予告2カットへ編集し、全体54/58/12秒の尺と保存当落を維持。長髪12姿勢も本編採用済み。[制作と編集](STORY_PRESENTATIONS.md)、[接続・全尺検証と残る範囲](QUALITY_ACCEPTANCE.md)。

下表と末尾は先行段階の記録。人物ステップアップ・回想・エピソード・追跡・救出の「専用映像未制作」は上記5映像に更新された。ただし原機固有の人物・各対戦相手・4モード・捕食や長押しの機構が全て完成した意味ではない。

## 抽選・時間の境界

- ヘソ／普図の入賞記録の当落と保留FIFOは変更しない。新規予告は演出用hashで選び、遊技RNGを使わない。
- 赤・金の予告は外れにも出る。早い予告から復活・プレミアを識別できる情報を表示しない。確定側の分類は保存された当選だけで許可する。
- 月影の新しい保留色・前予告の出現割合は独自制作値。原機の出現率や測定済み信頼度として案内しない。複数予告の組合せ信頼度を単純に足さない。
- 54秒／復活58秒／即告知12秒と上部19–24秒（即告知4–9秒）を保つ。液晶の攻防は上部中も進み、小さい矢印で案内する。
- 前予告を読む最低時間を確保するため、予告のある変動だけ表示用の変動尺を確保する。機構の開放期限・入賞済み乱数・獲得計算は延長しない。
- 新しいSE・PUSH操作・原作キャラクター・実機映像は追加しない。

## 独立統合検証

`prototype/tests/prediction-integration.test.js` は実際の `SessionGame`、`createBoardFlow`、`attachNormalSpin` を接続し、2026-10-05に7テストが成功した。通常／RUSHの当選・外れについて旧経路との入賞記録・当落・遊技RNG呼出数を比較し、4保留のFIFOと実描画用保留adapter／消化時予告の一致、当選保留の一致、チャージと保証普図の保留予告除外、許可ルート、保存プランの引継ぎ、54／58／12秒、一時停止、普図当選後の8秒開放期限、チャージの分離を確認した。

これは描画を伴わない実制御の検証。保留の予告輪・印の描画と全回転レイヤーのコード接続は確認したが、文字の読みやすさ、段階予告の視認性、全回転の実描画、スマートフォン実機、長時間遊技はこのテストの合格範囲に含めない。実際の画像・動画を確認した統合担当が最終的な接続状況を追記する。

## 統合担当の最終接続・実画面検証

本編の保留表示に青輪／赤輪＋菱形／金の二重輪を接続。消化中も同じ入賞IDの予告を維持し、チャージと保証された普図は表示を除外する。短いリーチは図柄のみ35%／人物32.5%／影32.5%の演出専用配分で、同じIDなら当落に関係なく同じ入口。発展のない図柄リーチを人物演出で全件置き換えない。

プレミアの約1/3を全回転として実描画。45.5–51.7秒に3列が同じ番号で下向きに増えて777に止まり、保存当選を既存の大当り・RUSH獲得へ渡す。他の月／剣プレミアはそのまま残す。途中予告の文字が液晶斜辺に欠けない位置へ修正し、RUSHの記号は残回数表示の下へ配置する。元の長髪の静止画を入口に使い、戦闘atlasの人物品質未合格は別の残作業として維持する。

最終ソースで全357テスト成功、ビルド成功（従来の大きいbundle警告あり）。Chromeで本編9ケースを確認：通常の赤継続→クライマックス→外れ、人物導入の外れ、図柄のみの外れ、影導入の当たり、エピソード系、闇の特殊導入、全回転当たり、RUSH探索→外れ、RUSH即告知。全件で当落・実獲得への転送・会計整合、JavaScriptエラー0を確認した。

これは当落・経路を指定した開発用の本編確認。通常短尺・RUSH即告知は等速で決着まで再生、長尺は入口・途中・全回転・決着の時刻へ移動して確認する。今回の全54秒連続再生・自然入賞頻度・長時間遊技・スマホ実機の確認ではない。根拠は `prototype/reference-review/predictions-2026-10-05/browser-check.json`（9ケース、変更コードhash付き）と同フォルダのPNG／動画。生録画から液晶周辺を切り抜いた等速・無音の確認動画を用意し、320／736幅で各3本、計6回の再生とエラー0を確認する。

掲載全項目の名称置換だけで専用演出を完成扱いにしない。上表の個別エピソード、捕食・救出、4モードなどの専用素材・経路は引き続き未制作。クラウド更新・pushは行っていない。
