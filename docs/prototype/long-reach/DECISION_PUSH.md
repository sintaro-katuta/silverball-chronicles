# 決着PUSHと赤金・虹色の光

2026-10-06。ユーザーの「熱い演出後に押せ、押さなくても続く、当たりか外れ」「虹色や熱い演出が薄い」という追加指示を本編へ実装した。PixiJSを維持し、既存の一撃をボタンと光で際立たせる。

## 接続範囲と動作

通常/RUSHの戦闘リーチの逆境・先手・互角が対象。通常敗北と復活にも同じ受付を出す。短い図柄リーチ、直当たり、即告知、プレミア/全回転は対象外。

| 表示時計 | 展開 |
| --- | --- |
| 43秒〜 | 赤金の液晶縁の光が強まり、最後の構えに集中 |
| 46.5〜49.9秒 | 「押せ」・残り秒数。受付約3.4秒 |
| 押下 | 表示時計を49.92秒へ進め、50.2秒の一撃を放つ |
| 50.85秒 | 押下時だけ振り抜き後の待ちを省き、51.7秒の結果へ |
| 51.7秒〜 | 当たりは虹色と大当り文字。外れは赤金が消える |
| 復活55.7秒〜 | 最初は敗北のまま、復活で初めて虹色 |

未操作は54秒/復活58秒の既存展開へ自動進行する。押下時は待ちを短縮するため、以前の「すべて54/58秒固定」という制作記述に対する明示的な追加仕様となる。最後の一撃の接触保持・振り抜きは省略しない。

ボタンはネイティブHTMLを実際の液晶座標へ投影する。全体・盤面・液晶の各ビューに追従し、最低64×48px。タッチ/クリック/Space/Enter、フォーカス表示に対応。一時停止中は受付を無効にし、表示時計/光/残り秒数も停止する。台の破棄時にイベントとボタンを除去する。

## 当落と光

PUSHは当落を選ぶ操作ではなく、入賞時に保存済みの結果を見せる操作。遊技乱数を呼ばず、記録/FIFO/残り回数/払い出し/V入賞条件を変更しない。進めるのは演出時計だけで、ゲーム/物理/機構時計は実経過時間で進む。

赤金の縁・ボタン光は当落共通。虹色は結果判明後の当たりだけに使う。復活前の敗北は通常敗北と同じ見た目にする。300玉チャージをこの大当り虹色へ含めない。液晶内の光条・きらめきと筐体照明を連動させ、顔の中心を空ける。全画面の高速明滅は使わず、局所の光を2Hzで変化させる。演出軽減時は色を残し、回転/きらめき/押下波紋を抑える。

## 検証

検証結果と録画は `prototype/reference-review/decision-push-2026-10-06/` に保存する。単体検証では当たり/外れ共通の受付、対象外経路、一回限りの入力、未操作の尺、復活の秘匿、通常/RUSH×当落×操作の8組で保存当落/乱数呼び出し数/会計/機構時計を確認する。

本編のブラウザ検証は、通常当たりの全尺タッチ、通常外れのSpace入力、RUSH当たりの時間切れ、RUSH外れの3ビュー、復活、演出軽減の6ケース。レビュー用に入賞当落を固定し、最初以外は43秒へ表示時計を移してから新しい受付/一撃/結果を連続再生する。自然遊技での信頼度計測ではない。スマホの画面幅を模擬したChrome検証であり、実機タッチ/Capacitor/音の実聴取は未確認。今回、新しい音は追加しない。
