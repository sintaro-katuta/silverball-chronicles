# 公開版の遊技フィードバックへの対応

対象：公開版1番台、PCと390×844。ユーザーの実遊技は467球/6変動/大当り0回。ローカルで修正・検証後、ユーザーの「公開版に反映させて」の今回の明示許可を受け、2026-10-07に公開版へ反映した。

## 修正

- 下部バーに持ち玉、発射中/停止中、発射停止/開始、一時停止、左打ちの強さを集約。全体/盤面/液晶のどの表示でも情報パネルを閉じたまま操作できる。バーと上部表示切替のための領域を確保し、盤面を隠さない。
- 案内は始動口への入賞待ち、図柄変動、停止、リーチ、右打ち、休止、玉切れへ追従。未告知の当落を参照しない。右打ち中は左強度スライダーを無効にする。
- 実入賞時に青白い入口の光を出す。受理された変動だけに約.35秒の保留への光を重ね、保留到着リング/既存の図柄始動とつなぐ。満保留で受理されなかった玉に架空の保留を増やさない。
- 通常待機の雲・水・髪の動きを1.4倍の時計で再生し、背景に約1%の緩やかな呼吸を加える。強い予告や当選示唆を待機へ追加しない。控えめ設定では背景時計と移動光、玉の尾を止める。
- 銀玉の明るい縁と最大7 worldの短い尾で流れを見やすくする。球半径や衝突位置は維持する。
- 台詳細に戦闘/PUSH、大当り/払い出し、RUSHの体験入口を追加。新しい独立セッションで指定演出を再生し、「演出体験中」「体験用玉」を表示する。終了後に本遊技を開始すると通常抽選/400球/獲得0へ戻る。体験で指定した抽選を通常セッションへ持ち込まない。

## 自然入賞

初期.20、口幅20、101釘、半径1.8、発射.6秒、右打ち、抽選、保留、賞球は維持する。液晶下へ左右の短い樹脂受けガイドを追加し、重力とカプセル接触だけでヘソへ送る。吸引、軌道置換、入賞注入は使わない。前面の線幅1.2は衝突半径.6と合わせ、支持の淡い幅3は背面に描く。

強度.18〜.26、口幅24/28、命釘間隔−1〜−3/＋2/4/6、短いガイド12/20および延長42の候補は十分な改善が得られず不採用。長さ28の候補は入賞を増やしたが、高速発射.12秒の排出検証で外端と道釘の間に1球が止まることが判明。外端を5 world上げ、釘との隙間を確保して再検証した。入賞率の良い一条件だけで採用しない。

再現スクリプト：

```sh
cd prototype
node tools/feedback-calibration.mjs verify
node tools/feedback-session.mjs
node --test tests/heso-calibration.test.js tests/compact-board.test.js tests/lcd-flow.test.js tests/rush-physics.test.js
```

固定120Hz、300秒自然発射＋45秒排出で開始位相0/.175/.35秒を比較。別に400球開始から玉切れまで、固定外れの.9抽選と通常演出配分で入賞・保留消化・結果・玉数を比較する。通し検証は大当り供給の影響を除く校正であり、自然抽選の成績保証ではない。

## 表現の根拠

ユーザーの体験を第一の根拠とする。`web-pachinko-design` の motion-and-sound（D2/D4/D5/D6、V1〜V4）の「状態ごとに主役と次の状態への出口を設計する」原理、reviewの現在のコードで静止画/連続再生/停止復帰を確認する手順を使った。ガイド寸法、光の.35/.4秒、尾の長さ、背景の呼吸、体験入口は本作への提案で、参考実機の寸法・秒数・入賞率とは扱わない。
