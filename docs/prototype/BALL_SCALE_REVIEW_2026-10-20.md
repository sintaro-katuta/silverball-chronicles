## 最新のコードとブラウザから確認した寸法

数値は盤面の内部座標。実寸mmや実機採寸ではない。Chromeの現在の実行モデル・テクスチャのalpha領域を読み取り、当たり判定と見える部分を分けて確認した。

| 項目 | 確認値 |
|---|---:|
| 球の当たり判定 | 半径1.8、直径3.6 |
| 球テクスチャ全体 | 28×28px |
| 球の不透明領域 | 27×27px |
| 球のSprite縮尺 | `(1.8 / 4.6) / 3` |
| 球の見える横幅 | 約3.522内部単位 |
| 釘頭の不透明領域 | 13×13px |
| 釘頭のSprite縮尺 | `0.52 / 3` |
| 釘頭の見える横幅 | 約2.253内部単位 |
| 釘軸の当たり判定 | 半径0.2、直径0.4 |

球の見える幅は当たり判定直径より約2.2%小さい程度で、描画だけが半分になっているような差ではない。釘は見える頭と接触軸の大きさが違うため、「釘頭の隙間」と「接触上の通過余地」を同じ値として扱えない。

風車中心は `(64, 476.5)`。風車直上の左右に平行な列の下側3組を候補として計測した。

| 候補の釘番号 | 中心間隔 | 見える釘頭間の隙間 | 球の見える幅に対する比 | 接触軸間の隙間 |
|---|---:|---:|---:|---:|
| 60 / 54 | 10.25 | 約7.997 | 約2.27個分 | 9.85 |
| 62 / 55 | 10.25 | 約7.997 | 約2.27個分 | 9.85 |
| 63 / 56 | 10.25 | 約7.997 | 約2.27個分 | 9.85 |
| 上側候補37 / 38 | 11.0 | 約8.747 | 約2.48個分 | 10.6 |

ここで「見える隙間」は不透明領域の横幅を用いた外形間の計算で、全ピクセル形状・光・動画のモーションブラーを測る値ではない。候補3組の接触軸間9.85は、当たり判定直径3.6の約2.74倍。ユーザーの「今は玉2個分くらい」という見え方と整合する候補があることは確認できた。参照動画の正しい比率、変更後の球径・倍率はまだ確定していない。

## Issueに引き継ぐ確認と受入条件

1. 比較動画・時刻と対象の釘列を同定し、参考側の玉径／同位置の釘間隔の比を測る。遠近・奥行・拡大率・ブラーを区別し、実寸を捏造しない。
2. 見える玉・釘頭・接触軸の比率と、球の衝突径を同じ図で説明する。表示だけ拡大するか、接触・盤面縮尺を含む改修が必要かを根拠から判断する。
3. 代表部位の同倍率の前後比較を作ってから、変更範囲と試射条件を決める。隙間だけに合わせて球径を約2.3倍にする結論へ飛ばない。
4. 改修する場合は発射通路・風車・道釘・ヘソ・一般口・右打ち・V/アタッカー、滞留・逆戻り・液晶侵入・計数・会計まで確認する。釘の隠し移動、吸引、入賞注入で大径化の不整合を埋めない。
5. PC・スマホ幅の実表示と接触の両方を確認する。参照未同定・球径未変更・未試射を完了済みの改善と混同しない。
