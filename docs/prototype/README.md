# 月影機関 — 縦持ちパチンコ・ローグライト試作

> **2026-10-01 現在の入口**：`/` はPixiJSの台選択・盤面・演出を接続した版です。SEは未搭載。旧ステージ報酬・強化・保存の接続は次の単位です。[接続範囲と検証](PIXI_SESSION_INTEGRATION.md)を優先してください。以下のPlayCanvas・旧操作説明は移行前の記録です。

iOS / Android 向けオフラインアプリのプロトタイプです。PlayCanvasで筐体・釘・玉・立体文字を3D表示し、Engineの更新イベントから120Hzのゲーム更新と、速度に応じて細分化する盤面物理を実装しています。Capacitorで同じゲームを両OSのアプリに組み込みます。

実機再現の基準と試作の相違点は [実機との照合と改修方針](REAL_MACHINE_AUDIT.md) を参照してください。現在の実装には簡略化とゲーム独自の例外が残っています。

## まず遊ぶ


## 実装済み

- 3コース、順次解放、各10ステージ。釘配置・抽選確率・出玉規模・変動テンポが異なる。
- 立体筐体、クローム・成型樹脂・導光レンズ、釘、銀玉、液晶、オリジナルの架空作品ビジュアル。リーチ／大当り／RUSHと枠の発光を同期。
- 液晶図柄は大きな縦スクロール表示。説明用の部品名や液晶下部の確率・保留数テキストは外し、保留ランプを残す。筐体全体と液晶を共通の投影寸法で配置。
- 物理入賞、一般入賞口・始動口・アタッカー、自動／ホールド発射、手動調整。
- 液晶と枠には当たり判定なし。液晶の手前にも釘を配置し、玉と釘を映像の前に描画。
- 接触で回転する風車2基。盤面左下の発射口から左側レールを通し、上部キッカー・反射材との衝突で強さに応じて左右の経路へ分かれる。右側は無釘の透明ガイドからアタッカーへ流下する。
- レール・扉・入賞口の縁を物理データから描画し、玉同士の衝突と見えるアウト口を実装。固定経路への吸着や位置補間は使わない。
- 弱すぎて発射側へ戻った消費玉は返却口から持ち玉へ戻す。追加玉には返却による持ち玉増加を付けない。
- 警報→敵登場→交戦→劣勢→覚醒→必殺技→決着の戦闘リーチ。生成イラストの寄り・切り替え、斬撃・火花・発光と前面に降りる月の装飾役物を同期。
- 通常時の大当り抽選、ラウンド振り分け、10カウントまたは15秒でラウンド終了。
- 20種類のスキル。均等な重複なし3択、再取得でLvアップ、最大Lv5、リロールなし。
- 持ち玉の純増によるステージ突破。超過分も持ち玉として保持し、次の開始残高から新たな増加目標を設定。大当り・盤面を持ち越し、スキル選択中は停止。
- ステージ下限未満（または0玉）が3秒続くと終了。下限以上かつ1玉以上に回復するとリセット。ポーズ・スキル選択中は停止。
- 出玉の節目・突破時にチケットを即時加算・保存。ポーズ／スキル選択から精算して永続強化へ。精算・敗北で獲得済みチケットは減らず、無賞球は0枚。
- 6項目の永続強化とローカル保存。

## 試作上の仮設定と省略

以下は要件として確定した数値ではありません。まず遊んで調整するための設定です。

| 項目 | 試作設定 |
|---|---|
| 初期持ち玉 | 400玉 |
| 発射 | 100 × 1.6^(ステージ−1) 発／分、四捨五入・上限6,000。基準値はデバッグで変更可能 |
| 大当り確率 | 1/199、1/229、1/259 |
| コース別出玉倍率 | 1、2.5、6 |
| 一般・始動・大入賞口の基礎賞球 | 4・2・15玉。コース倍率と強化による増加はゲーム加算として別記録 |
| ステージ目標 | 開始時の持ち玉 ＋ round(200 × 1.5^(ステージ−1) × コース倍率) |
| ステージ賞球倍率 | 1.5^(ステージ−1)。各入賞のコース・スキル・永続補正後の賞球に乗算。大当りは開始時のステージ倍率を終了まで固定 |
| 下限ボーダー | max(0, ステージ開始時の持ち玉 − 初期持ち玉)。下限と同数なら安全（0玉は除く） |
| 大当りラウンド | 4R:45%、6R:35%、10R:20% |
| 各ラウンド | 10カウントまたは15秒、ラウンド間0.65秒 |
| チケット | 賞球あり：max(1, floor(√(累計出玉/100)))＋突破数×3、その後永続強化倍率 |
| 永続強化 | 最大Lv10、費用3＋現在Lv×3枚 |
| 初期持ち玉強化 | 1Lvにつき25玉 |
| 賞球・チケット強化 | 1Lvにつき5% |
| 突破時補給 | 1Lvにつき5玉、最終ステージは補給なし |

- コース別の**チケット倍率は未採用の仮実装**。出玉の差から報酬に差が出ます。
- 少数の賞球は端数を内部で持ち越し、整数になると払い出します。
- スキルの倍率は加算。永続強化の賞球倍率も同じ加算枠です。
- 「宴の延長」は各ラウンドの制限時間だけを延ばす仮実装。カウント上限は変わりません。
- 「外れ貯金」は獲得出玉として計上、「玉の帰還」と突破時補給は計上しません。この集計範囲は試作の仮判断です。
- 盤面の玉はステージ間で位置・速度を保持。超過分と突破補給を含めた持ち玉を次ステージの基準にし、一度の大量出玉でステージを連続突破しない構成です。
- 右側始動口と100回転RUSHを実装。基礎1/66、当り消化後に100回転へ戻ります。保留と変動中の予約数を残り回転数以下に制限し、101回目の抽選を作りません。通常保留はRUSH中に停止して保持します。V入賞・時短・LT・声優ボイスは未採用です。
- 大当りR数は当選時に確定し、4→6→10の段階告知を行います。途中でR数を新規抽選する旧方式は撤去。保留5個、深い可変天井、スキルはゲーム固有の設定です。
- 追加発射は無料玉の待機数として保持し、0.15秒以上の間隔で同じ発射口から出します。オート時は追加玉にもラウンド間の止め打ちを適用します。
- 見た目は立体表現の試作段階。映像演出は生成イラストをそのまま使い、カメラ移動・斬撃・火花・発光を重ねる方式です。キャラクターの仮3Dモデルは撤去しました。手足が動く連続作画ではありません。
- 物理は盤面内2D、描画は3D。発射から排出まで同じ重力・接触計算を使います。奥行き運動、釘のしなり、実機の盤面傾斜・実寸の再現は対象外です。
- 玉数・目標・成長ペースは未調整。仕様の30〜60分、未強化での高難度、最大強化でも失敗するバランスを保証する段階ではありません。
- 署名・配布・ストア提出は未実施です。

## 保留・図柄停止の更新

始動入賞は変動中1回＋保留最大5個。図柄の下に5個のランプを表示します。満杯時も賞球は得られますが、それ以上の抽選は追加しません。ハズレ図柄は停止後も保持し、0.85秒の停止時間後に次の保留を開始します。試遊サポートの「始動入賞を6個試す」で確認できます。図柄は左→中央→右の順で停止し、左・中央が揃った後に右の結果を待つリーチへ進みます。釘・入賞口は機能に沿ってコースごとに配置し、シーソーは撤去しました。

[採用遊技フロー](GAME_FLOW_PROPOSAL.md)を実装しました。初当り4Rは50%の突入チャレンジ、6R・10RはRUSH突入。RUSH中は4R/6R/10Rを20/30/50%で抽選します。専用背景・残数・連数・獲得出玉とBONUSの消化状況を表示し、最終Rや突入結果を告知前に見せません。

### 画面・入賞口・演出の追加調整

全体／拡大、手動調整を開いた状態も一画面に収まるよう、実際の表示領域と操作部の高さから台のサイズを計算します。一般入賞口とヘソは上が開いたU字の受け口です。戦闘には剣の残像・火花、敵の圧力表現、覚醒光を追加し、ゲーム時間に同期します。

「調整」の「基準発射速度（発／分）」で10〜6,000を指定できます。初期値100、今回のプレイのみ有効。発射間隔だけを変えます。オートの止め打ち中は設定速度より発射数が下がります。

## チケット獲得の改善（2026-09-23）

通常モードで賞球を1玉以上得た時点からチケットを受け取れます。出玉の節目・突破ボーナス・強化分の累計報酬が増えた分だけ即時に加算・保存し、結果画面で再加算しません。遊技中には今回獲得分と所持数、結果には内訳を表示します。精算して永続強化へ戻っても獲得分は保持します。無賞球・試遊・無限は0枚。デバッグ開始後は追加報酬がなく、それ以前の確定分は保持します。

「調整」を変更なしで適用した場合と、音量・確定音の重さだけを変更した場合はチケットの対象です。発射速度や持ち玉・抽選などの変更、大当りなどの強制操作は従来どおり対象外です。

## ステージ成長と途中精算（2026-09-24）

- ステージ突破は累計出玉から持ち玉の純増へ変更しました。初期400玉ならステージ1の目標は600玉。ちょうど600玉で突破した場合、ステージ2の目標は900玉・下限200玉です。
- 賞球×1.5、必要な増加量×1.5、発射速度×1.6を各ステージで適用。発射は1発1玉のまま、物理・演出の時間は加速しません。自動とホールドで共通、保留・ラウンド境界の止め打ちは維持します。
- 「最後のひと押し」は現在の下限までの余裕が初期持ち玉の20%以下になった時に発動します。
- 長期無限プレイの数値発散を避けるため、必要増加は1兆玉、賞球倍率は100万倍、発射速度は6,000発／分を上限にしています。
- ポーズまたはスキル選択の「精算して強化へ」でプレイを終了し、獲得済みチケットを使えます。強化は次回のプレイから反映します。途中プレイの再開保存はありません。
- 倍率・発射速度の伸び・下限幅は調整用の仮値です。以前の「リタイア0枚」「累計出玉で突破」の記述よりこの節を優先します。

### 発射レートの上限拡大（2026-09-24）

上限は600から6,000発／分へ変更。ステージごとの伸びも×1.6へ変更し、ステージ1は100、2は160、5は655、10は6,000発／分になります。発射間隔の余り時間を次の更新に持ち越し、高レートで実発射数が設定値より低くなる端数落ちを修正しました。

高レートでは玉同士の衝突が増えるため、右打ち中は発射済みの玉を実際の入賞・排出まで予約数に含めます。途中の軌道予測でOUTと判定されただけでは次の玉を追加せず、RUSH残数やラウンド上限への過剰発射を防ぎます。

通常時と手動調整では最大6,000発／分。自動調整の右打ち（大当り・RUSH）は、狭いレーン内の衝突でほとんどの玉が戻ってしまう挙動を避けるため、発射間隔を0.1秒以上（最大600発／分）に調整します。表示のステージ発射レートは上限で、右打ちの調整や止め打ち中は実発射数が下がります。

### 大当り中のステージ倍率固定（2026-09-24）

大当り開始時のステージ賞球倍率を保存し、全ラウンド終了まで固定します。途中でステージを突破しても、その大当りの大入賞口の賞球はステージ倍率によって増えません。通常入賞・始動入賞・RUSH入賞、および次の大当りには新しいステージ倍率を適用します。同じRUSH内でも大当りごとに取り直します。スキル選択・ポーズ・ラウンド間の待機では固定値を維持します。

コース・玉・スキル・永続強化の補正は従来どおりです。画面の大当り中の賞球倍率は固定値を表示します。例：ステージ1で始まる10Rは、賞球補正なし・100入賞なら途中でステージが進んでも1,500玉です。

### 入賞部と保留ランプの視認性（2026-09-24）

ヘソと一般入賞口は上が開いたU字を維持し、縁・奥行きとヘソの発光を強めています。釘の金属頭部と座金は全て揃え、風車の軸と羽根を目立たせています。右打ちアタッカーは受け口を44から60盤面ピクセルへ広げ、閉時には前面扉が開口を覆い、開放時には口と扉が見えます。見える受け口幅と物理入賞幅は同じ値です。

保留が増えた時に点灯し、消化で繰り上がり、受付から少し後に青・白・金へ変化することがあります。色は抽選済みの結果と対応する期待度演出で、金色でも当り確定ではありません。演出にゲームの抽選用乱数は使わず、当選確率・保留上限・通常とRUSHの保留分離は変更しません。動きを減らす端末設定ではランプのアニメーションを停止します。
