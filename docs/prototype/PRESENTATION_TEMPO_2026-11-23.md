# 演出テンポ調整（ローカル）

目的：長い待ち時間を減らし、結果までの流れを軽くする。既存の当落・保留・賞球・物理時計は維持する。

対象は通常／RUSHの戦闘リーチ。代表は通常の戦闘外れ。従来の演出時計0〜5秒は導入、5〜43秒は戦闘、43秒以降は決着の準備・PUSH・当落とする。戦闘区間だけ2倍で進め、映像も同じ速度にする。通常54→35秒、復活58→39秒（いずれもリーチ開始から、未操作時）。即告知12秒、短い図柄リーチ、前段の変動時間は変更しない。上部演出・音の打点は既存の演出時計に従う。D2の緩急と映像・音の同期を本作向けに適用した仮調整であり、実機の秒数を根拠にしたものではない。

受入条件：保存された当落と保留順・乱数消費を維持し、PUSH・自動決着・ポーズと復帰が成立すること。実画面で戦闘から決着までを確認し、速度や音の聴き心地は人の試遊で判断する。スマホ実機・音の実聴取は未確認。

検証：ローカル候補で通常・RUSHの当落、PUSH・自動決着、ポーズ、保留FIFO、乱数、物理時計を自動テスト。390×844のヘッドレスChromeで入賞を起点とする通常外れを最後まで再生し、warning・battle・defeatの動画表示、外れ結果、収支整合、ページエラーなしを確認。これは実機での見た目や聴感の評価ではない。ビルド成功。

右打ちでは決着が早まるため電チュー開放の開始も早まる。開放期限は物理時計のまま。旧固定待機を開放発生待ちに更新した入賞〜3000玉のテストは合格。全テストは長時間実行中に中断したため未完了。候補の画面・聴感、勝ち・復活の実再生と自然遊技の通し評価は残る。
