# シンセ音色への統一（2026-10-06・最新のユーザー指定）

「前の方がよかったかな」「鈍い感じではなく、音色をこうシンセだけにして欲しい」を最新方針として採用。前回の硬い金属への寄せ方を撤回し、当たりの明るい返しを戻す。本編70音名と支えの音を、明瞭な周期波のシンセ音色へ統一する。以前の素材感/金属の擦れ/粒状テクスチャという採用方針より本節を優先する。効果音と支えの音への指定であり、全画面の演出や抽選ルールの変更ではない。

## 音色

- 当たり：前の1174.66/1567.98/2349.32Hzの明るい返しへ戻す。鋭い金属倍音・摩擦・48Hz付近の低域の衝撃・素材波形の連打を外し、周期波の上昇音、シンセの短い5連打、ユニゾンのリード、持続する明るい返しを使う。識別リズム・通常/RUSHの区別・4音型・ピーク目標は維持。
- 通常予告/斬撃/機構/復活など：音名ごとに周波数・ピッチ変化・シンセの発音順序・波形の明るさを割り当て、物理素材の複数の響きや低い打撃、録音風の擦れを使わない。カタログのkindは画面の動作分類として残す。素材音に使っていたbody/metal/air/roomパラメータを撤去する。
- 支え/溜め：空気ノイズと刃の共鳴を、周期波のシンセパッドへ変更。帯域と再生速度の開きで既存の溜めをつなぐ。
- 音作りは `synth-wave.js` の周期波、発音包絡、左右のユニゾン、短い電子ディレイを共通に使う。ノイズ・録音素材・素材波形の加工・低いキックは本編音色から外す。波形の倍音はレンダー時の帯域上限内に制限する。

音量を強めて鈍さを隠す変更ではない。通常/RUSH当たり0.54/0.51のピーク目標、背景を引くミックスと優先度、消音/一時停止/破棄、結果が公開される時刻、直前の静けさは維持。4音型の反復回避・保存当落・保留・機構・出玉は変更しない。

## 続く音域調整：少し高いという指摘

「悪くないけど、ちょっと音が高い」を受け、シンセの質感と明るさを保って当たりの全主音・返しを3半音、通常演出SEを2半音下げる。高次倍音の係数も10%抑える。支えの基音、連打の間隔、音の長さ、エンベロープ、ピーク目標と当たり公開時刻は維持。再生速度で音を下げず、合成時の周波数だけを変えるため演出との同期は動かない。変更前の高いシンセ版→調整版の比較WAVと、49.5秒からの決着確認動画で確認する。
