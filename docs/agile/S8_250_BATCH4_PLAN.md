# S8・250発比較 第4組：小幅の比較と優先案の事前固定

目的と守る条件は主計画S8_250_PLAN.mdに従います。目標は3条件各250発の合計60ヘソ以上と全条件変更前非悪化。元101本/原属性、左上の狙い、発射0.18、球/既定表示/物理、従来レール・壁・風車・口20・既存皿を固定します。変更は釘だけ、各原座標から1以内です。内部座標を実測mmと呼びません。

第1組46左0.25は確認43→55/750で未達、第2組下0.25は43→37、第3組46左0.25＋48下0.25はphase0では25/250でも確認43→40で不採用でした。phase0最大を選び直すだけで安定改善とは言えないため、今回は6案の数値と、確認へ進む優先案を結果前に固定します。移動量と入賞数の比例を仮定しません。

## 固定候補と進め方

元配置と46左0.25単独をfresh phase0各250発で対照として測ります。新案はmanifest順の6案、46左0.25＋48上/下/左/右の各0.125が4案、46単独左0.125と左0.375が2案。各案は元配置起点、前案から累積しません。既存guard静的PASSを動的安全性/入賞効果の証明にしません。

確認優先案は **46単独左0.125** と事前固定します。既存bestの半分の移動で、本数と総移動を最小化する仮説です。phase0では効果と副作用の観測だけを行い、他案が高い値でも今回の確認案へ差し替えません。優先案の動的安全/狙いに問題が無い場合だけ、phase0.175/0.35/0.525のfresh元配置と各250発確認します。phase0の入賞数を確認の入口条件にはしません。3条件合計60以上・全条件変更前非悪化・安全・未解決副作用無しを採用条件とし、未達後にphase0最大案へ乗り換えません。

3開始条件は以前の別案で観測済みで、統計的独立性や実機確率を保証しません。今回の優先案は結果前に定め、確認の結果を選別に混ぜません。新6案全てを隠さず報告します。

各変更前に内容を示し、各実行は単発、終端ごとに実発射数/ヘソ数/基準差/安全をチャットへ報告します。実spawn250到達step停止＋45秒排出、300秒で250未達は失敗・実途中数を記録し要求250を分母へ置換しません。source/HEAD/計画/manifestを凍結し、shot250-batch4/へ実行版・原JSON圧縮と両SHA・全実終点を保存。測定中のsource変更/commit/重い撮影やテストは禁止です。

目標未達は未達で、有限比較の終了を改善達成とはしません。本編配置を維持し、試した範囲と残る仮説を整理します。安全条件や球/構造を変えて数字を満たさず、別仮説が必要なら事前に限度を定めます。採用時は現画面/回帰/新CIと人間承認後の新動画・PRを別途確認し、本番公開・mainmergeは行いません。
