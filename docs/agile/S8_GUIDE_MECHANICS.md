# S8：丸い装飾と連続ガイドの分離

2026-10-24、ローカル実装。ユーザー説明「丸い部分には入らない」「その上には乗らない」「装飾としては存在する」を、それ以前の開口・筒という解釈より優先する。

## 目的と受入条件

左下の丸い部品を消さず、その手前のガイドから液晶下の斜めガイドへ玉を流す。見える線と接触を共有する。保存22本322点と釘101本の座標、玉半径3、ヘソ20、通常強度0.18、初速補正125、道釘反発0.12、軽い風車を保持する。上のキャラクターを玉が通り抜ける指摘も対象とする。盤面全体の詰まり解消は別に判定する。

## 実装

- 保存線は原本のまま保持。左縁終点 `[175,619]` → 丸い部品左側の既存点 `[168.5,646.8]` → 斜めガイド始点 `[174.4,659.1]` を接続し、同じ点列を描画と接触に使用。
- `left-return` は描画を残し、物理接触を装飾として無効化。曲線と横帯を残し、旧表示で開口に見せていた切り抜きを行わない。玉が丸い部分の上に乗る接触面を作らない。
- 上のキャラクターは描画で使う `upperRelief` と同じ輪郭の前面固体。旧粗い上側境界を置き換える。奥の発射通路には接触しない。
- 過去の斜線・小径比較画面は当時の条件を維持するため、旧プロファイルを明示。現在の構造確認はライブ計測版04を使う。
- 接触ソルバー、玉径、釘のオフセットは変更しない。前段の未採用接触実験は今回の実装に含めない。

## 検証

専用・関連14テスト、過去比較4テストを通過。2区間それぞれで半径3の前面玉が装飾側へ抜けないこと、ガイド端点の一致、装飾点列の保持、上側描画と固体の一致、奥発射の非接触を確認。本編と全プレビューのビルドを通過。全体テストは旧比較条件を現在の本編と比較していた2件を検出し、歴史的な比較条件を明示して関連ケースを再実行した。長時間の全体テストは別途確認中であり、全件合格とはしていない。

固定刻みの通常打ち100玉は全100玉が前面へ移り、返却0、排出90、残球10（25秒の排出待ち後）。実際の描画をライブ計測画面でも確認し、こちらは100玉・排出89・残球11で一時停止している。ライブと固定刻みは時間刻みが異なるため別の観測値として記録する。通常打ちの残球も画面に表示し、滞留を隠さない。釘付近を含む盤面全体の滞留解消は未達であり、今回の構造修正の合格と区別する。

計測URL：`http://127.0.0.1:5461/dev/live-measurement.html`。100玉の試射、一時停止、再開、最初からに対応。検証中のコード編集で画面が変わらないよう、起動用のコピーを固定している。
