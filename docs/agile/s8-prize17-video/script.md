# 台本

ヘソへの入賞を増やすため、寄り釘十七本の位置を見直しました。

変更前は釘の左側に当たり、左へ抜ける玉が多かったため、釘を左へ寄せて右側で受けることを狙いました。

釘の本数、玉の大きさ、左上を狙う位置、壁や物理の設定は変えていません。

同じ開始条件の比較では、二百五十発中のヘソ入賞が、十一から十九、五から二十五、十五から二十三に増えました。

確認に使った七百五十発では、三十一から六十七に増え、目標の六十発を超えました。最初の選別に使った二百五十発は、この集計に含めていません。

玉の戻りや残留、停滞はありませんでした。普図への一発も別に数えています。これは固定条件の試射結果で、実機や全ての遊技で同じ確率になるという意味ではありません。

動画では変更前後の流れを見比べてください。特に、寄り釘から道釘へ届く流れと、ヘソへ渡るところを確認します。
