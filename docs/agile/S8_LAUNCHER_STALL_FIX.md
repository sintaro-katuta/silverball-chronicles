# S8 発射直後の滞留を解消する

2026-10-24。ユーザー指示「手前で詰まるの解決しますか」に基づくローカル改修。

目的：保存線で作成した盤面で、発射直後の2球滞留により試し打ちが止まる問題を解消する。

対象：発射通路の接触と奥から手前への移行。保存22本322点、101釘、球半径3、通常強度0.18、初速補正125、ヘソ幅20、風車、反発、盤面の美術と液晶演出は固定する。先に指摘された道釘下の通りにくさを今回の成功へ混ぜない。

基準：c0e3b71。通常強度0.18で6秒間連射すると2球だけ発射し、2球とも奥のままworld y324/329付近で保持。出口/逆流防止部の通過は0、球の最終接触は内側の写真輪郭接触。写真から採った前面灰色部の幅は現在の球径と一致せず、以前の楕円接触との接続もある。2D写真を現在球径の奥通路寸法へそのまま適用していた。

試作：元の楕円による奥の発射内壁を接続し、写真の灰色部は前面接触へ限定する。外側のレール、逆流防止、有限の出口は維持。既存の前後層モデルに沿い、前側へ移るときに前面部品や釘へ球を重ねない。これはこのゲームの奥通路モデルであり、参照実機の奥行きや実測寸法を主張しない。加速・吸着・ワープ・玉の縮小で通過を作らない。

比較の限度：原因に対応した奥通路の接触と前面移行の2点だけを検証し、入賞率を理由に盤面配置を変更しない。

受入：自然発射で30球以上が発射を継続し、出口通過後に奥の球が残らない。既存の球数計数が一致し、弱い発射は物理的に戻れる。通常の開始位相3条件と右打ちを確認。接触と表示の前後層の区別、保存線と設定の維持をテストする。実ブラウザで現在の試し打ちを再開し、出口を抜ける玉を確認する。

## 採用と検証結果

奥の内側レールは既存楕円の欠けていた区間だけを補い、奥の玉だけに接触。写真の灰色部品の形と描画は変えず、前面の玉に接触するようにした。逆流防止と有限の出口通過条件に加え、前側の釘・部品へ球が重なる間は前面へ切り替えない。重力・球速を変える力や位置の飛び越しは追加しない。この補正は保存線プロファイルの大径玉に限定し、旧1.8半径の単独プレビューを維持する。

通常開始位相0/0.175/0.35、RUSH、BONUSの各30球、計150球の自然発射を確認。全150球が奥から前面へ移行し、発射部とworld y290より上に残球0、戻り0。0.6秒の既存発射間隔を維持。弱い発射では無理に前面へ移行せず返却1/残球0となることを別テストで確認。関連テスト33件成功、本編とプレビューのビルド成功。

通常3条件には計54球、RUSHには1球、BONUSには15球が観測終了時点で盤面内に残っている。計数は出た玉と残球の合計で一致する。これらは前面の残球であり、今回の発射部修正を盤面全体の滞留解消・入賞受入とはしない。

実ブラウザの本編と同じmountBoardを使う試し打ちページで、最終ソースを読み込み、連射して上の出口から左の釘領域へ玉が流れることを確認。一時停止と再開も実操作。連射を続けると左下の曲がったガイド付近に玉が蓄積する既知の問題は残す。
