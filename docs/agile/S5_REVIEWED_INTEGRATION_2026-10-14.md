## 内部での利用

`prototype/src/dev/pin-adjustment.js` の `resolvePinAdjustment()` に釘IDと元配置からの移動を指定し、`flowOptions` を描画と実行へ渡します。元配置からの累積移動は1論理単位までです。11mmの玉を仮定した換算を記録しますが、実物のミリ移動と同じ値ではありません。

`prototype/src/dev/pin-adjustment-measurement.js` の `measurePinAdjustment()` で、発射・各入賞・排出・返却・残球・無入賞時間を観測します。設定の発射強度と計測引数が違う場合は拒否します。機械試射を抽選や有限の持ち玉を含む本編成績に拡張しません。

```sh
node prototype/tools/launch-reference-compare.mjs /tmp/rail-comparison
node prototype/tools/normal-route-long-observation.mjs /tmp/strength-comparison
```

前者は従来／参照輪郭の左打ち・右打ちを比較し、後者は上記の固定6条件を再観測します。出力先に生データ・結果・始終ソースの識別情報を保存し、自動で配置を採用したり公開したりしません。
