# S8継続：3枚羽根を保ち、ヘソ入賞を増やす

2026-10-16、ユーザーの「ヘソの入る確率を上げることは引き続き」「3つの羽…それ以外の改善も必要なところで」により、風車の共通形状だけに限定した比較から、必要な下流・寸法比の改善へ対象を広げる。3枚羽根・丸い中央は今後の試射基準として維持する。4枚へ戻すことを改善策にしない。Issue23/S8内で継続、期間は固定せずこの有限1組の結果・検証・次の判断まで。

## 目的・根拠・守る条件

目標は従来どおり3条件各実250発、計750発でヘソ60以上、各条件で同一sourceの対照より減らさないこと。直前のガイドなし旧風車13/250→3枚9/250の差を、ガイド撤去だけでは説明できない。一方で1条件だけで全体傾向を決めない。過去15/250はガイド付きの別履歴。

3枚案では道釘成功接触47→56球、ヘソ近傍21→24球へ増加したが、実ヘソ13→9、近傍通過後の非入賞も増加した。近傍は広い観測帯で入口への整列を保証しない。道末端から90・91/92・口への受け渡しと、玉と釘間隔の比を一変数で調べる。

元101釘の本数/属性と参照配置、左上の狙い、風車中心・3枚の形状・回転/反発係数、発射.18/間隔.6、重力、legacyレール/壁、口20、抽選/保留/賞球を維持する。両側ともヘソ受けガイド・取付板なし。人工の誘導、力、入賞注入、新しい皿は使わない。候補で宣言するID90の位置または球径以外を一緒に変更しない。

Aは元の皿あり条件では静的に不成立だったが、皿撤去後は干渉guardが成立する。ジャンプ相当の受け渡し高さだけの仮説であり、現実の実測移動量ではない。元位置からの変位を累積させず、位置変更はこの1本だけとする。

Bは通常道23隙間の表面間隔3.631〜4.409・中央値3.973に対し、現球径3.6が全て小さいことから選ぶ診断。直径4.0なら12/23隙間を上回るが、動的に支持される保証ではない。実物の11mm玉という規格を変える意味ではなく、未校正の図上比率を調べる。4.09や大径へ飛躍しない。釘と同時調整、速度や反発の調整はしない。

## 実装・比較・報告

旧測定のguardは緩めず、新しい専用比較で宣言4設定だけを許可する。球2.0の内部指定と描画一致を追加し、旧無指定/旧設定の既存JSON・events・replay互換を検証する。既存3枚の当時13/9rawを新sourceへ付け替えない。今回の全依存・計画・manifest・HEADを凍結し、fresh対照を新sourceで測る。

球径Bは発射・右経路の詰まりや逆戻りも変わり得るため、3枚基準とBをそれぞれ右打ちrush/bonusで30秒自然発射＋45秒排出の固定条件で先に確認する。実試射数・ヘソ数（右の通過確認であり左の性能ではない）・各入賞/OUT/返却/残球/滞留/LCDを報告。基準にない残球・滞留・LCD侵入や返却悪化があればBの左250比較は不実行とし、失敗を残す。人工の消去で成功にしない。

成立した設定を上表順にphase0で各実250発。250spawn stepで止め＋45秒排出、最大300秒で未達なら実途中数/失敗のまま記録する。1回ごとに試射数・ヘソ・両対照との差・一般/OUT・安全を報告してから次へ進む。測定中はsource/計画/manifest/HEAD変更・撮影・重いテストをしない。

候補のヘソが同sourceの両対照を厳密に上回り、安全と狙いを維持する場合だけ、最多ヘソ→同率なら局所変更のA優先で新1案を選別する。phase.175/.35/.525で旧形状対照・現3枚基準・選別案を各250発（計9件）確認。合算60/750以上、各phaseで両対照のヘソ非悪化・返却比非悪化、残球/滞留/LCD4区分0、全計数一致を要求する。一般/OUT/最長無ヘソ・基礎賞球の差も開示し、未解決の副作用は採用保留。既知位相であり、統計的独立性や実機確率へ一般化しない。

有望なし/確認未達なら、この組の失敗を報告し、次の根拠を読み取る工程へ戻る。AとBを結果後に合成したり、次善へ黙って乗り換えたり、目標を下げたりしない。3枚形状の維持指示と入賞性能の未達を区別する。新たな具体案が必要なら、変更と比較範囲を提示してから最新の継続指示内で進める。
