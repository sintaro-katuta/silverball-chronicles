# 0.5.0 公開後スモークの動画ロード修正候補

main `361fabe` の CD 実行 44670377414 は attempt 1 の390幅、attempt 2 の1440幅で、公開 URL の `serena-bonus-extended` が `net::ERR_ABORTED` となりスモークに失敗。初回で Cloudflare Version `d357245d-ee78-440a-bea9-574a232e85b7` はデプロイ済み、GitHub Release は未作成。attempt 2 の390幅・操作検証は成功したが、1440幅失敗を全体成功として扱わない。

公開 URL の Chrome では中断後に同一動画の HTTP 200 応答と `readyState=4` を観測。範囲リクエストへ200を返すローカル再現では、修正前の idle・victory に `ERR_ABORTED` が発生。動画 `src` 設定に伴う自動開始と、明示的な `load()` / Pixi `VideoSource.load()` による再開始の重複を除くと、同条件の4回の起動・切替では中断が出なかった。

修正候補は、動画の最初のロードを1回にし、事前取得中の素材はメタデータ到着後に Pixi 側を接続する。Pixi の準備完了前に映像を表示しない。公開後スモークのネットワークエラー判定は変更しない。

ローカル検証：ビルド、関連単体12件、200応答条件の4回の起動と遅延中の戦闘切替、通常・戦闘・敗北・復活・RUSHをPC／スマホ幅で2回、チャージ終端保持、PUSH／保留、動画失敗時のフォールバック、勝利映像、約12.2秒大当り映像の2ループと停止・再開が成功。途中の初回案では通常画面の描画試験が2回失敗し、Pixi の準備を待つ修正後に同試験2回が成功した。スマートフォン実機は未検証。修正はローカル候補であり、公開版には未適用。
