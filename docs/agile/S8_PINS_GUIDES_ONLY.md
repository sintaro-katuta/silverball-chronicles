# Sprint 8：釘とガイドだけを元図へ合わせる

> ガイドの一致判断はユーザーの6部位の指摘で差戻し。以下の設定維持・釘の照合結果と、ガイドの目視受入は別。[ガイド再採寸と最新の証拠](S8_GUIDE_RETRACE.md)。

2026-10-24、ユーザーの最新指示「釘とガイドを合わせて、それ以外は変えなくていいです」を優先する。前段でヘソ幅・玉径・初速まで戻したのは対象を広げすぎたため、その変更を取り消す。

今回の元図合わせは101本の釘の位置と、既存の転記ガイドの位置/形状に限定。釘中心は元図の採寸点、入口は元の2本のガイド、発射上部は元図トレースの既存reference-exitを保持し、独自U字囲い・道釘上の連続支持面は採用しない。

玉半径3、ヘソ幅20、通常初速補正125へ復帰。通常/右の強度0.18/0.85、道釘反発0.12、軽い風車、タイトル非表示、既存の演出・賞球・チケット・BGMは維持。タイトル撤去後の細い左ベゼルと暗い通路の見た目も保持し、ガイドの位置合わせと装飾枠の見た目を分ける。ガイドへ合わせる目的で、他の部品の形状・寸法や遊技設定を変更しない。

84f97c4時点の非配置設定をfixtureへ保存し、本編オプションからpinPositions/launchRailProfile/leftInletRouteだけを除いた全設定が一致することを確認する。全101本は独立した元図の採寸HTMLと比較し、ガイドも既存の転記形状と比較する。

大径玉と元の釘間の不整合は未解決として保持。これを解消するために玉径や釘配置をさらに変えたり、隠れた支持面を足したりしない。前段の基準径1.8の850発を、今回の大径設定の成功結果へ流用しない。

## 確認結果

対象テスト20件すべて成功。本編ビルドとプレビュービルドが成功。実ブラウザの比較画面でも釘101本の差分0、最大差0.000 source px、ヘソ幅20、球半径3を確認した。転記ガイドの接触形状は既存reference-exitと元の入口・液晶境界を保持。比較画面には装飾枠の外形でなく実際の接触輪郭を重ねる。

非配置設定は84f97c4の記録と全項目一致。今回の確認は変更範囲と元採寸座標の一致を対象とし、自然発射の玉戻り・詰まり・入賞の再校正完了は主張しない。元図トレースにもともと含まれる下部発射部の推定モデルは、実機全体の完全再現とは扱わない。
