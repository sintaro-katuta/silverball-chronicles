# ヘソへ届く経路を根拠にした釘配置の調整方針

## 2026-10-18 最新方針：入賞改善の根拠を優先する

ユーザーは「その方針であれば多少構造と一致していなくても、許容し問題ない」と承認した。元図に対する釘の並び・間隔・傾きの多少の差を許容し、まとまり内部の相対位置を完全に保つことを必須にしない。以下の旧方針にある厳密な並び・間隔維持より、この追記を優先する。

変更前に、未入賞の玉がどこで経路を外れるか、対象の釘をその方向・量へ動かすと何が改善するか、期待する観測変化を説明する。安全に動かせることだけを入賞改善の根拠にしない。根拠を持った複数釘の調整を比較し、変更ごとの実試射数とヘソ入賞数を報告する。

元101本の本数・径・反発、玉の大きさ・左上の狙い・物理条件、目標60/750発と各条件非悪化は維持する。今回は釘配置の一致度の緩和であり、外枠・風車・入口の変更や誘導板の追加まで自動で許可されたとは扱わない。過去の比較は当時の条件と採否を残し、この承認を理由に後付けで合格へ変えない。

PBI正本の[Issue23](https://github.com/sintaro-katuta/silverball-chronicles/issues/23)の対象・確認内容にも同方針を反映済み。この方針更新自体は新しい配置の実装・試射・本編採用を示すものではない。

以下は2026-10-16〜17の方針履歴。

2026-10-16のユーザー方針：「釘一本だけの少しの移動では数発差しか見えないため、大きく動かすのを考えたい。ただ構造や本数は変えない」。これまでの微移動比較は履歴として残し、今後の検討にこの方針を優先する。

約束する固定条件：元の釘101本のID・本数・役割・径・反発など位置以外の属性を維持する。釘を追加・削除・別部品へ置換しない。外枠・レール・壁・風車の形状/寸法/中心・ヘソや他の入口形状/位置/幅を変えず、玉を集める誘導部品や力を加えない。玉の大きさ、狙い、発射・物理係数・抽選・賞球も今回の比較では固定する。

大きくするのは釘の位置変更幅。一本ずつの微移動に限らず、役割と列の順序を保った複数釘のまとまりの移動を検討する。まとまりを一体で動かす場合は内部の相対位置も維持する。釘の列を交差・入れ替えたり、壁に見立てた新しい列へ作り直したりしない。対象外の釘は元位置のままにする。

まず元位置から2/3内部単位（球11mm仮定で約6.1/9.2mm相当、実機採寸ではない）を幾何検討する。これは候補量で、実装・試射済みの値ではない。詰まり、釘/壁/口/風車との重なりや通路閉鎖を見て、通せない量や方向は不成立として残す。構造を変えて通せるようにはしない。現在の1単位上限を一律に削除せず、具体的な有限候補と検査条件を先に計画へ固定する。

現段階は候補の読み取り調査。新たな配置の実装・試射・本編適用はまだ行っていない。実比較へ進む際は変更前後で全101本と固定形状を照合し、各変更の実250発/ヘソ入賞数、選別後の未使用3条件750発、安全と副作用を従来どおり記録する。目標60/750発・各条件非悪化を維持し、差が大きいだけで改善と判定しない。
