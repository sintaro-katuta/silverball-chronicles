# S8：釘だけの微差を同条件で読む比較設計

2026-10-16。開始承認済みの [S8_PLAN](S8_PLAN.md) と制作フローに従います。作業基点は9317e6、作業場所は隔離したsprint/S08です。現段階は媒体配線の読取りと設計のみで、新試射・撮影・ブラウザ・音声合成・Remotion renderは未実施です。過去S6/S7画像は今回の検証に流用しません。

## 見せる目的と固定条件

左上の狙いと盤面を保ち、指定釘の小さな配置差が、その後の流れとヘソ入賞にどう対応したかを示します。近くを通ったことだけで入賞の原因と断定しません。元101本と属性、発射0.18、球半径1.8と本編既定表示、legacyレール・壁・風車・口20・既存皿、重力・反発・発射間隔を固定します。新UI・新部品・新ガイドは追加しません。

| 比較案 | 元配置からの独立差 | 局所確認 |
|---|---|---|
| 対照 | 元101本、移動なし | 左上の狙い・枠・入口・ヘソの基準 |
| 道入口 | ID2を下へ0.25 | 対象1本と周辺の玉・隣接釘 |
| ジャンプ相当（事前検査で不実行） | ID90を上へ0.25 | heso-tray-0との干渉でskip。候補/皿は変更しない |
| ヘソ左右 | ID91を左へ0.25、92を右へ0.25 | 口・受け皿を含む直前の通路 |

各案は組み合わせません。移動量は内部単位で、実測mmではありません。釘頭の可視外形と接触軸を区別し、注釈リングはrawの釘中心を実カメラ変換して置きます。数値座標の照合前に「移動した釘の印」として受け入れません。

## 新基準から順に確認する画面

1. **全体**：fresh baselineの実5/7.5/10秒など少数の同時刻画像から、元101・左上狙い・外枠/レール・球表示・既存皿を確認します。最初はbaseline対同じbaselineとし、候補改善の前後と呼びません。PMの代表画面受入後に候補との比較へ進みます。
2. **左上の狙い**：左右同じcrop・倍率・時刻で数球の初飛行を比較します。初反転、実初釘接触、認定できた自由頂点を別に示し、認定不能は不明のままにします。写真の赤ブッコミ/緑強めの相対位置と、流路の良否色を混同しません。既存S7の観察窓を結果に合わせて変えません。毎球同一点や小窓全数一致は必達にしません。
3. **変更部位**：ID2、90、91/92の実座標から局所cropを決め、対照と候補で同じ矩形を使います。隣接釘・口・皿が残る範囲で拡大し、0.25の向きを細い矢印/ID表示で補助します。盤面そのものや釘頭を拡大・縮小して差を誇張しません。静止だけで流路改善を判定しません。
4. **ヘソ直前と同球の終点**：実admission時刻の前後（例：前2秒/後3秒）を保存済み30Hz軌跡から抜粋し、入賞しない対照側も同じ秒で残します。球IDは各試射内の識別であり、左右が同一個体とは扱いません。入賞が無い案はOUT等の実終点をそのまま示します。入賞瞬間のための追加試射をせず、保存範囲内から選びます。
5. **発射停止と排出終端**：短120/165秒、長比較が成立した場合は300/345秒を別画像で示します。途中を省く場合は静止切替/省略と明記し、全窓連続上映とは呼びません。

全体→局所は同時刻の再掲か、連続するカメラ切替かを区別します。動画区間は元30Hzの隣接frameを1倍で再生し、軌跡補間・片側だけの速度変更・物理再計算をしません。終了後の保持は最後の実frameと明記します。

## 媒体の入力検証と描画配線

S7 mediaは「powerだけ異なる・pins/layoutは同じ」を要求するため、そのvalidatorをS8へそのまま適用しません。S8専用の `prototype/tools/s8-media/` へ最小adapterを分離し、S7ファイルは変更しません。既存 `mountBoard({production:true,trialReplay:true})` と `applyTrialFrame` を現基点から読み、rawのflowOptions/pinsを実描画へ渡します。旧映像・旧機械hashを新baselineへ付け替えません。

- 各案の許容movesとraw全101釘の差を照合します。ID2/90/91/92以外、または許可と異なる向き/量・釘属性・本数の差を拒否します。layoutSHAは配置で異なるため単純一致にせず、manifestと各rawの値を照合し、実pin差で比較条件を検証します。
- power0.18、球半径1.8と既定表示（ballRadius opt-in上書きなし）、phase/kind/fixed geometry/その他条件、30Hz/fps/frame数/全実時刻の対応を要求します。軌跡と計数は結果なので一致を強制せず、各frameの発射=全処理結果+残球、玉ID一意、実位置/半径/層/機構角と終端一致を確認します。
- gzip圧縮/展開SHA・bytes、config/layout/source、測定provenanceのsuccess/sourceUnchanged/endSourceSHA・計画SHA・Git始終を照合します。機械入力inventoryはネストしたbase/extra/filesを重複なく展開して始終確認します。
- 描画helper/HTML/位置図/ブラウザ起動設定と、使用public画像/fontの媒体inventoryを機械SHAとは別に始終保存します。描画時のpinsはrawと完全一致。Node/Chromeの固定曲線再生成だけは従来の浮動小数点上限1e-10で実差を記録し、raw同士のpin差検査は緩めません。
- 機械の許可・source凍結・新raw終端と撮影quietを受けてから実行します。撮影終了時はownedChrome/専用serverを閉じ、実行版媒体・読込raw・時刻・SHA・PNG/MP4を保存してquietを返します。

## 結果と最小受入

新しい対照と3案の短全4条件を必ず表示します。選別を通った1案だけの未使用3開始条件の長比較と、短い選別を分けます。長比較の条件別/合算ヘソ率・実発射分母、一般/OUT、返却率、残球/滞留/LCD、最長無ヘソを開示し、悪い条件を隠しません。採否はS8_PLANの規則でPMが判断し、媒体の見栄えを理由に選別を変更しません。

画面受入は同時刻・同倍率の形状/狙い維持、指定釘だけの差、時刻と計数の読み取り、局所と全体の対応を対象にします。静止画像だけを連続動作・自然発生率・実機の保証へ広げません。本編への採用は新本編の別検証が終わった状態で表示し、試射候補・限定採用・公開を区別します。

新PR動画の台本は全結果と採否後に作り、人間承認後にVOICEVOX:ずんだもん（ノーマル）とRemotionへ進みます。現在、台本/音声/依存場面/renderは未着手です。
