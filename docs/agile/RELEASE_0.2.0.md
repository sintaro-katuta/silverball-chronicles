公開先は既存Worker `tsukikage-pachinko`、正式URLは https://silverball-chronicles.sintaro-katuta.com です。ENABLE_PRODUCTION_CD=trueと必要なSecret名2件の存在を確認しましたが、値は読み出していません。前版0.1.0は公開済み、0.2.0の公開成功は今回のCDで判定します。

音の実聴取、スマホ実機、実機寸法・奥行、実運用の故意障害による再開・ロールバックは未検証です。途中再開のローカル模擬試験と、正常公開、実障害からの復旧を区別します。次スプリント#31の案は未承認・未実装で、このリリースへ含めません。
