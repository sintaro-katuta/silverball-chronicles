# 0.5.1 台詳細の体験入口撤去

ユーザー指示により、台詳細の「演出を体験する」と戦闘・大当り・RUSH の入口を画面から取り除く。着席人物の表示は変更しない。通常の400玉開始・チケット・抽選・賞球を維持する。

体験シナリオの公開 UI は設けず、従来 CI の状態分岐と出玉検証を維持するため、表示・フォーカスできない検証用の内部フックを残す。検証は画面上に見出しと入口がないこと、通常プレイの開始・画面操作、および内部シナリオの動作を別々に確認する。

0.5.0 は main にマージ・デプロイ済みだが公開後スモークが失敗して GitHub Release 未作成。0.5.1 は動画の重複読み込み修正を含む。ユーザーの版変更指示に合わせ、既に許可された3スプリントの一時例外は0.5.1へ移し、他バージョンには適用しない。公開後テストやデプロイ検証は省略しない。
