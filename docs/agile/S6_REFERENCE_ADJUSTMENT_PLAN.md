# S6追加：参照記事に基づく釘調整・比較の実行計画

## やりたいこと

2026-10-15、ユーザーの「このスプリントで対応してほしい」により、参照記事を踏まえた釘調整と試射をS6の#23へ追加することが明示承認されました。別スプリントの開始待ちにはしません。左上の釘群を狙う方針と元図の形を保ち、上流の寄り・道の末端・ジャンプ相当を分けて比較します。

追加範囲の承認後、PMが具体的な3案と短長の規則を確定しました。Leadが実装中です。測定開始はPMの差分確認とソース凍結後です。Issue投稿・PR・コミットはPM担当です。

## 確認内容

### 固定する条件

- 元101本のID・属性・元図配置を基準にします。候補の各釘は元座標からの累積距離1論理単位以内で、既存移動へ上乗せして上限を取り直しません。
- 左上狙いを保ち、自然なばらつきと初接触の差は許容します。発射0.14は本編未採用の実験対照のままです。
- 半径1.8、口幅12、参照レール・壁・弁・風車、重力・反発・発射間隔を固定し、独自のヘソ誘導ガイドを追加しません。
- 実機のmm寸法・奥行・釘軸の曲げを校正したものではありません。写真の矢印をそのままdx/dyへ置換せず、コードの平面配置で表せる範囲を明記します。
- 元図基準と、先行比較の道入口ID2下0.25案を別々の対照として保持します。新案へID2移動を自動合成しません。

### 確定した比較枠

各案は原図配置から単独で作り、他案や旧ID2移動を合成しません。

| 区分 | 釘と移動（論理単位） | 部位/仮説 |
|---|---|---|
| 対照1 | 原配置、移動なし | 同じ新世代で再観測する基準 |
| 対照2 | ID2を下へ0.25 | 先行S6の道入口案を再観測 |
| 新案1 | ID58を右へ0.25 | 寄り・風車周辺の流れ |
| 新案2 | ID26を右へ0.25・上へ0.25 | 道末端からの到達 |
| 新案3 | ID90を上へ0.25 | ジャンプ相当付近の到達 |

短比較は5条件×開始位相0、各120秒発射＋45秒排出です。実発射数を分母に、次をすべて満たす新案だけを選別対象にします。

- ヘソ/実発射比が両対照を厳密に上回る。
- 計数が整合し、残球・滞留・LCD全層/前面×中心/半径境界がすべて0。
- 逆戻り/実発射比が両対照より悪化せず、PMが狙いを確認済み。

有望案は条件を満たす新案のうちヘソ/実発射比が最大の1案です。同率は変更本数が少ない案、総移動距離が短い案、さらに同じならID58→ID26→ID90の順で決めます。新案が両対照を上回らなければ長比較は行いません。

長比較は原配置・旧ID2案・選別した新1案の3条件×今回の短い選別に使わない開始位相0.175／0.35／0.525秒、各300秒発射＋45秒排出の計9件です。合算ヘソ/実発射比が両対照を上回り、逆戻り比は両対照より悪化せず、全行の計数整合・残球/滞留/LCD4区分0を必要とします。各位相・最大無入賞・一般入賞の悪化は隠さず提出し、最終採否をPMが判断します。追加案探索や改善するまでの繰返しは行いません。

### 新しい経路観測と映像保存

SOURCE y713、x72〜220の下降通過を実サブステップで観測し、x<136／136〜176（両端を含む）／x>176の3区分へ幾何分類します。初回と再通過を区別します。これは座標の分類であり、左右の良否や風車の実内部通過を名前だけで確定しません。球IDと実際の終点へ対応させます。

道末端SOURCE x355〜400/y824〜870への初入域も実サブステップで記録します。未分類・観測の欠測を0通過へ付け替えません。

全測定窓の実球座標を30Hz以上で保存します。生データのgzip保存は可能ですが、圧縮ファイルと展開後の両SHA、始終のソース識別値と全入力を保全します。先行9件の原データは変更しません。

### 独立監査項目

1. 実行前に候補/対照の全設定、選別順位、実行環境・版・入力一覧を保存し、新しい比較世代としてソースを凍結します。始終一致と保全コピーの全入力を照合します。
2. 101本のID・属性と元座標を照合し、変更したID/座標と累積距離、固定部材・球・発射が案間で同一かを確認します。写真に無い部材・独自誘導を作らないことを確認します。
3. 実shotと終点から、発射＝ヘソ＋一般/右入賞＋out＋returned＋残球を再計数します。実発射分母のヘソ比、最大無入賞、排出待ち中の入賞、逆戻り、残球・位置固定/滞留、LCD全層/前面×中心/半径境界を別々に示します。
4. 狙いの分布・初飛行・初接触・下流経路を確認します。近傍釘IDの推定を実接触IDと呼ばず、既存のroadContact等を直接の内側通過数へ読み替えません。直接観測が不足する項目は未観測と記録します。
5. 新世代の生データと再生用実球座標は測定全窓を保存する計画です。30Hz以上の時刻・全窓被覆・欠測を確認し、圧縮/展開SHAも照合します。先行コードの先頭60秒保存を全窓取得済みと呼びません。動画は同時刻・同倍率の前後を使い、抜粋と全測定の結果表を区別します。
6. 短い選別と未使用条件の長確認を分離し、失敗・改善なし・位相ごとの悪化も全行提出します。最終採否は入賞だけでなく狙い・返却・流路・見た目を含めPMが判断します。実機率・最適配置・未観測条件の改善を保証しません。

## 今の状況

先行S6の固定2案・全9件は保存し、受入済みの比較結果を撤回しません。道入口ID2案の長比較は26→29/各1,500発、逆戻り双方4、一般26→24、一条件で最大無入賞80.920→104.065秒へ悪化しました。内部の改善候補として保持した判断を、新3案の採用や本編反映へ拡張しません。旧0.14の全体採用見送りも維持します。

追加比較は実装中・未試射です。先行結果のsource識別値を新世代へ付け替えません。本編の従来レール・初期強度0.20・口幅20・追加皿ありは変更せず、#23全体はOpenです。旧8段落の台本案は追加前の案として保存します。改訂動画台本は追加結果が揃ってから差し替えて人間承認を受け、旧案の承認や合成を先取りしません。
