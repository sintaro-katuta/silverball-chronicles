# S8：ユーザー向けガイド編集ツール

目的：元画像に合わない線を、ユーザー自身が画像を見ながら簡単に修正できる状態へ渡す。線の採用判断を代行して完成扱いにしない。

対象：ローカル専用の独立したSVG編集画面。既存線の点移動、線の新規作成、曲線、途中点の追加・削除、拡大・移動・拡大鏡、取消・やり直し、自動保存、JSON保存・読込。参照は既存904×1280の元画像。釘は表示のみ。ゲームの配置・物理・演出は変更しない。書き出した線はsource画像座標の点列として後の実装へ渡せるようにする。

画面設計：画像を主役にした製図机。左に線一覧、中央に大きい元画像、上に編集道具、下に短い操作案内と座標。背景#e6edf3、紙#ffffff、文字#20364d、枠#c5d1db、操作#225bca、選択線#d73270。日本語のUIはHiragino系のシステムsans、座標はui-monospace。特徴は元画像だけを拡大する小窓で、点を動かす時も元の灰色線を読める。装飾的な大見出し・カード・動く背景を入れない。初期は選択した線だけ表示し、太い重ね線で原図を隠さない。

受入：実ブラウザで新規線、点移動、途中点、曲線、取消、保存・読込、再読込後の自動復元を確認する。ファイル形式の検証で不正座標や重複IDを拒否し、読込失敗で現在の作業を壊さない。保存データの線と実装用の点列を対応づける。ユーザーの作業をテストで消さないように別の保存領域で確認する。

## 確認した操作

実ブラウザの別作業領域で新規4点の線、点ドラッグ、曲線、途中点の追加（4→5点）、取消（5→4点）とやり直し（4→5点）、再読込での自動復元を確認。「作業を保存」で実際にJSONをダウンロードし、23本・新規5点曲線と実装用点列の一致を検証。同じファイルを読込操作で開き、復元メッセージと線一覧を確認した。編集中の点追加は専用ボタンを主操作とし、追加後はドラッグ操作へ戻る。

データ検証・履歴・曲線の書き出し誤差・画像外防止のモデルテスト6件成功。後続のユーザーファイル反映と合わせた14件も成功。本編・プレビューのビルド成功。ユーザーの実作業はテストと別の保存領域を使用。新しい保存ファイルを渡された場合は、そのファイルを記録し、変更対象を確認して取り込む。今回のユーザーデータ採用は [S8_USER_GUIDES.md](S8_USER_GUIDES.md) を参照。
