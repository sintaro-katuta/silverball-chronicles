# Sprint 8：道釘をガイドで置き換えた案の撤回

## 即時修正

本編のpixelRoadGuardsをfalseにし、3本の連続カプセル接触とその描画を外す。ガイドがない場合に液晶境界の装甲タイルを代わりに描くfallbackも本編の盤面トリムから外す。道釘26本を個別の釘として見せ、接触させる。レール案のコード・ログは明示的な比較用として保持し、本編へ適用しない。

発射玉/盤面玉の前後分離、出口の逆戻り防止片は、道釘の置換と別の修正なので保持する。確率・保留・払出は変更しない。
