# 台本

ヘソへの入賞を増やす目標は、三つの開始条件で七百五十発を打ち、ヘソ六十回以上、各条件でも変更前より減らさないことです。現在は未達です。

釘と風車の位置を少しずつ変えた比較では、目標を満たす案は見つかりませんでした。元配置の玉の流れを追い、次に風車の形を見直しました。

提供いただいた写真に合わせ、四枚羽根と菱形の中央を維持する案を取り下げ、三枚羽根と丸い中央の試作へ直しました。

羽根と中央は、見た目と接触に共通の形を使います。前面の円盤は玉とは奥行を分け、全面で玉を弾く壁にはしていません。釘と狙い、風車の位置、玉や回転の係数は固定しました。

新しいガイド撤去後の条件にそろえて、変更前後で各二百五十発を試しました。変更前はヘソ十三回、修正案は九回で、四回減っています。以前のガイド付きの結果とは分けています。

残り玉や滞留はゼロでしたが、ヘソに入らない最長の時間も、約三十一秒から七十秒へ延びました。形の修正と、入賞の改善は別々に判定します。

入賞改善としては不採用とし、追加の三条件比較には進みません。本編の風車は切り替えず、試作と全結果を残しています。
