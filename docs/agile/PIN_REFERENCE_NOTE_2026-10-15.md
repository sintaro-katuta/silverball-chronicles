# 釘の参考記事を配置の比較へ使う

2026-10-15、ユーザー提示の[４分の１チク「e東京喰種+αの釘攻略と感想（第弐版）」](https://note.com/4bunno1chiku/n/nfec58467b44a)（2025-06-29公開）と添付6画像を読み取り、既存の元101点へ部位を対応づけました。記事は筆者の実戦観察です。写真から実寸や効果を確定したものではありません。

## 今回使う読み方

ヘソの開きだけでなく、左上の入口から振り分け・風車・道釘・ヘソへ進む経路と、途中で外へこぼれる経路を確認する資料として使います。左上の狙い、元図の形と101本、元座標から累積1論理単位以内の既存制約を維持します。

| 添付 | 確認した説明の区別 | 現在の配置との対応 |
|---|---|---|
| 1 | 赤/緑はブッコミ/強めの狙いの区別 | 左上の入口付近27〜36。既存の狙いを変える指示にはしない |
| 2 | 緑は内側、赤は外へこぼれる経路 | 左の振り分け〜風車周辺37〜63。接触した数と内側を通った数は別 |
| 3 | 青/赤は筆者が評価するプラス/マイナスの調整方向 | 同じ寄り部位。各矢印と個々の釘番号の厳密な一対一対応は未確定 |
| 4 | 風車の下から道釘・一般入賞周辺を読む | 左道釘1〜26と内側64〜90。ヘソと一般入賞を別集計する |
| 5 | ヘソと、道の終端・ジャンプ付近を読む | ヘソ91/92、道末端23〜26、ジャンプ相当90（名称は位置からの推定） |
| 6 | 右側の3本を見る | 94〜96の位置照合候補。左打ちの候補に混ぜず、写真だけで入口名を確定しない |

×/○の全画像共通の意味は未確定です。色の凡例を画像間で流用せず、写真上の斜め方向をそのままコードのdx/dyへ変換しません。写真の一部は別機種例を含むため、同じ配列・機能が保証されるとは扱いません。

## 既存コードとの対応で分かったこと

元図は904×1280画素で、コードは `world x=SOURCE x×0.5−14`、`world y=SOURCE y×0.5＋120` の一様変換です。以下は元図の転記であり、今回の写真を採寸した値や実機mmではありません。

釘のデータは2Dの中心・半径・反発等で、写真の釘軸の傾き、釘首・頭の高さ差、奥行き、盤面の寝かせを表していません。『上向き』を単にy座標を小さくする操作と同一視しません。記事上の分類のためにroleを`jump`へ改名すると既存の接触処理へ影響するため、部位の対応は調査用の名前として分離します。

## 配置比較へどう活用するか

1. **寄り・風車で失う箇所を先に特定する。** 既存の`roadContact`、`nearHeso`、`earlySpill`は代理指標です。これらをそのまま『風車の内側通過数』と呼びません。保存済み映像と照合し、直接観測していない数は未観測と記録します。
2. **次の仮説を部位単位で分ける。** 風車上37〜63での外へのこぼれ、道末端23〜26からジャンプ相当90への到達、ヘソ91/92の中心差を別々に検討します。元図の101本を大きく作り替えたり、上流と下流を一括変更したりしません。
3. **今回の結果を正しい部位の結果として残す。** S6の釘2は道の入口側です。長比較の26→29回/各1,500発は、道末端・ジャンプ・風車上や記事の釘曲げを検証した結果にはしません。命釘案0/200も全方向の調整が無効という意味ではありません。
4. **良い点だけで採用しない。** ヘソと一般入賞、逆戻り、残球、滞留、液晶侵入、無入賞の最長時間、狙い・外枠・レールを同じ条件で確認します。写真で好ましい方向でも、コード上の試射結果が改善するとは前提にしません。

資料提示直後は読み取りと対応表を追加しました。その後、ユーザーの「このスプリントで対応してほしい」により、寄り・道末端・ジャンプ相当の3案を実装・試射する範囲が承認されました。[追加の実行計画](S6_REFERENCE_ADJUSTMENT_PLAN.md)に対象・移動量・観測方法・有限比較の規則を固定し、このS6で進めます。先行2案と全9件の結果は保持し、新旧のソース・計数を混ぜません。

記事の写真・図は製品画像やPR動画へ複製せず、元のURLと添付番号で参照します。元の101点から作った自前の部位図と位置JSONは、原作業場所の `prototype/reference-review/s6-20261015/reference-note/` と `reference-pin-map.json` に保存しました。
