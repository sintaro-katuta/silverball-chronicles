# S8：保存線から本編の盤面を組む

目的：ユーザー保存JSONの線を、比較用の重ね線だけでなく実際の枠・通路・部品の外形へ反映する。

対象：本編の静的な機構表現。ユーザー22本322点を動かさず、液晶まわりの面、左通路、右の流路、部品の縁を同じデータから作る。古い固定ポリゴン・重複したベゼルを今回のプロファイルでは使わない。キャラクターと演出、釘101本・玉径3・ヘソ幅20・初速補正125・風車・反発は保持。発射部の既知滞留の解消はこの見た目変更の受入へ混ぜない。

設計：既存の青鋼・銀・抑えた金の素材を維持し、ガイドの機械的な縁と背面の面を作る。元画像の印刷や固有の絵は使用しない。ユーザーの線を外へ押し出した別の接触や、白い平行線を追加しない。面の閉じ方は表示上の構成であり、新しい当たり判定にしない。

代表一本：通常時の盤面を本編と同じmountBoardで描画する直接プレビュー。実ブラウザで全体と左右を確認し、必要な修正後に本編の表示と一時停止・再開も確認する。テストでは保存線との一致、形状構築の非破壊性、従来のデフォルト表示の維持を確認する。公開はしない。

## 組み上げた範囲

- `source-board-surfaces.js`で、ユーザー線から中央の枠、左の通路床、右上の流路、右下の壁の面・始動口の成形面を構成。接触縁は322点のまま、素材の面だけをその背後へ作る。元図写真を製品へ描かない。
- 本編の`board-trim`で古い固定ポリゴンを置換。`lcd-view`の旧ベゼル重ね描きをこのプロファイルで停止し、液晶の位置・大きさ・マスク・演出の配置は維持。
- 上部のキャラクターと右の鞘・月章は既存素材のまま、外形とクリップを新しい面に合わせる。左下の旧四角い部品板を撤去し、開いた丸い輪郭を保持。
- 右下の長い流路を丸い旧キャリアで切らないよう、表示用の外形も保存線の外側の縁へ合わせる。筐体全体表示では、元の筐体画像の丸い窓が新しい右下を隠すため、共有外形で筐体の表示窓も切り抜く。接触・排出の外壁は変更しない。

追加した素材の面や表示の切り抜きは接触を増やさない。物理モデルの全シリアライズ結果が、表示形状を構成・描画する前後で同一であることを検証した。ガイドの描画縁は保存線と同じ点を使い、独自の線移動は加えていない。旧式の単独プレビューは元の描画を保つ。

## 確認結果

関連テスト20件成功。本編・プレビューのビルド成功。実ブラウザで直接プレビューの盤面・筐体全体を確認し、右下の欠けを修正後に再確認。液晶と筐体表示の再開・一時停止を実操作で確認。390×844のブラウザ表示でも盤面と右下の部品が収まり、操作へアクセスできることを確認した。実機スマートフォンでの負荷確認ではない。

本編の確認用セッション（`?review=session&scenario=reach-loss`）でも盤面を起動し、発射停止状態で新しい面とガイドが表示されることを確認。本遊技の持ち玉・抽選・払出の受入には用いない。2発で止まる既知の発射部滞留はそのままで、ここを成功としていない。

直接表示：`http://127.0.0.1:5460/dev/user-board.html`。本編と同じ`mountBoard`、本編オプション、素材・描画を使用し、確認ページではチケットやプロフィール保存を使わない。
