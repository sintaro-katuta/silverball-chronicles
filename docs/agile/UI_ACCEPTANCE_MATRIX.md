## 共通の視覚判定

1. 持ち玉、発射停止/開始、一時停止、強度がパネル内スクロールなしに操作できる。右打ち時は強度欄の自動調整文言が読める。
2. 操作部が図柄・人物・受け皿・排出部を覆わず、パネルと下部バーが重ならない。表示切替後もcanvasと枠の寸法が一致する。
3. 状態案内は現在の公開状態へ追従する。待機/停止/変動/右打ち/休止/玉切れの矛盾がない。RUSH残数0だけで未完了払い出しを終了扱いしない。
4. 消化回数の説明は発射数・保留数・最終当落告知数と混ざらず、演出中の回も含むと読める。
5. ブラウザ例外、欠落画像、残った旧canvas/PUSH、終了後の持越しがない。解消した問題は同条件で再確認する。
