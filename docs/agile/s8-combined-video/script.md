# 台本

三枚羽根を保ち、ヘソへの入賞を増やすため、増えた変更を同時に試しました。

道入口の釘一本を右へ、風車を上へ、ごく小さく動かします。狙い、玉の大きさ、釘の本数は変えていません。

最初の二百五十発では、変更前九回、単独変更十一回ずつ、組み合わせ十四回となりました。

風車を右へ動かす組み合わせは八回に減り、選びませんでした。

有望だった上の組み合わせを別の三条件で確かめると、ヘソは七回、十回、十回でした。

計七百五十発では変更前三十一回、組み合わせ二十七回で、目標の六十回と、各条件で減らさない条件を満たしませんでした。

玉の詰まりや残りはありませんでしたが、安定した改善ではないため組み合わせは採用せず、三枚羽根と元の配置を維持します。
