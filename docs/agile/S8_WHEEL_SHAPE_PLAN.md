# S8：風車の表示と接触形状を揃える

2026-10-16、ユーザーの「了解、修正する方針にしたい」により、[前回の提案1つ](S8_ROUTE_RESULTS.md)の実装・比較を承認。Issue23・sprint/S08・PR35内で継続する。期限は固定せず、下記の有限比較・検証・判定まで進める。

目的：盤面に見える風車の羽根・中央部と玉が接触する輪郭を揃え、道へ渡る流れとヘソ入賞がどう変わるかを実数と映像で確認する。

対象：既存の尖った4羽根と中央部を共通の形状定義へ移し、同じ回転角で描画・接触に使う1案。未知の透明外装を円の壁へ置換せず、見えない誘導や追加の力を入れない。衝突の向き・面の速度・角速度への反応を既存係数で扱い、接触円だけを安易に拡張しない。

守る条件：101釘の全座標/属性、左上の狙い、発射.18/間隔、風車中心(64,476.5)・初期角.28・初期角速度0・羽根長10・既存反発/トルク係数/減衰/角速度上限、球半径1.8と本編既定表示、重力、legacyレール/壁、口20、抽選/保留/賞球を固定。自然な接触で生じる回転差は結果として記録する。位置調整や別形状の追加探索は今回行わない。

最新仕様への整合：共有workspaceのdocs/pachinko.mdとDESIGN.md冒頭に、同日の別作業としてユーザー指示によるヘソ左右の受けガイド・取付板撤去がある。既存未コミット差分を保護する。今回の比較は両側をガイドなしに揃える。過去のガイド付き15/250や43/750を新しい基準とみなさず、旧形状/新形状を同一実装・ガイドなし・同条件でfresh測定する。発射.18はS8比較条件であり、本編初期強度.20は変えない。

試作・設計：既存表示の実寸輪郭と旧接触を0度/初期角/45度/90度の同倍率で比較し、共通形状1案を作る。羽根先端・側面・中央・羽根間の隙間を確認する。既存の回転・反発係数の意味を保持し、共通定義が描画と実ソルバーで一致することをテストする。最初の1案を通しで確認し、別案へ展開しない。

比較：旧方式を明示して再現できる内部指定を保持し、旧ガイド付き記録の短窓一致で既存挙動の互換を確認する。本編への新形状採用は性能判定後とし、比較段階では旧既定を維持する。計画・manifest・全依存source・HEADを凍結して、まずphase0旧形状250発、続けて共通形状250発を測る。実spawn250で停止＋45秒排出、最大300秒で250未達なら途中数・失敗をそのまま記録する。各試射終了時に試射数・ヘソ数・基準との差・一般/OUT・返却/残球/滞留/液晶侵入を報告する。測定中はsource/計画/HEAD変更、撮影、重いテストを並行しない。

選別：共通形状のヘソが旧形状を厳密に上回り、安全・狙い・副作用条件を満たす場合だけ、phase.175/.35/.525で旧形状と新形状を各250発（計6件）確認する。合計750発でヘソ60以上、各条件変更前非悪化、返却非悪化・残球/滞留/液晶侵入0・全計数一致を要求する。一般入賞/OUT/最大無ヘソ時間も開示し、未解決の悪化なら採用保留。既存で観測済みの位相なので未知条件への汎化や実機確率とは扱わない。未達時は性能目的で本編採用せず、失敗と形状一致の達成を分けて報告する。別案・別球径・位置変更へ勝手に広げない。
