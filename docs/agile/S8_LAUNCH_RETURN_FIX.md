# Sprint 8：試遊版の玉戻り修正

2026-10-24。ユーザーが試遊画面で玉の戻りを指摘した。基準は`bda2707`。前回は通常750発中354発の返却を把握しながら「試遊候補」として提示した。終了後残球0・計数一致だけでは発射から盤面へ進む体験の受入を満たさず、この提示判断を差し戻す。前の検証記録は当時の結果として保持する。

## 原因と変更

1. **異なる前後面の玉が衝突**：発射中の後面の玉と、盤面へ出た前面の玉が同じXYで衝突していた。表示と釘の接触は既に前後を分けていたが、玉同士の分離と発射待ちはreference-exitだけが分離対象だった。今回、`separateLaunchPlane`を使う盤面ではレールの見た目の種類にかかわらず前後を分離する。同じ面の玉同士の衝突は保持する。
2. **出口からレーンへ落ち戻る**：上記の修正だけでは、盤面へ出た玉が出口を逆に通って戻った。既存の楕円レールの端・初速・発射間隔を保持した`guarded-exit`を追加し、出口を横切る有限の逆戻り防止片を配置。既存の受動的な片側カプセル接触を再利用し、前面へ出た玉の戻りだけを受ける。部品の線分・厚み・支点は同じ座標から描く。後面の発射玉は後ろを通る。実機の蝶番慣性を測定したモデルではなく、閉じた面を表す理想化した構造試作。
3. **新しい流入経路での大径玉の挟まり**：250発・位相.35で玉160が右の釘98/99間に残った。玉中心は(237.423,541.122)、両釘から約3.2で支持され、終了時約99秒残存。釘97を左6.5へ移す初回修正は、別の位相0で釘93/97の挟まりを作ったため差し戻した。最終は97を下2.5、98を左2.75、100を上4、101を上8（元位置からの内部座標差）とし、隣接する97〜101と93/97の表面間を直径6より広くする。表示/接触共通で釘数101を維持。失敗した試射は残して再検証する。

4. **通常強度0.30の閉鎖電チューで滞留**：通常50発のうち5球が蓋と左側樹脂通路の間に残った。半径1.8向けの蓋の通過余白を半径3へ更新していなかった。閉鎖蓋の両端を`2×(半径−1.8)`、今回2.4だけ下げ、同じ端点を表示へ使う。開閉タイミング・入賞口・閉鎖中に入賞しない制御は維持。0.30と右打ちから再検証する。

球半径3・軽い風車・道釘の弱い反発・金属ガイド3区間を維持。抽選・保留・賞球・チケット・BGMは変更しない。戻った玉をOUTへ付け替える、玉を消す、盤面へ瞬間移動する、接触時に加速するといった処理は追加しない。力不足の玉が盤面へ出る前に返却される既存の会計も維持する。
