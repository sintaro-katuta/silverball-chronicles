# セレナの映像をゲームへ接続

## 変更

制作済み動画を通常待機・予告・共通戦闘・勝利・敗北・復活・大当り・RUSHへ割り当てる。ゲームの抽選結果と既存の決着時刻を用い、図柄・保留・獲得玉数はゲーム状態から表示する。動画の読み込みに失敗した場合は従来の表示へ戻し、一時停止に合わせて動画も停止する。

液晶開口部を動画で覆い、縦横比を維持したまま外側をマスクする。保留と文字は液晶内へ配置し、獲得玉数のテキストは高解像度で描く。大当りでは既存動画を編集した約12秒の映像を繰り返す。

## 制約

- 新たな動画は生成していない。既存映像には剣の出現や接触、映像の接続などの課題がある。
- 短縮リーチ等には従来演出が残る。動画はミュートし、ゲーム側の音を使う。
- 動画の一部は開口部の外側で切れる。映像・音の全経路の通し視聴と実機での性能確認は未完了。
- 大当り中は既存2素材を組み合わせた映像が繰り返されるため、映像の多様性には限りがある。
