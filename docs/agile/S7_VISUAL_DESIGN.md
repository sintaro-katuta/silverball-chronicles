## 伝えることと固定する条件

利用者が知りたいのは「左上のどこを狙い、強さを変えるとどこへ入り、その後どちらへ流れるか」です。赤い狙いを通っただけで入賞しやすいと説明せず、全体・左上・下流を同じ玉IDと物理時刻で結びます。

新しい対照は公開0.2.0の本編条件です。読取時の基準は`2ef267a4a9c6173990788bc6fa8a2bc6b8502531`、従来レール、通常強度0.20、口幅20、追加皿あり、元101釘です。現在の操作範囲は0.18〜0.30、刻み0.01です。球・表示倍率・重力・反発・発射間隔・風車・壁・レールを固定し、試射用の明示的な球径上書きで本編の描画倍率を変えません。抽選・保留・賞球・右打ちは変更対象にしません。

S6の参照レール・0.14・口幅12・皿なしは別実験です。旧位置図や動画は履歴の参考であり、新しい本編対照・狙いの受入結果に置き換えません。0.14は次の採用設定として指定していません。

## Lead・PMへ提案する狙いの判定

1. 本編0.20の新しい対照を先に観測し、出口から上側釘群へ入る位置を、A/Bと同倍率で示します。旧実験の最高点を現対照の実測値として置きません。
2. 最高点、最初の釘接触、接触反転、初下降を別イベントにします。接触で早く反転した玉を、自由飛行の最高点と混ぜません。入口を一度通過した数だけで狙い達成としません。
3. A/Bの領域・許容条件・順位は正式計画で実行前に固定済みです。球中心が内側／外縁から球半径以内の境界／A・B重複／領域外／不達を分けます。重複をA/B双方へ成功として二重計上しません。分布、初接触相手、最初の落下方向を併記し、毎球同一点や小窓全数一致を必達にしません。
4. 強め側は同じ左上入口の上・右との比較対照です。赤側へ合わせるため壁幅・球・レールを変えたり、接触点を強制する処理を加えたりしません。操作範囲外の値が必要なら、設定と利用者操作の整合案を先に提出します。

写真上の赤が下・左、緑が上・右という対応は、最初の自由飛行頂点または初釘接触点の散布図と、各分類の分母付き内訳で判断します。平均位置だけで二群を分けず、重複・領域外も見せます。分類ルールと順位はS7_PLANを正本とし、この図で別の合否基準を追加しません。候補は0.18／0.19／0.22、対照0.20。短い開始条件0、長い確認を行う場合は未使用0.175／0.35／0.525秒です。新対照を見ずに最適値や入賞増を認定せず、追加構造調整や釘変更を混ぜません。

## 新しい映像と図の最小構成

| 場面 | 映す内容 | 受入の条件 |
|---|---|---|
| 全体・位置図 | 本編対照と候補の全体、左上A/Bの位置、強度と固定条件 | 同時刻・同倍率。元101・枠・レール・口・皿が維持される。仮範囲と実軌道を区別する |
| 左上の連続数球 | 発射→出口→最高点または初接触→初下降 | 実記録1倍、両側同じ開始条件と時刻。前後層、釘頭と接触軸を区別し、自然なばらつきも残す |
| 下流・同じ玉 | 寄り／風車→道→ジャンプ相当→ヘソ／一般入賞／OUT | 玉IDと時刻を連結。内側通過、実接触、入賞は別分類。失敗・逆戻りも省略しない |
| 全結果 | 短い選別と未使用3条件の長い確認を別表に | 実発射分母、ヘソ/100発、一般入賞、OUT、返却、残球・滞留・LCD侵入、最大無入賞を全条件で示す |

全165/345秒を保存する場合でも、抜粋を全編再生と呼びません。停止直前・排出終端と実入賞前後を選び、入賞しない対照側も同じ秒で示します。保存fps/timeから実フレームを選び、1秒間隔の記録を連続軌道へ補間しません。発射の狙いと入賞率の評価に必要な試射数は分けます。

390/1440で左上と操作強度、全体の欠け、左右の倍率を確認します。注釈は細い線と短い文字を使い、釘頭・球・実接触点を覆いません。写真1の赤/緑を使う図には必ず文字ラベルを添え、下流は「内側」「OUT方向」と文章で区別します。

## #11とPR動画

#11は「失敗→制限付き診断保存→元の失敗判定を保持」の図と、通常成功・制御失敗・保存不能の表で説明します。再開成功や診断追加を、初回失敗の原因修正・実障害の復旧保証にしません。

PR冒頭は問題→狙い位置→同条件実球→下流と全結果・採否→#11診断→残件を想定します。新しいRemotion＋VOICEVOX動画の発話は確定結果後に作成し、ずんだもん・ノーマルの人間台本承認後に合成します。現段階は図の設計だけで、音声合成・依存シーン制作・renderは未実施です。撮影・測定はPMの新ソース凍結通知後に行います。
