## Lead・PMへ提案する狙いの判定

1. 本編0.20の新しい対照を先に観測し、出口から上側釘群へ入る位置を、A/Bと同倍率で示します。旧実験の最高点を現対照の実測値として置きません。
2. 最高点、最初の釘接触、接触反転、初下降を別イベントにします。接触で早く反転した玉を、自由飛行の最高点と混ぜません。入口を一度通過した数だけで狙い達成としません。
3. A/Bの領域・許容条件・順位は正式計画で実行前に固定済みです。球中心が内側／外縁から球半径以内の境界／A・B重複／領域外／不達を分けます。重複をA/B双方へ成功として二重計上しません。分布、初接触相手、最初の落下方向を併記し、毎球同一点や小窓全数一致を必達にしません。
4. 強め側は同じ左上入口の上・右との比較対照です。赤側へ合わせるため壁幅・球・レールを変えたり、接触点を強制する処理を加えたりしません。操作範囲外の値が必要なら、設定と利用者操作の整合案を先に提出します。

写真上の赤が下・左、緑が上・右という対応は、最初の自由飛行頂点または初釘接触点の散布図と、各分類の分母付き内訳で判断します。平均位置だけで二群を分けず、重複・領域外も見せます。分類ルールと順位はS7_PLANを正本とし、この図で別の合否基準を追加しません。候補は0.18／0.19／0.22、対照0.20。短い開始条件0、長い確認を行う場合は未使用0.175／0.35／0.525秒です。新対照を見ずに最適値や入賞増を認定せず、追加構造調整や釘変更を混ぜません。

## S7専用の実記録リプレイ

媒体専用コードは`prototype/tools/s7-media/`の`replay.html`、`replay.js`、`trial-input.mjs`、`capture.mjs`です。商品ソースを編集せず、既存`mountBoard({production:true,trialReplay:true})`と`applyTrialFrame`で保存座標・前後層・機構角を適用します。物理の再計算や補間はしません。元の記録Hzと全165/345秒のフレーム数・実時刻・計数整合を確認します。

比較の許容差は強度だけです。両rawの全101釘の座標/属性、固定形状、球の既定表示、開始条件、power以外の条件、全フレーム時刻は完全一致を要求します。本編既定を維持するため球半径の試射上書きを拒否します。baseline同士の参照だけは`--baseline-only true`を明示し、異なる強度の前後比較とは別表示にします。

Node記録とChrome描画で再生成した従来レールには、三角関数の浮動小数点末尾差がありました。描画側との数値照合だけ上限`1e-10`、全キー/順序一致を要求し、実差を記録します。両raw間の完全一致をこの許容差で緩めません。基準画像での最大差は`5.684341886080802e-14`内部単位でした。

計測の正常終端、始終source/plan/commit、gzip/展開SHA・byte数・layout/config/fps/フレーム数を照合します。媒体4ファイルとブラウザ起動ヘルパー・位置図JSON、public/font資産は機械入力とは別inventoryで始終照合します。全体/左上/下流は一様な倍率で切り出し、同じ時刻を描きます。実入賞前後を抜き出す場合も、入賞しない対照側を同じ秒で保持します。

```sh
# prototype/を127.0.0.1だけのViteで提供し、source凍結と撮影枠をPMから受領後に実行
node prototype/tools/s7-media/capture.mjs \
  --a "$BASE_RAW" --b "$CANDIDATE_RAW" --out "$FRESH_OUT" \

```

`--ball-ids A側ID,B側ID`でケースごとの実球を追跡できます。上左拡大は`△`が認定済み自由頂点、`×`が初実釘接触、`◇`が最初の反転で、記号はその玉の過去の実記録位置です。認定のない自由頂点を補いません。`--event side:index`は指定側の実ヘソイベントを基準に、両側同じ時刻窓を取得します。球IDはケース間で同一個体を意味しません。
