# 台本

今回は音を中心に、通常、戦闘、ボーナス、ラッシュの四つのBGMと、八つの用途の効果音を作りました。

変更前は短い背景パッドと効果音でした。変更後は、旋律とリズムのある曲が場面に合わせて切り替わります。

決意の一閃では、戦闘曲からプッシュ、一撃前の静けさ、決着へつなぎます。音付きで前後を聞き比べてください。

発展、プッシュの表示と押下、斬撃、一撃、復活、ボーナス開始、ラッシュ突入に新しい効果音を割り当てました。採用済みの当たり音は維持しています。

ボーナスは報酬を感じる曲、ラッシュはテンポの速い曲にしました。大切な効果音のときはBGMを引き、当たりの情報は公開前に音で漏らしません。

BGMと効果音は別々に音量を調整できます。一時停止や画面を離れた後の復帰でも、映像との位置と設定を保ちます。

音源の計測とブラウザーでの再生を確認しています。聴こえ方の好みや疲れにくさは試遊で確認し、そのフィードバックで仕上げます。
