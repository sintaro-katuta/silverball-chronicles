# 台本

今回は左上の狙いを変えず、釘をわずかに動かして、ヘソへの入賞が増えるか比べました。玉の大きさや物理、レールは固定しています。

三つの案のうち、ヘソ直前の釘を上げる案は、既存の受け皿との干渉検査で見送りました。部品や候補を差し替えず、残る二案を試しています。

同じ百二十秒の試射と四十五秒の排出で、各百九十六発を比べました。元の配置はヘソ十一回、道入口を下げた案は六回、ヘソ両側を開いた案は十一回でした。

玉の最初の反転と釘接触の領域別の数は同じでした。実行した全条件で、逆戻り、残球、滞留、液晶への侵入はありません。

道入口の案では一般入賞が三回から七回へ増えましたが、ヘソ入賞は減っています。ヘソ両側の案も入賞数は増えず、ヘソへ入らない最長の時間はわずかに延びました。

入賞が増えた案がないため、追加の長い試射は行わず、今の釘配置を維持します。この有限比較の結果を、別の条件や実機での確率の保証とはしません。
