# S9 音楽と効果音の初稿

2026-10-18。開始承認後、通常・戦闘・BONUS・RUSHのBGM4用途と、新SE8用途をオリジナルの数値スコアから制作しました。これは試聴・本編統合へ渡す初稿です。人間の聴感、ユーザー採用、本編への最終ミックスの合格を、合成完了やデコード成功から推定しません。

## 維持する採用方針

現行の明るい周期波シンセ、当たり−3半音・通常SE−2半音・高次倍音0.90の基準を尊重します。新SEもこの調律を使います。既存 `win` / `rushWin` の音程・識別リズム・尺・PCMは変更しません。保存当落・公開時刻・演出尺・PUSH・保留・払出・S8採用釘配置にも作用しません。

本編SEにドラムやベースを重ねた過去の不採用を、新BGMのリズム・低音まで禁止する規則へ拡張しません。好評だった低い2声ハーモニーは設計の参考とし、その音型を全用途へ流用しません。6.4秒の余韻試作や参照再現実験を採用済みとは扱いません。

BGMはSEスキルの対象外で、独立した旋律・和声・低音・リズムの作曲です。外部音源・サービス・録音・歌声は使っていません。写真や既存機種の録音から音を抽出していません。

## 代表初稿の自己批評と検証の範囲

最初に `decisiveHit` と `normal` / `battle` を音源化しました。一撃初稿は旧音とピーク同等でも平均音量が約4.4LUFS低く、入口へ偏った構成でした。中間版を非公開履歴に残し、音高・尺を保って持続本体の長さ/配分/減衰を調整しました。最新v0は−17.06LUFS、旧音は−16.02LUFS、true peakは両者約−5.04dBTPです。スペクトルで入口の下降と本体・保持を確認しました。これは聴感で改善を認定した記録ではありません。

BGMはスコアに旋律・和声・リズムの別パートがあり、単なる持続パッドとの差を作っています。一方、通常と戦闘の密度・主題の識別性、戦闘の音域上昇、反復時の疲れ、スマホで低音が失われた際の拍の明瞭さは未聴取です。本編で重なるSEを含め、ユーザーが判断する必要があります。

全4曲・32新SE音型・9旧比較音をWAV/MP3へ書き出し、finite/ピーク/ステレオRMS/mono loss/相関、FFmpeg LUFS・true peak、MP3全デコードを測定しました。LUFS分析だけ末尾1秒を加え、出力ファイル自体は延長していません。測定は音楽性や聴感一致率の採点ではありません。複数音が重なるため混合F0を一音の音程とみなさず、指定Hz列をスコアに保存します。

比較ページへは各用途の基準と最新v0だけを表示します。v1〜3と中間版は内部検証に残します。平均音量差で判断を偏らせないよう、manifestの `auditionGain` は大きい側だけを減衰しLUFSを揃えます。原WAV/MP3は変更しません。旧パッド3秒と曲全尺は役割・長さが異なり、同一旋律の再現比較ではありません。

旧win/rushWinは保存した旧合成コードと現在の実装で、各4音型・48kHz左右PCMが全8件一致しました。新SE8用途の同入力再生成、カタログ尺とフレーム数、不正入力拒否も純粋チェック済み。ブラウザ再生・本編同期・人間のスピーカー/イヤホン聴感・ユーザー受入は別の状態で記録します。

### 計測と音程の限定確認
