# 元配置250発を追って分かったこと

2026-10-16。今回の承認範囲は、元配置の精細観測・映像、盤面図との照合、修正案1つの提案までです。釘・風車の位置、玉の大きさ、物理、壁、受け皿は変えていません。

## 試射の結果

**250発中、ヘソ15発・一般入賞6発・OUT229発。** 返却・残球・滞留・液晶侵入は0でした。実250発で発射を止め、45秒排出しています。観測を追加する前の記録と、記録版を示す3項目以外の全既存JSON値（全座標・速度・接触集計・計数・表示条件・実終点を含む）が一致しました。単体テストは623件成功です。

## 主に確認する場所は、道に届くまでの受け渡し

OUT229球のうち、**203球は道釘26本への状態を変える接触がありませんでした。** 釘間の隙間や、ヘソ直前の受け皿だけを先に修正する根拠は得られていません。

同じ250球を、前面で道釘の中心を結ぶ線を上側から下側へ横切り、その交点では玉と釘の接触円が重ならなかった最初の移動で分けると、次のとおりです。接触で押し戻された移動は除きます。横断は幾何的な記録で、OUTの原因の認定ではありません。

|最初の該当する横断|球数|ヘソ|一般|OUT|
|---|---:|---:|---:|---:|
|通常の釘間|6|0|1|5|
|大きい切れ目2か所|18|0|5|13|
|該当する横断なし|226|15|0|211|

中心線だけを横切っても、球の円が釘へ重なる3球は「余白のある横断」に入れていません。接触による押し戻しと実際の移動も分けてあります。全球CSVは`route-analysis/all250.csv`、詳しい条件は[観測結果](S8_ROUTE_OBSERVATION.md)です。

## 風車の近くを通ったのに、羽根で動きが変わらない球

別の切り口では、風車の高さを最初に左側で下降した180球が全てOUTでした。この180球は全て道釘への変更接触がありません。

全180球が、記録された実前面座標の少なくとも一点で「風車が回った時の最大範囲に玉の半径を加えた円」の内側へ入りました。ただし、実際の羽根は4本で、その円全体が部材ではありません。風車による成功反発は71球、残り109球には位置補正を含めて状態が変わる羽根接触が記録されませんでした。変化のない接線接触まで否定するものではありません。

そのため、「風車から遠すぎる」「少し左へ動かせば拾える」「羽根を透過した」とは判断できません。羽根の形と、その時の角度を合わせて読む必要があります。この180球は上表と別の切り口なので、球数を足し合わせません。

## 原図と照合し、次の修正案を1つに絞る

**提案は、風車の羽根と中央部を、表示と接触で共通の形状定義から作ることです。** 現在は描画が尖った4羽根と中央の菱形、接触が丸い端を持つ4本の線分で、同じ輪郭になっていません。実写真では透明外装・中心・内部の形が重なり、どの面が球に触れるかや奥行までは確定できません。[原図・写真との照合](S8_ROUTE_REFERENCE_REVIEW.md)。

次の実装案では、釘101本と狙い、風車の中心・回転条件、玉、発射、壁、口、受け皿を固定し、羽根・中央部の形状を共通化します。まず実際の角度で表示輪郭と接触輪郭を重ねて確認し、共通形状へ移す案です。外装の未知の面を接触体へ追加する根拠にはしません。

これはヘソ入賞が増える保証ではありません。形状変更で接触が減る可能性や、詰まりの再発も検証対象です。承認された場合にだけ、変更前後を各実250発で比較し、有望なら既存の3条件750発・ヘソ60以上/各条件非悪化で確認する方針です。**今回は提案までで、形状修正や改善候補の試射はしていません。目標60/750は未達のままです。**
