# S8 右上ガイドの訂正

2026-10-26。ユーザーの座標705.8,266.6付近への質問を、前回こちらが元図確認なしに「釘追加」と取り違えた。ユーザーは釘ではなくガイドを意図していたと明言。誤追加した釘102を削除し、元図右上の灰色の帯をガイドとして実装した。

## 元図との照合

904×1280の元画像 `prototype/reference-review/pixi-source-layout/reference.jpg` を4倍で拡大して確認。右上の帯は元図およそ (733,245) から (715,264) に折れ、(721,289) から下へ湾曲して (815,467) で薄くなる。独立した釘の丸記号はない。元図のピクセル輪郭（読取り誤差およそ±1px）を `source-right-upper-guide.js` に記録した。ユーザーの指定座標は部位の位置を示すものとして扱い、壁をその空白点まで移動させることはしていない。実機寸法・材質は未計測。

見た目とソリッドポリゴンの当たり判定が同じ頂点列を使用。既存の盤面の配色とドット描画で帯を表現し、旧円弧の線が帯を透過して見えないよう前景にも描画する。既存101本の釘・ユーザー保存22パス・左側・玉径・発射強度は変えない。灰色帯を単一の釘や線分で代用しない。
