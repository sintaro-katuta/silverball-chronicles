# 風車へ当たる前の流れを確かめる

2026-10-16、ユーザーは風車での左右比より、風車に当たらず落ちる流れの見直しを指示しました。元101本・左上狙い・3枚形状・球・係数・壁/口を維持し、まず内部の観測を補います。動画は改善後まで保留します。

旧風車124→3枚70という値は成功反発の記録で、位置補正だけの接触を含む全接触数ではありません。接触未記録180はヘソ3・一般1・OUT176、全て未到達だったとは断定しません。保存30Hzの点では118発が新羽根＋球の最大包絡11.30645の外、旧4腕＋球の包絡13.1以内に来ています。ただし包絡は全面solidでなく、保存点だけで全軌道の非接触を証明できません。

今回の有限診断は、既存の現在3枚の元配置・phase0・実250発を、既存の非作用traceを有効にして1回だけ再測定します。反発・位置だけの補正、風車周囲への進入と通過、全釘成功反発の時系列を区別し、全発射・各群の終点を数えます。既存traceが出す実積分のmotionとsolver contactから集計し、30Hzの補間を同じ測定と表示しません。名目包絡進入と羽根への接触も分けます。予測用の仮想軌道は入れません。

源/plan/manifest/旧raw/新tool/testをSHAで固定し、始終HEADも固定。全250spawn-step停止＋45秒排出・発射最大300秒・全30Hz・実終点を既存runnerと同条件で保存。traceの有無で旧rawの全既存JSONが一致することを確認し、不一致なら診断を成功扱いにしません。新traceは接触と風車上流近傍の実移動だけに絞って保存し、全生SHA/byte/件数・入力と結びます。計数・残球/滞留/液晶4区分を独立照合します。

この診断では配置・風車寸法・物理係数・分岐率を変更しません。成功反発だけでない接触の定義、実際に近くを通った玉、直前釘の反射を根拠に次の変更箇所と有限案を決めます。ヘソ60/750・各条件非悪化の目標は維持、左右50:50だけで入賞改善に合格とはしません。新候補の実装・250比較はこの診断に混ぜず、対象と変位を固定してから進めます。本編採用・公開なし。
