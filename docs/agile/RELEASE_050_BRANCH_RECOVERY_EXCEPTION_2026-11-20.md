# 0.5.0 リリース要約の一時例外

0.4.0 公開後の変更が旧 `release/0.4.0` に集約され、PR #88 で `release/0.5.0` に移された。0.5.0 の候補には、受入済み3スプリントの番号を正確に対応づけられない。2026-11-20、ユーザーはこの条件の一時緩和を許可した。

0.5.0 の main 向け PR に限り、`releaseScopeException: "0.5.0-branch-recovery"` と空の `sprints` を明示した要約を受け付ける。実際の変更、対象 Issue、改善と制限の記載は必要。別の版は従来どおり3件の異なる Sprint が必要。ビルド、単体・ブラウザ・盤面検証、公開前後の検査や main マージ承認は変えない。

対象には完了済み #57 と #78 がある。フロア #65 と液晶 #74 は未完了のため、関連変更を含むことと Issue 全体の完了を区別する。実機性能および映像・音の通し視聴は未確認。0.5.0 公開後、当例外コードは削除する。
