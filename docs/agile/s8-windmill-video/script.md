# 台本

ヘソへの入賞を増やすため、釘の比較に続いて、風車の位置を変えて試射しました。目標は、三つの開始条件で合計七百五十発を打ち、ヘソ六十回以上と、各条件で変更前より減らさないことです。

これまでの釘だけの比較では、確認した三条件の最良の結果は、変更前の四十三回に対して五十五回でした。目標の六十回には届かず、本編には採用していません。

今回は百一本の釘、狙い、玉の大きさ、物理、レールを固定して、風車だけを元の位置から左右上下へ別々に動かしました。移動量は内部座標で零点二五で、実測のミリメートルではありません。

各二百五十発で比べると、元の位置はヘソ十五回、左は十一回、右は十一回、上は九回、下は十一回でした。四案とも、元の位置より入賞が減りました。

今回の五件では、逆戻り、排出後の残球、滞留、液晶への侵入はありません。ただし、安全項目に問題がないことと、入賞が増えることは別に判定します。

採用する案はなく、釘と風車は元の位置を維持します。目標は未達です。原図との照合で見つかった釘の間隔と受け皿の重なりも、入賞減の原因かはまだ確認できていません。
