# S8継続：250発の実測でヘソ入賞を増やす

2026-10-16、ユーザーが「250発平均20ヘソ」を承認し、続けて「何かしら変化を与えた時に都度報告して、変更の試射した数とヘソに入った数」と指示しました。この計画はその承認範囲を具体化します。旧S8の120秒/196発・固定3案と終了判断は過去の結果として保持し、新比較の終了・採用判断には本書を優先します。PBI正本はGitHub Issue23、対象PRは35です。

## 目的と受入

- 目標は、変更後を3開始条件で各250発、合計750発測定し、ヘソ60回以上（平均20回/250発、8%）とすること。各条件で同条件の変更前よりヘソ数を減らさない。
- 元101釘と属性、左上の狙い、発射0.18、球半径1.8と本編既定表示、物理係数・発射間隔・従来レール/壁/風車/口20/既存皿を固定。各釘は原座標から累積距離1内部単位以内。新誘導部品・強制入賞・球径変更で目標を満たさない。
- 実発射=250を確認し、250到達stepで発射停止して45秒排出。最大300秒発射で未達なら失敗・未完とし、要求数250を実分母へ置換しない。全250球の実終点、返却/残球/滞留/液晶侵入、計数整合を確認する。
- 返却率を悪化させず、残球・滞留・液晶侵入4区分は0。一般入賞・OUT・最長無入賞・発射停止時刻も示し、未解決の悪化がある案は本編採用を保留する。
- 目標未達なら「比較が終わった」ことを入賞改善完了とは扱わない。未達の値、試した範囲、原因として分かったこと/まだ分からないことを報告する。候補数や安全条件を結果に合わせて変えない。

## 有限比較の手順

1. 新しい変更前を開始条件0で実250発測定し、PMが結果・固定条件を確認する。
2. prototype/tools/s8-shot-cases.jsonに固定した単釘12案を元配置から独立に、記載順で各250発測定する。毎回前の候補の移動を累積・合成しない。
3. 各案の設定前に変更箇所を示し、終端のたびに実発射数・ヘソ数・変更前との差・安全性をチャットで報告する。複数案を黙って連続実行しない。不成立/中断は試射0または実途中数と理由を示し、別案へ自動差し替えしない。
4. 安全と狙いを保ち、変更前のヘソ数を上回る案のうち最多1案を確認候補にする。同数なら変更本数が少ない案、総移動距離が小さい案、manifest順。短い選別で20未満でも、合算目標は別3条件で判断する。12案全体の結果を残す。
5. 有望1案だけ、選別に使わない開始条件0.175・0.35・0.525秒で変更前と各250発を測る。合計750発60以上かつ各条件の変更前非悪化と安全性を確認する。同じ条件の結果を後の候補選別へ流用せず、未達は未達と報告する。
6. 達成した案だけを本編へ反映し、通常/右打ち/停止再開・必要な回帰と現画面、最新CIで確認する。未達は本編を維持し、追加探索が必要な場合は次の有限の仮説・比較条件を具体化する。未達を埋めるため球や構造へ無断拡張しない。
