# S8 右打ち可動部の実装試作（2026-10-26）

目的：右打ちで、閉鎖中は下部の普図／OUTへ流れ、開放中は電チューまたはアタッカーへ入り、停止後に残球がない状態をレビューできるようにする。ユーザーの「実装後に結果をレビューする。指示待ちにしない」に基づくローカル試作。

基準：`631a317` の採用プロフィール、ユーザー保存線 `guide-layout-2026-10-25T16-27-47.json`（29本）。玉径12 source px、右打ち強度0.85、0.6秒間隔。元図の釘・保存線の点は変更しない。左の既存の採用調整も維持する。

## 動作と根拠

- アタッカーは下支点 (721.7,777.5) を固定。先端は閉 (725.4,658) → 開 (670.5,655)。ユーザーが観察した正面座標へ補間する。投影距離が変わるため剛体2D回転とは呼ばない。
- 閉じた板は玉の奥側。閉鎖中にその正面投影を壁にすると、玉が右の戻り側へ押し出されて詰まったため撤去。開放完了で手前へ出る縁と受付を有効にする。開閉途中の投影線を平面の壁にすると閉じ際に玉を右の裏通路へ押し込んだため、途中は奥側の移動として試作し、完全開放時だけ前面接触を有効にする。左右への抽選分岐は追加しない。
- 下部特2電チューは、奥へ引く蓋と受付を分離した試作。閉じた蓋の正面投影に広い床判定を置かない。開放完了時だけ source Y852・中心X581・幅46 source px の下降横断を受け付ける。572付近を含む。開放中の短い右縁は (613,835)→(604,837)。実機の内部扉形状・奥行き量は未計測。
- 古い広い `denchuShelf` は新しい保存線と重なっていたため削除。
- 普図の下りに図の点線で示されている区間を、既存端点 (559.2,874.9)→(558.6,898.3)、(582.7,874.4)→(582.6,896.8) につなぐ奥側の短いシュートとして試作。ユーザーの保存線は動かさず、この補完を別の接触部品として記録する。実機の断面形状の確定ではない。
- OUTは図の「OUT」文字がある受け皿の上端 Y897、X589.6..632.9 の下降横断で排出。描かれた底まで落とすと受け皿内へ溜まるため、実際の入口と底の描画を分ける。滞留時間による削除・玉の縮小・吸引・瞬間移動は使わない。
- 新しい可動板は接触に使う姿勢から描画する。重なっていた静的な下部飾りをこのプロフィールだけ外した。

606,800付近の隙間は約4.64 source pxで玉径12より狭い。そこを新しい通路にしない。535付近の入賞境界、奥行き構造、実機の正確な秒数は引き続き試作扱い。[調査資料](S8_ELECTRIC_MECHANISM_RESEARCH.md)。
