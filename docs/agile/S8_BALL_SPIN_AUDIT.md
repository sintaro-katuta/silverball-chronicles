# 玉径を維持した接触モデルの監査

2026-10-24。ユーザーの「玉の大きさは変えないのは無理でしたか」を、既存の玉径優先を維持する確認として受け止める。小径案の採用依頼を撤回し、球半径3・元図の釘中心・保存線・発射強度0.18/初速補正125・法線反発を固定して接触モデルを調べる。本編の採用条件は未達のまま。

原因仮説：現ソルバーは玉の角速度を持たず、接触の法線速度だけを反発として更新する。釘上の静止が物理的に存在することと、自然な流れの中でそこへ過剰に捕捉されることを分ける必要がある。「大径では無理」とは結論していない。

試作：既存の枠接触見直し案で、角速度0から開始する球の並進・回転を、クーロン摩擦の接線インパルスで結合する。慣性係数は一様球の2/5。摩擦係数は未実測の作者パラメータとして0.08と0.2の最大2条件を比較。移動壁を除く静的接触では、並進＋回転の運動エネルギーを増やさない。球速の直接補充、初期スピンの注入、接触径の縮小、軌道補正はしない。法線反発係数は変更しない。失敗した試作は保存し、本編へ導入しない。

参照：Erin Catto, Sequential Impulses (GDC2006), https://box2d.org/files/ErinCatto_SequentialImpulses_GDC2006.pdf 。Box2D公式の摩擦・回転抵抗の説明 https://box2d.org/documentation/md_simulation.html 。式の考え方の参照でありBox2D導入・実機再現の主張ではない。

受入：エネルギー監査、摩擦無しで従来同一、停止球へ勝手な推進力を加えないこと、自然発射20球の残留と姿勢の比較。試作が改善しなければ既存の形状と多点接触のモデルへ戻り、ユーザーに小径への妥協を求めて完了扱いにしない。

## 結果

既存の製品ソースは変更せず、一時ディレクトリのコピーへ法線反発後の接線インパルスだけを追加。コピーに対し球半径3・初速補正125・通常強度0.18の自然発射20球を2条件で比較した。係数0.08/0.2とも20球が返却し、盤面への通過案として不採用。接触から発生した角速度の最大は約19.6/48.9 rad/s、静的接触による並進＋回転エネルギーの増加は両条件0。摩擦で並進と回転へ配分される分、現状の発射条件の校正も関わるため、回転だけを足して完成とはしない。

単体テスト3件成功。接触方向・速度・角速度・摩擦係数の組合せで、エネルギーの非増加、クーロン上限、摩擦無しの厳密な従来維持、支持インパルス無しの無推進、接線滑りの減少を確認。実機の摩擦係数や奥行きの校正はしていない。風車と玉同士の接線摩擦は今回の試作に含めない。

この失敗から「現在の玉径では不可能」とは結論しない。現ソルバーが回転を持たないことは確認できたが、回転導入だけで直ることも示せなかった。今後の接触・発射・多点支持の校正と、見える部品の前後関係の確認は未完。本編の玉径・速度・釘・保存線は未変更。

比較画面から小径案の採用依頼を撤回し、玉径維持・未解決を冒頭に明記。小径の過去対照は折りたたんだ履歴だけに残し、操作可能な候補から外す。ユーザーへ追加判断は求めず、検証を開発側へ戻す。旧資料S8_FRAME_ROUTE_REVIEW.mdの玉径判断依頼より本追記を優先。

成果物：`prototype/reference-review/s8-ball-spin-20261024/`の数値結果、実行したコピーの接触ソース、単体テストとビルドログ。実行用`prototype/tools/ball-spin-audit.mjs`は一時ディレクトリへコピーして試験するため、本編物理を変更しない。`src/dev/spin-contact-audit.js`も製品からimportされない。
