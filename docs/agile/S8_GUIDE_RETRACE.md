# S8：ガイド線の再採寸

2026-10-24、ユーザーの6枚の指摘画像を受けた差戻し。旧source-layout.jsのガイドは粗い推定点であり、釘101点の照合成功をガイドの一致へ広げた前回の報告は誤り。

目的：元図のガイド線を、左入口、左の液晶脇、左下の曲面、液晶下の複数の縁、右下通路、右上通路の各部位で合わせる。対象は釘・ガイドのみ。釘101点、玉半径3、ヘソ幅20、発射補正125、風車・反発・抽選・演出を固定する。

基準：904×1280の元画像。元データの自己比較を合格根拠にせず、元画像を通常濃度で表示した拡大比較を全6区間で確認する。表示と接触を同じ採寸線から作る。図の線は2Dの転記であり、実機の奥行き・可動部・機能は画像だけで確定しない。追加の縁は用途を記録し、玉を支える見えない面にしない。

受入：全6区間と未転記の縁を一覧にし、既存の粗い線を重複して残さず置換する。元画像と現版を全区間で目視確認し、未確認を位置一致と報告しない。物理試射の結果と画像の一致を分けて残す。公開は行わない。

## 指摘との対応

| 指摘 | 原因と修正 | 表示・接触の扱い |
|---|---|---|
| 1 左入口 | 自由に立つガイドが左へずれ、途中の曲率も不足。元画像の線を途中点ごとに採寸 | 自由ガイドとタイトル側の縁を別の輪郭として共有 |
| 2 タイトル脇 | タイトル右側の旧液晶輪郭を使っていた。指定の左縁へ移し、下の斜面も釘の右側へ戻す | 旧縦線と右側入口ガイドは置換し、二重の壁を残さない |
| 3 左下 | 丸い部品を斜線と角で近似。外側、丸い下端、内側の開いた端を分けて転記 | 開いた端を勝手に閉じない。横の黒い帯は成形の表示のみ。実機の機能は未確認 |
| 4 液晶下 | 複数の縁・段差を1本の旧輪郭へまとめていた | 道釘側の外縁を接触とし、厚い成形縁・液晶側内縁・ベゼルの段差は橙の表示。別々の壁を重ねない |
| 5 右下 | 粗い斜線が緑の印刷面と白い空間を横切っていた | 外壁・内壁、枝分かれ、曲がり、下の成形縁へ置換。可動棚・ポケットと小さな偏向部品は維持 |
| 6 右上 | 少数の点を結び、曲線の途中と折れ曲がりの高さがずれていた | 曲線途中を再採寸し、下側へつなぐ。外観の外縁も別に表示 |

元のsource-layout.jsは旧試作・測定の基準として変更せず、本編のdiagramプロファイルだけで旧ガイドを置換する。新データは`src/pixi/source-guide-trace.js`。描画と接触は同じ点列を使用する。ポケット・可動棚・偏向部品、発射部の既存接触、釘・風車・玉径・初速・演出は比較テストで維持を確認。偏向部品の接触だけが残る状態を避けるため、既存の描画も保持する。

比較画面は元画像を薄くせず、[部位別照合](http://127.0.0.1:5460/dev/s8-guide-audit.html)で元画像／現版を並べる。青はガイド、橙は接触を追加しない成形縁、紫破線は今回未変更・元画像への校正をしていない可動部モデル。発射レールの接触区間制限も表示に反映し、接触のない下部延長を青い壁として見せない。

## 確認と限度

現ブラウザで全6部位の拡大画像と、本編表示を確認。釘101点の一致とガイドの形状確認を分ける。独立に元画像から読んだ27点を接触線と比較し、許容距離2 source px以内を確認。元画像の灰色・黒の画素との近接も補助的に計測したが、釘や文字にも反応するため、この値だけを合格にしていない。下側のタイトル縁では実際に釘を拾っていた近似を、目視で修正した。元画像のぼけ・丸みの転記であり、ガイド全点の完全一致や実機の深さを保証しない。
