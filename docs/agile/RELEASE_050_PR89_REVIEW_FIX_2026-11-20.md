# 0.5.0 PR #89 レビュー指摘の修正

対象は映像の終端と戦闘中の PUSH・保留表示。抽選結果・保留数・停止順・演出時計・払い出しは変更しない。

- 非ループ動画は演出時刻が動画終端に達したら終端付近のフレームを表示して停止する。遅れて表示し始めた場合も終端を表示し、演出時刻が戻った場合は再開する。ゲームの休止・タブ非表示も従来どおり停止する。
- 映像背景の戦闘では PUSH を上に移し、画面下部の保留表示との重なりを避ける。映像を表示していない場合は従来位置を維持する。

ローカル検証：release build と関連単体テスト12件。チャージ動画は実ブラウザで自然終端・遅延表示・停止保持・戻した後の再生を PC 1280×960／スマホ幅390×844で確認。保留4個を固定した戦闘は全体・盤面・液晶の各表示、PCとスマホ幅で画像を確認し、PUSH 押下時の当落保持を確認。既存のキーボード操作試験は外れ表示・復帰まで成功。画像は `/private/tmp/serena-review-fixes/`、実機端末・全演出の通し視聴は未確認。
