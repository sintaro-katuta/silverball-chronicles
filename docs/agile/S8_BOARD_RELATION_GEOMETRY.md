# S8：原図の釘・風車・道・ヘソの位置関係

2026-10-16、ユーザーが再掲した904×1280の盤面図と、作業版 `fb6d26a` のコードを読み取りました。**原図から転記した中心が一致することと、球が同じように通り・乗り継ぐことは別です。** 本稿は構造理解の記録で、新しい試射・風車移動・製品変更はしていません。

## 根拠と単位

- 再掲画像：添付 `E10B887A-6E80-43D5-9F74-98895DEB0F0C/1-写真1.jpg`。全体を実見しました。寄りの釘群→風車→右下がりの道→ヘソという相対配置、道の途中の大きい切れ目を確認できます。設計者が各釘へ与えた意図や奥行きは画像だけでは確定しません。
- [source-layout.js](../../prototype/src/pixi/source-layout.js) の転記を [lcd-layout.js](../../prototype/src/pixi/lcd-layout.js) が一様変換します。`world x=SOURCE x×0.5−14`、`world y=SOURCE y×0.5＋120`。101釘の位置をこの転記から生成することは確認しましたが、再掲画像上の101中心を今回すべて再採寸したわけではありません。転記は概ねSOURCE±1画素の不確かさを含む記録です。
- 以下の距離はコードから独立に再計算した**論理単位**です。球半径1.8、直径3.6、釘の接触軸半径0.2を使用。11mm球を仮定した約3.06mm/論理単位は実機の採寸・縮尺校正ではありません。
- 釘の表示は14px画像を`.52/3`倍にした外枠約2.427ですが、接触軸の直径は0.4です。画像内の透明余白や釘頭と軸を同じ寸法とは扱いません。写真の釘の傾斜・首・頭・盤面の寝かせも現在の2D円では表現しません。

**機能仮説：** 上の釘群で入射位置・速度を振り分け、風車の接触時刻・回転位相を経て道1/2側へ受け渡す配置に見えます。単に風車を道へ近づければ良いのではなく、道1との狭い箇所と上側からの入射を同時に見る必要があります。初期角・回転・球同士の接触を含む実挙動は未検証で、風車移動の改善はまだ試していません。

## 4. 現在の追加皿が元の釘列と重なる

[heso-guide.js](../../prototype/src/pixi/heso-guide.js)の左皿の4頂点はworld `(170.5,530)→(197.5,552)→(197.5,558)→(166.5,536)`。右は口中心に対して反対側です。この皿は原図釘の座標を保ったまま追加した本編部材で、原図から転記した釘そのものではありません。

皿の**表示は塗った多角形、物理は閉じた周囲4辺それぞれの半径0.6カプセル**です。内部全体を塗り潰したsolid-polygon接触ではありません。下表の符号付き余白は、釘中心から最近の皿辺までの距離−釘半径0.2−皿辺半径0.6です。負なら軸円と辺カプセルが幾何的に重なります。

| 釘 | 皿の表示多角形内に中心 | 最近辺への中心距離 | 軸と辺カプセルの余白 |
|---|---|---:|---:|
| 23 | 外 | 0.908 | +0.108 |
| 24 | 外 | 0.572 | **−0.228** |
| 25 | 内 | 0.053 | **−0.747** |
| 26 | 内 | 0.940 | +0.140 |
| 89 | 外 | 2.440 | +1.640 |
| 90 | 内 | 0.266 | **−0.534** |
| 91 | 外 | 10.028 | +9.228 |
| 92 | 外 | 10.344 | +9.544 |
| 93・右皿 | 外 | 0.050 | **−0.750** |

26は軸だけなら辺と重なりませんが、球中心へ作用する皿辺の接触帯は半径1.8＋0.6＝2.4です。中心距離0.940より大きく、釘への接近と皿の反発が競合し得ます。90等の小移動が既存の皿余白検査で拒否されたことも、この関係と整合します。これは静的な幾何の指摘で、今回新たに球を流して接触不能を実証したものではありません。

[描画順](../../prototype/src/pixi/board-runtime.js)も、同じrearLayerに釘Spriteを置いた後で、追加皿の支持板・塗り・縁を加えています。そのため表示多角形内の25/26/90や近い釘頭は皿に覆われ得ます。新しい描画を撮影して隠れ方を画素で確定したわけではありませんが、元図の釘を保ったことだけでは視認性を保証できない順序です。

物理は各stepで皿を含む固定辺→釘の順に接触し、密集時の球同士の位置補正後にも釘→固定辺を繰り返し解決します。両者の接触帯が競合する場合は、単独釘の中心距離だけで元図と同じ役割を期待できません。一方、この競合だけを全入賞不足の原因と断定せず、皿を外す・広げるなどの変更も本稿から実施しません。

## 現時点の整理と検証が必要なこと

- **可視原図の関係：** 寄り群と風車、風車右下の道、2つの大きい切れ目、下がった末端から高い命釘、下の口を別の機能段階として読むのが妥当です。釘単独の「プラス方向」を画像だけで決めません。
- **現在コードの計算値：** 元図由来の中心と一様変換は保持しています。ただし接触軸0.4、球3.6、風車の腕半径1.3、口20、追加皿の位置関係は独立に点検すべきモデル条件です。写真の頭径・軸傾斜・奥行や実寸校正の完了を意味しません。
- **機能仮説：** 風車から道1への位相依存の受渡し、道の小隙間/大隙間での通過・反射、26→90→91への渡り、追加皿との接触競合は説明候補です。どれが主因かは未特定です。
- **次に必要な判断：** 原図を再現したい範囲と、過去に追加した本編皿を保持する範囲を先に揃え、同倍率の表示・同じ接触輪郭・実際の球の通り方を対応させる必要があります。これを済ませず、風車4方向の比較が承認済みとは扱いません。既存の入賞不足・目標未達はそのまま残し、新候補や試射を勝手に追加しません。
