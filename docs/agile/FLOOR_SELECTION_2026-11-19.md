# 台選択画面（2026-11-19）

1階の台を選ぶ画面をPCとスマートフォン向けに構成し、台・人物・椅子・ドル箱などを個別に描画する。台を選択するとフロア上の右側に機種名、直近のスランプグラフ、基本スペック、プレイ開始を表示する。台番号は画面に表示しない。PCでは選択可能な筐体に沿うホバー表示を付ける。階移動と1プレイ0枚のフロア料金を表示する。

直近の本遊技の差玉（持ち玉−開始時の持ち玉）を台ごとに端末保存する。未遊技はデータなしと表示し、演出体験と確認用遊技を履歴に含めない。既存のチケット・抽選・出玉のルールは変更しない。

1階で遊べる台は5台、その他と2階は準備中。履歴は端末内の直近1回で、他端末や以前の未保存データは表示しない。公開とスマートフォン実機での確認は対象外。
