# 台本

本編と内部試射の条件を一覧に分け、左上の狙いと百一本の釘を保って、二つの微調整を比べました。

道釘一本を下げる案と、ヘソ両側を外へ開く案です。移動量はそれぞれゼロ点二五の内部単位で、実物のミリ寸法ではありません。

玉の大きさ、発射、壁、レール、重力、反発は同じにしました。

短い試射は各二百発で、ヘソ入賞は基準がゼロ、道釘案が二回、両側を開く案はゼロでした。

道釘案だけを別の三条件で長く試すと、それぞれ合計千五百発で、基準二十六回から二十九回へ増えました。

ただし、逆戻りは双方四球あり、一条件ではヘソに入らない最長時間が約八十一秒から百四秒へ延びました。

残球、滞留、液晶への侵入はありませんでした。一般入賞は、ヘソと分けて表に示します。

道釘案は改善候補として残し、本編の設定は維持します。今回の結果を、実機の入賞確率の保証にはしません。
