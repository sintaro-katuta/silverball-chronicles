# 台本

いただいた資料をもとに、風車左上、道釘の末端、ジャンプ釘に相当する位置を、このスプリントで調整して試射しました。

元の百一本と左上の狙いを保ち、指定した向きへゼロ点二五ずつ動かす三つの案を、別々に試しました。移動量は内部の座標です。

玉の大きさ、発射、口、壁、風車、重力と反発は同じにしました。写真の釘の曲げや傾きを再現したものではありません。

二百発ずつ試すと、元配置のヘソ入賞はゼロ、前の道釘案は二回、新しい三案はいずれもゼロでした。

新しい案に改善が見られなかったため、今回は採用せず、長い追加比較も行っていません。

風車付近では、左側を通った百五十一から百五十三球が、すべて排出されていました。これは観測用の座標区分で、原因を確定したものではありません。

逆戻り、残球、滞留、液晶への侵入は、五条件ともありませんでした。試射は排出完了まで記録し、入賞の前後も同じ時刻で比べます。

先行の長い比較では、それぞれ千五百発で、元配置二十六回、前の道釘案二十九回でした。新しい三案の結果とは分けて残し、本編の設定は維持します。
