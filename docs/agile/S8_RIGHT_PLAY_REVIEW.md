# S8 右打ち専用の確認画面

2026-10-25、ユーザーが左打ちを良さそうと確認し、右打ちに絞ったレビューを依頼。採用版16（631a317）の盤面・釘・玉径・物理設定を維持して、観察用画面を追加する。右打ちの不具合の修正や仕様変更は、この画面の作成に混ぜない。

## 目的と画面

[右打ち専用画面](http://127.0.0.1:5462/dev/right-play-review.html)。確認点は、右上から詰まらず下るか、開いた入賞先へ届くか、発射停止後に玉が残らないか。

- 初期条件は電チュー開放（RUSHの経路）、右打ち強度0.85、50玉。途中で通常打ちへ自動移行しない。
- 条件選択で、アタッカー開放（大当りの経路）・両方閉鎖（排出経路）を選べる。条件変更時は再読み込みして球と集計を最初からにし、条件間の残球を混ぜない。
- 右打ち全体・右上・アタッカー・電チュー・盤面全体のビューと、同座標の元図重ね表示。一時停止時に玉番号・座標・速度と低速の継続時間を読める。
- 電チュー・アタッカー・普図作動口・その他入賞・OUT・返却・残球を分ける。
- 入賞先を開いた/閉じた状態で玉の経路を見る機械的なレビュー。実際のW抽選、V入賞、大当りの開閉タイミングや収支の通し試遊を再現したとは扱わない。

## 実装と境界

新しい公開API `setMode` は `mechanicalOnly:true` でだけ使用でき、本編の通常セッションから条件を上書きしない。既存のmode選択と同じ内部処理を呼び、画面表示・開閉と発射強度を揃える。新しいカメラは表示専用で、既存の左打ち・盤面ビューを変更しない。

関連15テストと通常/比較ビルドを確認。左打ちの物理・採用プロフィール・保存線は変更していない。ブラウザでRUSH条件の強度0.85と右上の玉1（source775.2,361.7）の停留表示を確認した。過去の右50発の結果を、このページを今回再生した結果へ読み替えない。

## 指定釘の追加

その後ユーザーが座標705.8,266.6への釘追加を依頼。現在の画面は採用版16＋釘102。詳細は [追加と計測](S8_RIGHT_UPPER_PIN.md)。上記の「物理未変更」は画面作成時点の記録であり、その後の釘追加を含まない。

画面の実再生で、RUSH50玉は電チュー49・残球1、大当り50玉は排出49・アタッカー0・残球1を確認。閉鎖条件は15発時点で表示「両方閉鎖」・実発射強度0.85、条件変更時の集計リセットを確認（閉鎖条件の50発完走検証は未実施）。
