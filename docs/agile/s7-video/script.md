# 台本

今回は左上の狙いを保ち、発射の強さだけを比べました。釘の本数や球、壁、レール、入口と受け皿は変えていません。

写真の赤はブッコミ、緑は強め打ちです。元の強さ0.20と三つの候補を比べ、狙いを下と左へ寄せる0.18を選びました。

同じ時刻の実記録で、最初の反転と実際の釘接触を分けて見ます。自由な飛行の頂点を確かめられない玉は、不明として残します。

同じ試射の玉を、発射から下流の入賞やアウトまで追います。内側を通ったことだけで、入賞した原因とは決めつけません。

選別に使わなかった三条件の長い確認では、ヘソ入賞率の合算はほぼ同じで、二条件では低下し、一般入賞も減りました。0.18は狙い位置を合わせる目的で採用し、入賞の改善は保証しません。

公開後の確認が失敗した時は、通信や画面、エラーの記録を残します。保存できなくても最初の失敗理由を保ち、制御した失敗、保存不能、通常成功の三経路を確認しました。

変更後の操作と右打ち、停止と再開の確認結果も示します。実機の寸法校正と、以前の公開後確認が失敗した原因は残る課題です。今回、本番は更新しません。
