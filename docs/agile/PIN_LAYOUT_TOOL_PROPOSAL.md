# 釘配置ツールの要求案

2026-10-10。ユーザー提供の手書きメモを元にした要求。対象/AC提示後のユーザー「はい」でS5開始承認済み。現在の実行範囲は[S5_PLAN](S5_PLAN.md)を優先し、以下の未決事項は要求整理時の履歴と区別する。PBI正本は[Issue #22](https://github.com/sintaro-katuta/silverball-chronicles/issues/22)。

## 目的と読み取り

実機との乖離を減らすため、釘をどこに配置するかを調整できるようにする。配置の自由度が高すぎるとAIの判断で変更が広がり、釘配置の影響を切り分けにくい。盤面の配置可能地点に間隔・制約を設け、比較できる釘配置ツールを作る。

球の大きさ・釘軸径・物理設定・盤面寸法なども差の要因になりうる、という問題意識として読み取った。写真の不鮮明な語句は逐語転記せず、未確定の目標や寸法を補わない。実機との差が釘配置だけで説明できるとは断定しない。

## 現在地

- 2026-10-10にPR #20のマージをGitHubで確認。S4の#13は5台共通の固定配置と説明を合わせる対象で、編集ツールは別PBI。

## 初回の範囲案

初回は開発用のローカルツールとして開始承認済み。プレイヤー向け機能へ拡張しない。

1. 現行盤面を基準として読み込み、釘・固定部材・配置可能地点・禁止領域を重ねて表示する。
2. 許可地点を選んで配置する。地点の間隔・原点・対象領域は仕様データで管理し、任意座標や禁止領域への配置を拒否する。現行の不規則な101点を格子へ自動丸めしない。
3. 配置案を保存・読み込み・基準へ復元し、基準との差分と釘本数を表示する。
4. 同一の物理・発射条件で基準と候補を試射し、入賞・流路・停止後残球・計数を比較する。配置ID、コードSHA、条件と生ログを保存する。
5. PMが条件別結果と動画を判定し、本編へ採用する配置は別途確認する。

初回は手動候補の比較まで。自動探索・最適配置の決定・5台への自動反映・本番公開は初回の対象外。

## 受け入れ基準案

- AC1：現行配置を変更せず表示・再読み込みでき、表示と衝突計算が同じ配置データを使う。
- AC2：承認された許可地点・釘群・本数・距離制約に従い、禁止領域、地点の重複、固定部材との干渉を検出する。安全な通路・意図した隙間の扱いも定義する。
- AC3：候補の保存と読み込みで同じ配置を再現でき、配置データ・制約の版・差分を確認できる。不正なデータは適用を止める。
- AC4：配置以外の球径、釘軸径、重力、反発、盤面寸法、受け皿、発射強度・間隔、時間刻みを固定して比較し、条件の相違や未計測を明示する。釘群ごとの既存反発値を移動先から無断再決定しない。
- AC5：自然接触による入賞と流路、発射数・排出数・残球の整合を測る。強制入賞・吸引・球消去によって良い結果を作らない。抽選・保存当落・保留・賞球を変更しない。
- AC6：同条件の盤面・プレイ映像と差分図表から候補の利点・悪化・限界を説明できる。PR冒頭のRemotion/VOICEVOX動画で確認でき、PMがAC別に判定する。

## 要求整理時の確認項目（履歴・現設計はS5_PLAN）

- 開発用ローカルツールか、プレイヤー向け機能か。
- 配置可能地点の間隔・配置方式（盤面格子／領域別の候補地点など）、編集できる釘群、本数変更の可否。寸法を独断で固定しない。
- 「最適化」の評価軸。入賞頻度、流路の自然さ、詰まり、無入賞区間などを整理し、入賞率の最大化を自動的な目標にしない。実機比較には出典・条件を別途必要とする。
- 比較する発射条件、測定量、排出待ち時間と判定基準。既存測定を参考にし、過去ログを現在の結果へ代用しない。

## 担当・終了条件

Lead：現行配置・制約・比較計測の接続調査、承認された範囲の開発。Designer：編集地点・固定部材・差分と比較画面の設計。SM：依存・分割・受け入れ記録。PM：要件、ユーザー開始確認、成果物判定。

固定期間は設けない。S5は対象Issue・ACの開始確認済み。ツールで比較できる状態と、実機に近い配置の採用は別の完了判定とする。

## S5採用設計への対応

ローカル開発ツール、101本/属性保持、pitch4/原点[22,180]、ヘソ2固定、矩形群・最低中心4/固定部材clearance2をPM採用。格子地点は閉じ受け皿polygon追加後の群別376/117/708/0/53/27。実機寸法ではない。保存はbaselineIdentityとmetadataのbaselineSHA/layoutSHA/constraintSHAを分ける。JSONはツール配置だけを保存し、本編固定5台を変更しない。attempt02実比較とportableV2短UI証拠を提出。最終全回帰/候補join/実CI・承認待ち音声/PR動画は未完了。
