# 0.4.0 統合版の試打と残件

Sprint 7・8・9の統合候補。開始玉チャレンジ、盤面と右打ち機構、停止順・人物演出を含む。試打で風車下の短い坂を調整し、右枠の剣の装飾と盤上の賞球数表記を取り除いた。右下の大入賞後は、玉が既存の経路を流れて下部で回収される。回収位置は仮定であり、実機の内部構造を測定したものではない。

## 既知の残件

- 通常30発後の45秒排出で確認した2箇所の残球に対し、ユーザーが了承した釘79を元図座標で2px下へ移し、一般入賞口の共通前縁を浅くした。3位相の再検証と全809件が成功。球径・口の中心と幅・他の釘は維持。全条件で残球が発生しない保証ではない。
- 閉じた電チュー付近で玉が部材をすり抜けて見える。部材の奥行き・実機機構は未確定。見た目だけの変更と部材を短縮する試作は採用していない。
- 今回の試作の右打ち関連テストとrelease buildは成功。スマホ実機での確認は別に必要。
