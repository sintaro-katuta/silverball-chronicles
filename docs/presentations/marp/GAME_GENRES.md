# ジャンル別プレイ時間の円グラフ

2026-10-15、ユーザー指定の[Playtime Panorama](https://playtime-panorama.superserio.us/76561199132069185)が参照する公開APIから162本の累計プレイ時間を確認した。

取得値は `data/steam-playtime.json`、作品ごとの分類は `data/game-genre-classification.json`。複合ジャンルは紹介用に主な1ジャンルへ割り当て、重複加算しない。分類は厳密なジャンル定義ではなく編集上の判断。ローグライトFPSなどはローグライク／ローグライトへ分類した。

Wallpaper Engine、VRoid Studio、Aimlabs、VRChat、Desktop Mateはソフト・練習・交流として除外。「その他」はストラテジー、放置、リズム、カード、レース等をまとめたもの。

`npm run genres` でジャンルごとの累計分を合計して、スライドの円を更新する。直径は `360 × sqrt(そのジャンルの累計分 / 最大ジャンルの累計分)`。したがって円の面積が累計時間に比例する。全円で同じ係数を使い、小さい円の最低サイズによる水増しは行わない。
